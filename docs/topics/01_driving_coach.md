# ✅ 확정 주제: 운전 연수 어시스턴트 (가칭 DriveCoach) — 제품 정의 v2 (2026-09-26)

> v1(9/25)은 "일반 도로 주행 한 세션 + 채점 2층"이었다. 9/25~26 세 라운드 질의응답으로 **과제 카탈로그·모드·장소·커리어** 네 축으로 넓어졌고, 시연 주인공은 **후면 직각 주차 과제**로 바뀌었다. 결정 경위는 `../journal/2026-09-25.md`, `2026-09-26.md`.

## 0. 정체성

**화내지 않는 조수석.** 브레이크를 대신 밟아 주지는 않는다. 대신 감정 없이 보고, 주행 중엔 참고, 멈추면 말해 준다. 그리고 기억한다.

한 문장: 초보·장롱면허 운전자가 두려운 상황(주차·도로)을 **과제 단위로 연습**할 때, 차량 신호로 과정을 측정해 **가이드 → 힌트 → 평가** 순으로 손을 떼 가며 코칭하고, 세션이 쌓이면 **본인·동승자·(동의 시) 기관**이 보는 진단 리포트가 되는 AAOS 앱.

## 1. 문제 (계기)

- 아내가 장롱면허. 아기가 태어나 운전할 일이 생겼지만 **두려움**이 남아 있다.
- 지인 연수는 아무리 친해도 코칭 과정에서 **스트레스와 갈등**이 생기기로 유명하다. 옆에 탄 사람은 데이터를 저장하지 않고 기억과 감정으로 실시간 피드백을 준다.
- 면허는 취득 시점의 실력으로 평생 간다. 갱신 때 별다른 조치가 없다. **운전자가 자기 취약점을 개선·코치 받을 통로**도, **기관·보험사가 실력을 가늠할 지표**도 없다.

|---|---|---|
| **1** | 장롱면허·초보 (아내) — 두려운 상황부터 과제로 연습 | **○ 주차 과제 본편** |
| 2-1 | 면허갱신·보험사 제출용 진단 (고령운전자 능력평가 포함) | 진단서 화면 한 장 + 보상 예시 |

**동승자.** 있어도 없어도 앱은 같다. 바뀌는 것은 동승자의 역할 — 실시간 코치에서 **관찰자·응원자**로. 앱의 음성·가이드·점수표를 **같이 보고**, 세션 뒤 공유된 점수표를 근거로 코칭하면 감정 비용이 줄고 코칭이 수월해진다.

## 3. 제품 구조 — 네 축

### 3.1 과제 카탈로그

| 난이도 | 과제 | 유형 | 필요 신호 (확정/추정) | 주행 필요 |
|---|---|---|---|---|
| 하 | 출발 전 점검 (안전벨트·기어 P·시동) | 조작 | 벨트·기어·IGN (추정) | ✗ |
| 하 | 단순 전진 후 정지 | 주행 | 속도 (확정) | ○ |
| 하 | 좌회전 시 방향지시등 켜고 끄기 | 주행 | 방향지시등 (추정), 조향각 (추정) | ○ |
| 중 | 차선 변경 (지시등 3초 전) | 주행 | 지시등·조향각 (추정), 속도 | ○ |
| 중 | 일반 도로 코스 주행 (구간별 기대 행동) | 주행 | 속도 (확정) + B층 | ○ |
| **상** | **후면 직각 주차** ← 시연 본편 | 주차 | 속도 (확정), 기어 R/D/P·조향각·주차센서 (추정) | ○ |
| 상 | 평행 주차 / 전면 주차 | 주차 | 위와 같음 | ○ |
| 상 | 회전교차로 진입 (우선순위·진출) | 주행 | 속도·지시등·조향각 | ○ |
| 상 | 비상등 활용 / 날씨별 행동 | 지식 | — | ✗ (음성·화면 퀴즈) |

**시작 가능(READY, 2026-09-26)**: 출발 전 점검 · 후면 직각 주차 · 비상등/날씨 지식 테스트. 나머지는 카탈로그(계획)로만 보이고 상태기계가 시작을 거부한다(`Task.status`).

**출발 전 점검 채점(`ChecklistScorer`)** — 차는 서 있으니 주차 지표가 아니라 **순서**를 본다. 가이드 3단계 = 벨트 → 기어 P 확인 → 브레이크 밟고 시동. 배점은 가정(`INTEGRATION.md` B절 9/26).

| 축 | 본다 | 감점 |
|---|---|---|
| 숙련 | 벨트·시동을 다 했나 / **벨트가 시동보다 먼저**였나 / 30 s 안에 끝냈나 | 벨트 없음 -30 · 시동 없음 -40 · 시동 먼저 -40 · 10 s 초과마다 -5 |
| 안전 | 점검 중 차가 움직였나 / 끝에 기어 P / 벨트를 채웠나 | 움직임 -30 · P 아님 -30 · 벨트 없음 -40 |

신호가 `MISSING` 이면 그 항목은 감점하지 않는다. 힌트 모드는 **시동이 켜지는 순간 벨트가 아직이면** 한 마디("시동보다 안전벨트가 먼저예요"), 움직이면 한 마디. Fake 시나리오 2벌(`ChecklistScenarios`): 잘한 점검 8 s → 100/100, 못한 점검 12 s(시동 먼저 + 살짝 움직임) → 60/70.

### 3.2 모드 — 손을 떼 가는 순서

| 모드 | 앱이 하는 것 | 채점 |
|---|---|---|
| **가이드** | 단계별로 말하고 **신호로 확인한 뒤** 다음 단계로 ("안전벨트를 매세요 → 확인했어요, 이제 기어 R") | 없음 |
| **힌트** | 조용히 있다가 **틀린 순간만** 말한다 (지연 0, 규칙) | 있음 |
| **평가** | 끝까지 조용. 멈추면 총평 | 있음 |
| **지식 테스트** | 정차 중 음성 질문 → 3지선다 화면 버튼(STT 는 사내 확인 후 얹는다) | 있음 |

**앱이 실력을 보고 자동 제안**하되(가이드 3회 통과 → 힌트 제안), 운전자가 언제든 다른 모드를 고를 수 있다.
가이드 모드에서 확인할 신호가 `MISSING` 이면 그 단계는 **확인 없이 순서만 읽고** 넘어가며 "이 항목은 확인할 수 없어요"를 리포트에 남긴다.

### 3.3 장소

실도로 / 편안한 주차공간 / **제휴 시험장** — `Setup` 에 "근처 제휴 시험장 · 오늘 14:00–15:00 비어 있음 · 코스 B(주차 3종) · 예약" 한 장. 실제 연계 없음(시드).

### 3.4 진행 — 세션에서 커리어로

- **프로필 두 층.** 자기 진술(첫 설정 대화 5문항: 면허 취득 연도 · 마지막 운전 시기 · 차종 · 목표 · 무서운 상황) + **관측**(세션마다 앱이 갱신: 실제 취약 과제, 조향 반복 경향, 급조작 경향, 자주 하는 코스). 진술과 관측이 어긋나면 앱이 제안한다("말씀하신 것과 달리 주차에서 더 헤매고 계세요").
- **점수는 횟수·시간 기반 개인 점수.** 크리티컬 기준 없이 "지난번보다"가 기본 비교. 실사용자 평균 대비 위치는 **같은 단계 사용자**(예: 장롱 10년차 재시작 2주차) 기준으로만, 본인 화면에서는 문장으로 순화하고 숫자는 진단서에.
- **"타인에게 피해 주는 요소"는 별도 축.** 자기 숙련(느림·반복)과 안전(급조작·지시등 누락)을 섞지 않는다.
- **멘트 톤.** 거부감 있는 말 대신 프로필 기반 위트로 북돋운다 — "장롱의 문 정도는 열었습니다. 좋은 출발이에요." 점수 구간 × 프로필 × 이력별 **시드 멘트 풀**을 두고(같은 점수에 같은 말 반복 금지), AI 가 프로필·이력을 보고 변주한다. AI 실패 시 시드 풀에서 고른다.

### 3.5 수신자·보상 (✅ 2026-09-26 결정: 구조 A + 수신자 예시 B·C)

진단서는 운전자가 **주도권**을 쥐는 문서다. 공유 범위를 3단계(총점만 / 항목별 / 원시 신호)로 고르고 단계마다 보상이 커지며 언제든 철회한다(구조 A). 수신자 예시: 보험사 — 운전습관연계보험(UBI)의 안전운전점수로 반영(현실 근거) / 기관 — 적성검사 일부 감면·고령 면허갱신 보완 자료(확장 서사). 시연은 화면 한 장, 실제 전송 없음을 화면에 밝힌다.

## 4. 시연 본편 — 후면 직각 주차 과제

### 4.1 흐름 (`LessonPhase`)

| 단계 | 내용 | 화면 | 음성 |
|---|---|---|---|
| **`Setup`** | 정차 중 대화로 설정. 첫 사용이면 프로필 5문항. 앱이 과제·모드를 제안, 운전자가 고른다. (옵션) 제휴 시험장 예약 한 장 | 터치 가능 | 대화 |
| **`Briefing`** | "후면 직각 주차, 가이드 모드. 오늘은 핸들 방향과 기어 전환을 봅니다." | 큰 글자 | 고지 |
| **`Maneuver`** | 주차 중. **속도 < 5 km/h 라 화면이 살아 있다** — 위에서 본 차 도식에 조향각·기어·센서 거리를 그린다. 가이드 모드면 단계별 음성 + 신호 확인, 힌트 모드면 틀린 순간만, 평가 모드면 조용 | 도식 (터치 없음) | 모드별 |
| **`Done`** | 운전자가 "다 됐어요" 버튼 (기어 P 이면 앱이 먼저 "다 되셨나요?"). 회차 피드백은 **"서두. 조언."** 두 문장 — "장롱 10년차, 문고리는 잡았어요. 다음엔 열어 봅시다. / 다음엔 벨트를 먼저 매고 출발해요." **운전자 문장에 숫자(횟수·초·점수)는 없다**(9/27 결정). 왼쪽에 신호로 계산한 **추정 궤적**("실제 위치와 다를 수 있어요") | 궤적 + 두 문장 | 짧은 총평 |
| → 다음 회차 또는 **`Report`** | 세션 종료(버튼 또는 운전석 도어 열림) → 진단 리포트 | 리포트 | AI 총평·다음 과제 |

도로 주행 과제(2순위)는 `Maneuver` 자리에 `Driving`(잠금·음성만)이 들어가고 나머지는 같다.

### 4.2 채점 — **과정을 본다** (결정 (a))

앱에는 카메라가 없다. 차가 칸 안에 반듯이 들어갔는지는 **모른다**고 정직하게 둔다. 대신 과정을 잰다.

| 층 | 지표 | 필요 신호 | 비고 |
|---|---|---|---|
| **A (무조건)** | 이동 구간 수 (≈ 전·후진 왕복 근사) | 속도 | 정지→이동→정지 를 한 구간으로 |
| A | 총 소요 시간 / 정지 대기 시간 | 속도 + 시계 | |
| A | 급조작 (급출발·급정지) | 속도 미분 | |
| **B (신호 있을 때)** | 조향 왕복 횟수 · 최대 조향각 | 조향각 | 핸들을 몇 번 돌렸다 되돌렸나 |
| B | 기어 전환 수 (R↔D) · 마지막 기어 P | 기어 | |
| B | 근접 경고 횟수·최소 거리 | 주차센서 | 있으면 "오른쪽 뒤 30 cm" 음성 |
| B | 출발 전 점검 (벨트·IGN) | 벨트·IGN | 가이드 모드 첫 단계 |
| **안전 축** | 급조작 + 근접 경고 | | "타인에게 피해" 축, 숙련 축과 분리 |

리포트 배지: **실신호 N · 시뮬레이션 N · 미측정 N.** 무엇이 진짜인지 화면이 말한다.

### 4.3 가이드 모드 대사 — 신호 확인형 (결정 3)

```
"안전벨트를 매 주세요."           → 벨트 신호 ON 확인 → "확인했어요."
"브레이크를 밟고 기어를 R 로."      → 기어 R 확인      → "좋아요."
"핸들을 오른쪽 끝까지 돌리세요."    → 조향각 ≥ 임계     → "다 돌렸어요. 이제 천천히 후진."
"차가 45도쯤 됐어요. 핸들 중립."    → 조향각 ≈ 0       → "곧게 후진하세요."
"정지하고 기어 P."                 → 속도 0 & 기어 P   → "다 되셨나요?"  → [다 됐어요]
```
확인할 신호가 `MISSING` 이면 그 줄은 확인 없이 읽고 넘어가며, 리포트에 "이 항목은 확인할 수 없었어요"를 남긴다.

### 4.4 Fake 시나리오 2벌 (`FakeVehiclePort` 재생기)

- **잘한 주차** (`ParkingScenarios.good`): 시동 → 벨트 → R → 우 끝 → 후진 → 45°에서 정지·중립 → 곧게 후진 → 정지 → P. 이동 2구간, 조향 1왕복, R↔D 전환 0, 근접 0, 급조작 0. 26 s. 숙련 100 · 안전 100.
- **못한 주차** (`ParkingScenarios.bad`): 시동 → **벨트 없이** R·우 끝 → 후진(출발 뒤에야 벨트) → 너무 일찍 중립 → 전진(D)으로 보정 → 다시 R·우 끝 → 후진 → 근접 경고(35 cm) → **급정지**(-3.7 m/s²) → 중립 → 곧게 후진 → P. 이동 4구간, 조향 3왕복, R↔D 전환 2, 근접 1, 급정지 1, 벨트 늦음. 44 s. 숙련 60 · 안전 55.

이 숫자는 `ParkingRecorderScenarioTest` 가 고정한다(시나리오·채점기 어느 쪽을 바꿔도 드러남). `-PdemoSpeed` 로 압축.

### 4.5 시연 시나리오 (약 90초, "못한 주차" → 힌트 모드)

1. `Setup`: 정차 중 대화 — "오늘은 뭘 해볼까요?" 앱이 프로필(장롱 10년차, 목표: 아이 등하원, 무서운 것: 주차)을 보고 **후면 직각 주차 · 힌트 모드**를 제안. 운전자가 수락. (옵션) 시험장 예약 한 장 스쳐 지나감.
2. `Briefing`: "핸들 방향과 기어 전환을 봅니다."
3. `Maneuver`: 도식 위에 조향각이 돈다. 너무 일찍 중립 → 힌트 "핸들을 조금 더 유지하세요." 전진으로 고쳐 다시 후진. 근접 경고 "오른쪽 뒤 30 cm."
4. `Done`: 기어 P → "다 되셨나요?" → [다 됐어요] → "장롱 10년차, 문고리는 잡았어요. 다음엔 열어 봅시다. / 다음엔 벨트를 먼저 매고 출발해요." 왼쪽에 추정 궤적(전진 보정 한 번, 급정지 빨간 점). "몇 번 만에, 몇 초 만에" 는 **측정 원칙**(발표·리포트 자세히 보기)이지 운전자에게 들려주는 문장이 아니다.
5. 운전석 도어 열림 → `Report`: 숙련 60 / 안전 55 / 눈썹 `신호 출처` + 배지 `실신호 0 · 시뮬레이션 8 · 미측정 0`(외부 에뮬. 사내 실신호가 붙으면 그 수만큼 `실신호` 로 옮겨 간다) / 총평 두 문장(흐름 / 안전, 숫자 없음) + "다음엔 가이드 없이 평가 모드 어때요?" / **진단서 탭**: 공유 범위 3단계 + 예상 혜택 예시. 횟수·초 같은 숫자는 여기 **자세히 보기**·진단서에만.
