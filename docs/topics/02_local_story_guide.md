# 주제 후보 2: 로컬 스토리 음성 가이드 (A계열 단독, 메모 1·2·3·8)

## 한 줄

목적지를 정하면 AI가 **코스(경유지 2~3곳)를 추천**하고, 이동 중 지나는 동네·경유지의 **로컬 스토리를 음성으로** 들려주는 "차 안의 도슨트". 목적지는 숨기지 않는다.

## 운전자 가치

- **편의**: "어디 가서 뭘 볼지"를 코스로 받는다. 이동 시간이 콘텐츠 시간이 된다.
- **안전**: 운전 중엔 음성만, 정차 시 코스 카드·사진. 속도 신호로 화면 정보량을 조절.
- **차별점**: 관광지 오디오 가이드를 "경로 전체"로 확장. 주민 콘텐츠 확장 스토리(향후).

## 시연 시나리오 (약 90초)

1. 정차 중 목적지 입력("판교") → AI가 코스 3안 제시(카드) → 하나 선택.
2. 주행 시작 → 경유지 접근 시 "왼쪽에 보이는 양재 시민의 숲은…" 스토리 재생. 속도가 높으면 짧은 버전, 정체 중이면 긴 버전(속도 신호 활용).
3. 경유지 정차·도어 열림 → 그 장소의 사진·심화 스토리 화면 공개. 다시 출발하면 자동 잠금.
4. 도착 → 오늘 코스 요약 카드.

## 평가표

| 기준 | 점수 | 근거 |
|---|---|---|
| VSS 신호 존재 | 5 | 속도·도어만으로 충분 (둘 다 문서 확인) |
| Fake 외부 시연 | 5 | 위치는 경로 재생, 신호는 Fake |
| 3D 에뮬 임팩트 | 3 | 신호가 "정보량 조절"에만 쓰여 단계 전환이 눈에 덜 띈다 |
| 1인·2~3주 규모 | 4 | 결합안보다 상태가 단순(코스 선택→주행→경유지). Maps+Places+LLM+TTS는 동일 |
| AI 현실성 | 5 | 코스 추천·스토리 생성 모두 LLM 적합 |
| 편의/안전 설득력 | 3 | 편리하지만 "있으면 좋은" 성격. 안전 스토리는 화면 잠금 정도 |
| 사내 머지 리스크 | 4 | 결합안과 동일 |

**합계 29/35**

## 필요한 VSS 신호

`Vehicle.Speed`, `Vehicle.Cabin.Door.Row1.DriverSide.IsOpen` (둘 다 확인됨). 선택: 외기온(계절 스토리).

## 범위

- MVP: 코스 3안(시드) + 경유지 스토리 재생(TTS) + 속도 기반 화면 잠금.
- 2주차: Places 기반 코스 생성(LLM), Maps 경로선.
- 3주차: 스토리 길이 자동 조절, 사진 카드, 주민 콘텐츠 "제보" 목업.

## 리스크 · 판단

- 시연 임팩트가 낮다. 청중이 "내비+오디오북"으로 볼 수 있다.
- 강점은 **구현 안정성**과 **확장 스토리(주민 콘텐츠 플랫폼)**. 심사 기준이 완성도·실용성 중심이면 유리.
