# 주제 브레인스토밍 메모 (2026-09-16 밤, 사용자 원문 전사)

1. 여행가이드 음성가이드
2. 내비에서 추천하는 코스들
3. 숙박업소 사장님 등 지역 로컬 주민의 코스 데이터(음성 가이드 포함)를 받아 차를 타고 이동하며 이야기를 들음
4. 같이 여행하면서 내비를 공유 + 휴게소 및 작전 변경 등 소통 가능한
5. 놀러갈 때 정보는 조(組) 등을 고려해서 시간 자동 계산 + 처지는 차가 있으면 속도 혹은 조정 등을 통해 맞추는 기능
6. 랜덤 장소 가이드. 원하는 곳/기분(꿀꿀 등)만 제시하고 내비만 띄우고 중간중간 힌트를 조금씩 주는 방식. 랜덤한 선물 같은 드라이브, 막판에 선물
7. T의 발상. 콘서트 진입 시 가장 가까운 곳 (카카오맵의 "지하철 몇 번 출구로 나가야 가까운지"처럼) → 현대백화점처럼 특정 매장을 가려면 가장 가까운 주차장 위치 + 도착했을 때 예상 이동 경로 시뮬레이션
8. 해당 지역 관련 스토리 음성 중 가장 합입한(=인기 있는), 사람들의 조회수를 많이 받은
9. 지인에게 특정 장소를 가면 내가 남긴 메모리(사진·음성·텍스트), 제휴된 쿠폰
10. (추가, 09-17) 내가 마시고 싶은 커피(예: 메가커피) 픽업을 고르면 제휴 업체에 주문이 들어가고 픽업 매장까지 경로를 표시

## 인터뷰 진행 기록

### 1차 — 전체 방향 (2026-09-17)
- 사내 시연 환경에서 인터넷·지도 SDK 사용 **가능(확인됨)**.
- 심사에서 VSS 활용 비중은 **양념 수준이면 충분** (콘텐츠 경험이 주인공).
- 시연은 **에뮬 1대로 완결** → B계열(4,5 그룹 드라이브) 제외.
- 본인 애착 계열: **A(1,2,3,8), C(6), D/E(7,9)**.

### 2차 — 계열별 구현 방식
- A 콘텐츠 출처: **AI 생성** (위치·POI → LLM 스토리 → TTS). 주민 데이터 업로드 구조는 향후 확장으로만 소개.
- C 상호작용: **기분 입력 → AI가 반경 내 목적지 선정, 목적지 숨긴 채 음성 힌트**, 도착 시 공개+선물.
- D/E 데이터: **시연 장소 2~3곳 시드 데이터로 내장** OK.
- 결합 여부: **A·C·D/E를 하나의 드라이브 경험 앱으로 결합**.

### 3차 — 외부 의존
- 일정: **2~3주**.
- AI: **Cloud Copilot (GitHub Copilot 구독 있음)**.
- 지도: **Google Maps SDK + Places API**.
- VSS: 속도·운전석 도어(문서 확인됨) + 기어 P/D·동승자 좌석·연료/배터리·외기온(사내 목록 확인 필요).

### 4차 — 결합안 세부
- 도착 시 선물 기본형: **지인이 남긴 메모리(사진+음성)**, 시드 데이터. '남기기'는 제외.
- 음성 입력(STT): **MVP는 큰 버튼, STT는 3주차 옵션**. TTS 출력은 MVP 포함.
- 시연 지역: **서울 서초/강남 → 판교 현대백화점**.
- 확정 여부: 다른 후보도 평가해 비교 후 결정.

### 5차 — 확정
- **주제 확정: 01 Mood Drive 결합안.** 04를 1주차 MVP로.
