# 주제 후보 3: 도착 구간 주차·진입 안내 (D계열 단독, 메모 7)

## 한 줄

"현대백화점 판교 5층 식당가"처럼 **최종 목적지가 건물 안**일 때, 가장 가까운 **주차 구역·층·입구**로 안내하고, 주차 후 **매장까지 도보 경로를 미리 시뮬레이션**해 보여준다. 지하철 앱의 "몇 번 출구가 가까운지"를 자동차 버전으로.

## 운전자 가치

- **편의**: 대형 시설에서 주차 후 헤매는 시간 제거. 실제 자주 겪는 불편(본인 경험).
- **안전**: 주차장 진입 직전 저속 구간에서 화면 조작을 줄인다. 진입 후엔 음성 "B2 동편 램프로".
- **차별점**: 내비는 건물 입구까지만, 이 앱은 "주차 칸 → 엘리베이터 → 매장"까지.

## 시연 시나리오 (약 60초)

1. 정차 중 목적지 "판교 현대백화점 · 5층 A매장" 입력.
2. 주행 → 시설 반경 1 km 진입 시 "가장 가까운 주차: B2 동편, 엘리베이터 E3" 음성 + 카드.
3. 주차장 진입(속도 < 15 km/h 유지) → 층별 화살표 안내(시드 데이터 기반).
4. 기어 P·도어 열림 → 도보 경로 시뮬레이션(평면도 위 애니메이션) 자동 공개.
5. (옵션) 주차 위치 자동 저장(기어 P 시점 GPS) → 돌아올 때 안내.

## 평가표

| 기준 | 점수 | 근거 |
|---|---|---|
| VSS 신호 존재 | 4 | 속도·도어 확인. 기어 P는 사내 확인 필요(없으면 속도 0 + 도어로 대체) |
| Fake 외부 시연 | 5 | 전부 시드 데이터·Fake 신호로 재현 |
| 3D 에뮬 임팩트 | 4 | 저속 진입·정차·도어가 곧바로 안내 단계로 이어져 신호 연동이 눈에 띈다 |
| 1인·2~3주 규모 | 5 | LLM 불필요(있으면 양념). 평면도·시드 데이터 제작이 핵심 노동 |
| AI 현실성 | 2 | AI가 굳이 필요 없다 → "AI 기능 탑재" 가산점을 놓칠 수 있음 |
| 편의/안전 설득력 | 5 | 페인포인트가 구체적이고 누구나 공감 |
| 사내 머지 리스크 | 5 | 지도 SDK 없이도 시연 가능 |

**합계 30/35**

## 필요한 VSS 신호

`Vehicle.Speed`, `Vehicle.Cabin.Door.Row1.DriverSide.IsOpen` (확인됨), `Vehicle.Powertrain.Transmission.CurrentGear`(사내 확인), 선택: `Vehicle.CurrentLocation.*`(VSS 표준에 있음, 사내 목록 확인 시 GPS 대신 사용 가능).

## 범위

- MVP: 시설 1곳 시드(주차 구역 3개, 엘리베이터, 매장 5개) + 근접 감지 + 안내 카드 + 도어 시 도보 시뮬레이션.
- 2주차: 시설 2곳 추가, 주차 위치 저장/복귀 안내, 음성 안내.
- 3주차: LLM으로 "매장명 → 층/구역" 자연어 입력 해석(AI 양념).

## 리스크 · 판단

- 데이터가 전부 수작업 → "확장 가능한가"라는 질문에 답이 필요(시설 운영자 데이터 제휴 스토리).
- AI 요소가 약하다. 심사에 AI 항목이 있으면 불리.
- 가장 **완성도 높게 끝낼 수 있는** 후보. 실용성 심사에 강함.
