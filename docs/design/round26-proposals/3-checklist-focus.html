A

플레이리스트 확대

지금 줄: 높이 약 250 dp · 이름 72 dp(제목 크기) · 왼쪽 빨간 세로 띠 + 밝은 면. 다 한 줄: 약 96 dp · 32 dp · 흐림. 남은 줄: 약 114 dp · 40 dp. 목록 전체 높이는 그대로라 화면이 흔들리지 않는다.

장점

  • 사용자 말 그대로 — "확실히 크게, 나머지 작게". 크기 대비만으로 강조(Bold 금지 규칙에 맞음)
  • 목록의 순서·위치가 그대로라 "어디까지 왔나" 가 단계 막대 없이 읽힌다
  • 구조를 거의 안 바꾼다 — 같은 줄 컴포넌트의 높이·글자 크기만 상태에 따라 바뀜

주의점

  • 가독성 — 다 한 줄 32 dp 는 운전석에서 읽기 어렵다. 다 한 줄은 "읽을 것" 이 아니라 "지나간 것" 이라 의도된 흐림이지만, 회차 끝 판정 화면에서 다시 크게 보여 준다
  • 정직성 — 지금 줄 오른쪽 아래에 출처(예: "브레이크 실신호 · 시동 시뮬레이션")를 11 dp 로 남긴다(위 그림에선 생략)
  • 힌트·평가 모드에는 "지금 할 항목" 이 없다 — 4번 페이지 결정에 따라 확대를 끄거나 다르게 쓴다

튀어나오는 카드

지금 줄이 Ink 목록에서 들려 나와 Paper 카드(먹 글자)가 되고, 오른쪽 끝이 패널 경계를 넘어 흰 영역까지 걸친다. 그림자로 "앞에 있다". 나머지 줄은 같은 크기로 흐려진다.

장점

  • "앞으로 튀어나옴" 이 가장 문자 그대로 — Ink 위 흰 면이라 대비가 다섯 안 중 가장 크다(야간에도 바로 보임)
  • 카드가 오른쪽 지시문과 맞닿아 "이 줄 = 저 지시" 가 이어져 읽힌다

주의점

  • 그림자 — 이번 라운드 "평면" 방향(알약 질감 제거)과 부딪힌다. 그림자를 빼면 튀어나온 느낌이 약해진다 — 겹침(패널 밖으로 걸침)만으로 버틸지 사용자 판단 필요
  • 구현 — 줄이 부모(왼쪽 패널) 밖으로 그려져야 해서 Compose 에서 `zIndex` + 잘림 해제가 필요. 오른쪽 지시문 자리를 카드만큼 비켜야 한다
  • 야간에는 넓은 흰 면이 눈부심 — 다크 모드(6번 페이지)에서 카드 색을 따로 정해야 한다

가운데 고정 바퀴

음악 앱의 가사 화면·시간 고르는 바퀴처럼, 지금 줄은 늘 패널 세로 가운데(두 가는 선 사이)에 가장 크게 있고, 위아래로 멀어질수록 작고 흐리다. 넘어가면 목록 전체가 한 칸 위로 흐른다.

장점

  • "지금 할 것" 의 자리가 늘 같다 — 운전자가 시선을 한 곳에만 두면 된다. 오른쪽 지시문과 같은 높이에 맞출 수 있다
  • 플레이리스트 "느낌" 이 다섯 안 중 가장 강하다(흐르는 움직임)

주의점

  • 가독성 — 첫 항목·마지막 항목에서 위나 아래가 텅 빈다. 끝 줄들은 거의 안 보여 "전부 몇 개인지" 가 안 읽힌다
  • 정직성 — 힌트처럼 순서가 틀린 항목(예: 브레이크 없이 시동)이 가운데 밖에서 일어나면 바퀴를 거꾸로 돌릴지 정해야 한다 — 흐름이 어지러워질 수 있다
  • 구현 — 목록 스크롤 위치·거리별 크기 계산(`LazyColumn` + `animateScrollToItem` + 거리 기반 scale). 다섯 안 중 손이 가장 많이 간다

아코디언 + 기다리는 신호

접힌 줄은 이름과 점만(상태 글자를 뺌 — 점 색이 됨/아직을 말함). 지금 줄만 펼쳐져 이름(66 dp) · 상태 · "기다리는 신호" · 신호 출처 배지까지 보인다.

지금 재생 중

왼쪽 패널을 음악 앱 "지금 재생 중" 화면처럼: 가운데 항목 그림(기하학 정사각형) + 큰 이름 + 상태·출처. 위에 "지난 것" 작은 알약 띠, 아래에 "다음" 띠. 목록이 아니라 한 장씩 넘긴다.

장점

  • 강조가 극단적으로 분명 — 패널 전체가 지금 항목. 기하학 일러스트 컨셉과 잘 맞고 시연 영상에서 가장 눈에 띈다
  • 지난 것·다음 것 띠가 단계 막대 역할을 대신한다

주의점

  • 그림 공수 — 항목 일곱 개마다 정사각 그림(도어·벨트·기어·브레이크/시동·좌/우 지시등·비상등). 마감 안에는 단순 도형으로만 가능
  • 가독성 — 지난 것 띠의 알약이 작아(30 dp) 각각의 값(닫힘·채움·P)이 안 보인다. 한 화면에 "전체 상태" 가 없어 힌트·평가 모드에는 맞지 않는다(그 모드는 목록형으로 돌아가야 함)
  • 다른 과제(주차 가이드)는 이미 오른쪽에 도식이 있어 같은 틀을 쓰기 어렵다 — 점검 전용 화면이 된다
움직임300 ms · 표지가 왼쪽으로 밀려나며 작아지고 흐려짐 · 다음 표지가 오른쪽에서 들어옴(`AnimatedContent` slideInHorizontally) · 지난 것 띠에 알약 하나가 붙음

구현새 레이아웃 + 항목 그림 일곱(Codex) · 큼

다섯 안 비교

"강조 세기" = 지금 줄과 나머지의 크기·밝기 대비. "힌트·평가" = 지금 할 항목이 없는 모드에 그대로 쓸 수 있나(4번 페이지와 연결).

안강조 세기전체가 한눈에신호 출처(정직성)평면 규칙힌트·평가공수
A 플레이리스트 확대강함예 — 일곱 줄 다 보임지금 줄 아래 작은 글맞음확대만 끄면 됨작음
B 튀어나오는 카드가장 강함예(나머지 흐림)카드 안그림자 필요카드만 끄면 됨중간
C 가운데 고정 바퀴강함아니오 — 끝 줄 거의 안 보임가운데 줄맞음흐름이 어색중간~큼
D 아코디언강함예(값 글자는 지금 줄만)가장 분명 — 배지맞음펼침만 끄면 됨작음~중간
E 지금 재생 중가장 강함아니오 — 띠로만표지 아래맞음목록형으로 돌아가야큼
추천 공수 작음

A 플레이리스트 확대 + D 의 출처 배지(지금 줄에만)

사용자가 말한 "확실히 크게 · 나머지 작게 · 커지는 애니메이션" 을 목록 구조를 그대로 둔 채 줄 높이와 글자 크기만으로 해결한다. 일곱 줄이 늘 다 보여 단계 막대를 빼도 진행이 읽히고, 힌트·평가 모드에서는 확대만 끄면 된다(4번 페이지와 충돌 없음). 정직성은 D 처럼 지금 줄 아래에 `브레이크 · 실신호` `시동 · 시뮬레이션` 배지를 붙여 채운다.

  1. Codex: 위 단계 막대 · 아래 "출발 전 점검 · 확인 상태" 삭제 · 줄 세 상태(다 함 / 지금 / 남음)의 높이·글자 크기 · 300 ms 크기 주고받기 애니메이션 · 지금 줄 출처 배지 · 줄마다 붙던 "시뮬레이션" 작은 글은 지금 줄에만
  2. Claude: 상태기계 변경 없음(`guide.index` · `availability` 그대로). 화면 계측 문구 계약에서 "출발 전 점검 · 확인 상태" 를 찾는 곳이 있으면 제거
  3. 시간이 남으면 B 의 "패널 밖으로 걸침" 만 그림자 없이 더해 본다 — 평면 규칙 안에서 앞으로 나온 느낌을 보탬
