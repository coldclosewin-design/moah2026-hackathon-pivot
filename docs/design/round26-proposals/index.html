라운드 26 시안 — 앱 전반 피드백(10/7)

사용자 사내 에뮬 직접 사용 피드백 중 "시안을 보고 고르고 싶다" 여섯 주제. 시안 없이 정해진 열두 가지는 Codex 라운드 26a(#228)로 이미 진행 중.
각 페이지를 열어 보고 "1-1, 2-A, 3-A+D …" 처럼 고르면 26b(화면) · Claude 모델 PR 로 나눠 구현한다. 마감 10/9 — 공수 표시를 같이 본다.
1
홈 — 과제 표시 · 바꾸기 · 시작 (10안)
과제 알약 · 과제 카드 + 바꾸기 · 분할 알약 · 두 줄 선택기 · 과제 칩 줄 · 제목 속 밑줄 링크 · 시작 알약 안에 과제 · 좌우 반전 · 과제 묶음 패널 · 코치 질문 + 두 답. 안마다 첫 실행(과제 미리 고르지 않음) 목업.
추천 1안 과제 알약 — 주차 › 후면 직각 주차 · 힌트 모드 › 를 프로필 알약처럼, 누르면 과제 시트. 첫 실행은 빈 알약 + 과제 고르기 →. 여유 있으면 9안의 모드 세그먼트. 좌우 반전(8)은 마감 뒤.
작음
2
브리핑("운전대 화면") 정체성 · 시간 (5안)
A 준비 카드(출발 → 누를 때까지) · B 자막 + 진행 막대(음성 끝 + 1 초) · C 오늘 볼 것 미리보기 · D 브리핑 없애기 · E 과제 포스터.
추천 A 준비 카드 — 운전자가 출발 → 을 누를 때까지 머문다(움직이기 시작하면 저절로 넘어감).
작음
3
출발 전 점검 — 지금 할 항목 강조 (5안)
A 플레이리스트 확대 · B 튀어나오는 카드 · C 가운데 고정 바퀴 · D 아코디언(출처 배지) · E 지금 재생 중. 다섯 안 모두 위 단계 막대 · 아래 확인 상태 줄 없음.
추천 A + D 의 출처 배지 — 지금 줄만 커지고 나머지는 작아짐, 지금 줄에만 실신호/시뮬레이션 배지.
작음
4
점검 — 가이드 / 힌트 / 평가 차이 (5안)
1 물음표 가림 · 2 내 순서 기록지 · 3 면 색 + 모드 사다리 · 4 코치의 존재감 · 5 패널 폭. 안마다 모드별 보이는 것 · 들리는 것 표.
추천 1 + 3 의 모드 사다리 — 힌트는 틀린 줄만 드러나고 평가는 끝까지 가림. "?" 와 "미측정" 을 구분하는 규칙이 같이 필요.
작음
5
코치 문장 — 짧게 · 마침표 줄바꿈 (5안)
A 짧은 두 줄(문장 ≤ 20자) · B 제목 + 한 마디 · C 세 박자(≤ 14자) · D 핵심어 표시 · E 줄바꿈만(지금 길이).
추천 A — 두 문장 이하 · 한 문장 20자 이하(검증 22자, 넘으면 규칙 문장) · 쉼표로 두 말 잇지 않기 · 높임 "-시-" 는 운전자가 주어일 때만 · 큰 글자 72 dp. 규칙 문장 다시 쓰기 포함(Claude).
중간
6
다크 모드 색 (5안 · 고민)
P1 잉크 밤 · P2 Periwinkle 면 · P3 완전 검정 · P4 저청색 밤 · P5 황혼 + Ink 패널. 야간 눈부심 기준(넓은 면 상대휘도 ≤ 0.05)과 대비 실계산 표.
방향 P5 — 단, 색 토큰이 29개 파일 약 400곳에서 역할이 섞여 있어 리팩터가 먼저. 마감 전엔 구현하지 않고 발표에 "설계 완료, 구현 예정" 권장.
큼
추천만 다 고르면: 1·2·3·4 → Codex 26b(화면) + Claude(첫 실행 미리 고르지 않기 · 브리핑 머무름 · 점검 모드별 표시값) / 5 → Claude(프롬프트 · 규칙 문장) / 6 → 마감 뒤.
