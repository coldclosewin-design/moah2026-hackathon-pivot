홈 · 과제·모드 표시와 `과제·모드 바꾸기` 와 `시작` — 열 가지 배치

지금 홈은 과제 이름 줄(`출발 전 점검 · 가이드 모드`)과 그것을 바꾸는 링크(`과제·모드 바꾸기`) 사이에 `시작` 알약이 끼어 있어, 무엇을 바꾸는 링크인지 떨어져 보이고 분류도 안 보인다. 첫 실행에서는 추천 규칙이 과제를 미리 정해 띄워 당황스럽다. 열 가지 배치를 같은 데이터로 그렸다 — 각 안은 평소 홈(기록 있음) 1/3 화면 + 첫 실행 홈(과제를 미리 고르지 않음) 1/6 화면.

사용자 피드백 (원문, 10/7) — #홈화면 - '시작'알약이 다른 알약과 다르게 입체적인 느낌이라 플랫하게 변경 필요
- '출발 전 점검 가이드 모드' 와 '과제 모드 바꾸기'는 같이 있어야 헷갈리지 않고 실제로 모드를 바꿔야 해당 부분이 바뀌어야 이를 고려하여 디자인 제안 필요 (프로필 버튼 처럼만 해도 무방할 듯)
- '출발 전 점검부터.... ' 맨 아래 멘트 필요없으니 삭제
- (큰 공수가 예상되어 일단 선택사항)운전자 위치를 고려해서 버튼이랑 카드 등이 가깝게 전체 정렬을 반전(그림도) 시키는 것도 해보고 결정 고민해보자
- 처음 접속 한정으로 '예시. 후면 직각 주차' 란을 없애고 사용자의 당황스러움을 낮추기 위해서 임의로 설정하지 말고 실제 과제를 선택할 수 있는 버튼을 '과제 모드 바꾸기' 대신
- '후면 직각 주차 - 가이드' 보다 '주차 - 후면 직각 주차 (가이드 모드)' 같이 카테고리를 잘 명확하게 표시하는 방향으로 제시
- '과제-모드 바꾸기' 의 존재 가치에 비해서 위치랑 표시되는 항목이 '시작'알약으로 구분되어 있는 것도 좀 별로야. 이를 고려한 디자인 시안을 다양하게 10개 정도 구성해서 보여줘 고민하고 진행해보게
큰 화면 = 실제의 1/3 (853 × 423) · 작은 첫 실행 화면 = 실제의 1/6 — 실제 화면은 약 3배 / 6배

이미 반영한 확정 사항`시작` 평면 Signal(질감·하이라이트 없음) · 보조 알약 Lavender 평면 · 프로필 알약 얇게 `목표:` 구분 · 맨 아래 흐린 지난 코치 말 없음 · `코치와 대화` 알약은 열 오른쪽 끝(라운드 25).
표시 = 실제 선택 상태홈의 과제·모드 표시는 추천 문구가 아니라 지금 선택된 값(ViewModel 상태)이다. 시트에서 바꾸고 돌아오면 그 자리 글자가 바뀐다 — "실제로 모드를 바꿔야 해당 부분이 바뀌어야" 를 모든 안의 전제로 둔다.
첫 실행 규칙기록이 없으면 `ModeAdvisor` 가 과제를 미리 고르지 않는다. 홈은 "아직 고른 과제가 없다" 를 정직하게 보이고, 주 동작이 `과제 고르기` 가 된다(누르면 지금 과제 시트가 열린다 — 시트 자체는 그대로).
바뀌지 않는 것과제 시트(분류 트랙 · 카드 C · 모드 트랙 · `제휴 시험장`), 왼쪽 일러스트, 관리자 띠, 프로필 시트, 코치 대화 시트. 바뀌는 것은 홈 오른쪽 열의 과제 표시 · 바꾸기 · 시작의 모양과 자리뿐.
빨간 점선 = 이 안에서 새로 생기거나 모양이 바뀌는 요소· 과제 표기법은 시안마다 하나씩 다르게 써 봤다(각 칸의 "표기" 참고)

문제

  • 떨어짐 — 링크가 무엇을 바꾸는지 위치로 안 읽힌다. 링크는 `코치와 대화` 와 같은 줄이라 "부가 기능" 처럼 보인다
  • 분류 없음 — `후면 직각 주차` 만 보이고 그게 주차 과제인지(18개 중 어디인지)는 시트를 열어야 안다
  • 첫 실행 — 프로필 질문 뒤 홈에 `출발 전 점검 · 가이드 모드` 가 이미 정해져 있다. 고른 적 없는 과제가 떠서 당황스럽다
  • 링크의 무게 — 18개 과제 × 세 모드를 고르는 핵심 동작이 밑줄 글자 하나다

시안 1 · 사용자 제안("프로필 버튼 처럼")

과제 알약

과제·모드 표시 자체를 프로필 알약과 같은 문법의 알약으로 만든다. 누르면 과제 시트. 링크 `과제·모드 바꾸기` 는 없어진다 — 표시가 곧 손잡이.

표기주차 › 후면 직각 주차 · 힌트 모드 ›

장점

  • "바꾸는 대상 = 누르는 곳" — 떨어짐 문제가 구조적으로 사라진다. 끝의 `›` 는 프로필 알약과 같은 "눌러서 연다" 신호
  • `시작` 위에 놓여 "무엇을 → 시작" 순서로 위에서 아래로 읽힌다. 링크 줄이 비어 `코치와 대화` 만 오른쪽에 남아 정돈된다

주의점

  • 구현 — 이름 줄 Text 를 알약 컴포저블로 감싸고 링크를 지우는 정도. 프로필 알약 컴포넌트 재사용 가능
  • 가독성 — 알약 글자 36 dp(1/3 12px)는 지금 이름 줄(40 dp)보다 살짝 작다. 프로필 알약보다 한 단계 크게(높이 90 dp) 그려 위계를 둔다
  • 정직성 — 첫 실행 빈 알약이 "아직 안 골랐다" 를 그대로 말한다. 추천이 있을 때도 미리 채우지 않는다

공수 작음알약 1개 · 링크 제거 · 첫 실행 분기(빈 알약 + 주 알약 문구) · 계측 문구 `과제·모드 바꾸기` 찾는 곳 갱신

시안 2

과제 카드 + 바꾸기 단추

시트의 과제 카드 C 를 가로로 눕힌 작은 카드(그림 · 분류 · 이름 · 모드)를 홈에 올리고, 오른쪽 끝에 둥근 `바꾸기` 단추를 붙인다.

표기눈썹 `주차` / 이름 `후면 직각 주차` / `힌트 모드 · 이유`

장점

  • 시트에서 고른 그 카드 그림이 홈에 그대로 온다 — "실제로 바꾸면 여기가 바뀐다" 가 그림으로 확인된다
  • 분류·이름·모드·이유가 한 면에 묶여 위계가 분명하다(분류 작게 → 이름 크게 → 모드 흐리게)

주의점

  • 구현 — 새 카드 컴포저블. 그림은 시트 카드 그림 재사용(18개 모두 있음). 카드 · 단추 둘 다 시트를 연다
  • 가독성 — 예약 카드가 있는 날은 카드가 두 장 쌓여 오른쪽 열이 빽빽하다(예약 카드를 과제 카드 안 한 줄로 줄이는 처리 필요)
  • 정직성 — 첫 실행 흐린 `시작` 은 상태가 분명하지만, 흐린 알약은 "고장" 으로도 읽힐 수 있어 카드 쪽 `+` 가 눈에 띄어야 한다

공수 중간카드 컴포넌트 신규 · 그림 재사용 · 예약 카드와의 공존 규칙 · 첫 실행 빈 카드

시안 3

분할 알약 — 시작 | 바꾸기

`시작` 알약 오른쪽 끝을 잘라 Lavender `⇄ 바꾸기` 조각을 붙인다. 한 덩어리 안에서 "이대로 시작" 과 "바꾸기" 를 고르는 모양.

표기주차 — 후면 직각 주차 (힌트 모드) · 사용자 예시 그대로

장점

  • 바꾸기가 `시작` 과 같은 높이·같은 덩어리로 승격 — "존재 가치에 비해 작다" 를 바로 푼다
  • 이름 줄 → 분할 알약이 바로 이어져 "이 과제를 시작하거나 바꾸거나" 로 읽힌다. 사용자 표기를 그대로 써 볼 수 있다

주의점

  • 구현 — 분할 알약 컴포넌트 신규(모양만, 동작은 기존 두 진입점). 계측이 `시작` 알약 폭·자리를 보는 곳이 있으면 갱신
  • 가독성 — 운전석(왼쪽)에서 오른쪽 끝 조각은 가장 멀다. 큰 Signal 옆 작은 Lavender 라 잘못 누를 위험은 낮지만, 장갑·흔들림에서는 경계가 좁다
  • 정직성 — 문제없음. 다만 이름 줄은 여전히 글자라 "누르면 바뀐다" 는 조각 쪽만 말한다

시안 4

두 줄 선택기

홈에 직접 "과제 칸(분류 › 과제 ▼)" 과 "모드 세그먼트(가이드·힌트·평가)" 두 줄을 둔다. 모드는 홈에서 바로 바꾸고, 과제 칸만 시트를 연다.

표기과제 칸 `주차 › 후면 직각 주차` + 세그먼트에서 `힌트` 선택

장점

  • 모드 바꾸기가 한 번 누름 — 가장 자주 바꿀 값(가이드 → 힌트 → 평가로 손을 뗌)이 홈에 그대로 있다. 이유 줄이 세그먼트 바로 아래에서 즉시 바뀐다
  • 세그먼트가 시트의 모드 트랙과 같은 모양이라 새로 배울 것이 없다

주의점

  • 구현 — 모드 선택을 홈 상태로 끌어올리고 지식 과제일 때 세그먼트를 `지식 테스트` 한 칸으로 바꾸는 분기 필요. 계측 계약에 세그먼트 추가
  • 가독성 — 오른쪽 열 요소가 하나 늘어 가장 빽빽하다. 예약 카드가 겹치는 날은 제목을 한 줄로 줄여야 들어간다
  • 정직성 — 문제없음. 첫 실행 잠긴 세그먼트가 "아직 고를 수 없음" 을 보여 준다

공수 중간세그먼트를 홈으로 · 지식 분기 · 예약 카드와 높이 조정 · 첫 실행 잠금

시안 5

과제 칩 줄

최근 연습한 과제 셋을 칩으로 늘어놓아 홈에서 바로 고르고(선택 = Ink 채움, 분류 트랙과 같은 문법), 나머지는 `전체 ›` 로 시트를 연다. 모드는 작은 세그먼트.

표기칩 안 두 줄: 작은 `주차` / `후면 직각 주차`

장점

  • 다시 하는 과제(대부분의 날)는 시트 없이 한 번 누름. 칩마다 분류가 작게 붙어 18개 중 어디인지 보인다
  • 첫 실행이 가장 자연스럽다 — 기록이 없으면 칩이 분류가 되어 "고르는 버튼" 이 저절로 생긴다

주의점

  • 구현 — 최근 과제 목록(기록에서 셋 뽑기) 데이터가 새로 필요. 칩 폭이 과제 이름 길이에 따라 넘칠 수 있어 최대 셋 + `전체`
  • 가독성 — 칩 글자가 작다(실제 33 dp 이하). 운전석에서 가장 작은 터치 타깃이 늘어난다
  • 정직성 — "최근" 칩이 추천처럼 읽히지 않게 눈썹을 `최근 과제` 로 분명히. 시연 빌드는 시드 기록에 따라 칩이 달라져 녹화가 흔들릴 수 있다

시안 6

제목 속 밑줄 링크

제목 문장 자체에 과제 이름과 모드를 넣고, 두 낱말을 Periwinkle 밑줄 + `▼` 로 만들어 각각 누르면 바뀐다. 분류는 눈썹 `오늘의 과제 · 주차`.

표기눈썹 `오늘의 과제 · 주차` + 문장 "후면 직각 주차를 힌트 모드로"

장점

  • 가장 큰 글자(72 dp)가 곧 선택 상태 — 바꾸면 제목이 바뀌어 "실제로 바뀌었다" 가 가장 크게 보인다. 이름 줄 · 링크 줄이 둘 다 사라져 화면이 가장 단순하다
  • 과제 · 모드를 따로 누를 수 있어 모드만 바꾸기가 빠르다(모드 밑줄 = 세 칸 작은 팝업)

주의점

  • 구현 — 제목을 문장 틀 + 클릭 영역 둘로 쪼갠다. 지금 제목은 과제마다 손으로 쓴 문장("시동 켜기 전, 순서를 익혀 볼까요?")이라 그 맛이 사라진다. 긴 과제 이름(`장내기능 모의시험`)은 세 줄로 넘친다
  • 가독성 — 밑줄 글자가 버튼인지 첫눈에 덜 읽힌다(차 화면에서 텍스트 링크는 약한 신호). 터치 영역이 글자 높이뿐
  • 정직성 — 문제없음

시안 7

시작 알약 안에 과제

`시작` 알약이 두 줄이 되어 윗줄 `주차 · 힌트 모드`, 아랫줄 `후면 직각 주차 시작 →`. 바로 왼쪽(운전석 쪽)에 둥근 Lavender `⇄` 단추.

표기알약 윗줄 `주차 · 힌트 모드` / 아랫줄 `후면 직각 주차 시작`

장점

  • 누르는 순간 무엇이 시작되는지 손가락 아래에 적혀 있다 — 표시와 시작이 한 몸이라 "떨어짐" 이 없다
  • 바꾸기 단추가 알약의 운전석 쪽 끝에 붙어 시안 3 보다 손에 가깝다

주의점

  • 구현 — 알약 문구를 과제·모드로 조합(과제 이름 길이별 축소 규칙). 계측이 `시작` 문구를 찾는 곳이 있으면 문구 계약 변경 — 시트의 `시작` 과 문구가 달라진다
  • 가독성 — 알약 안 9 px 윗줄(실제 27 dp)은 Signal 위 흰 글자 대비가 약해 작아 보인다. 원형 아이콘만으로 "바꾸기" 가 덜 읽혀 아래 글자 라벨이 필요
  • 정직성 — 문제없음

시안 8 · 사용자 선택사항(큰 공수)

좌우 반전 — 운전석 쪽에 손잡이

글·버튼 열을 왼쪽(운전석에 가까운 쪽)으로, 일러스트를 오른쪽으로 뒤집는다. 과제 줄은 "이름 + 같은 줄 끝 `⇄ 바꾸기` 작은 알약" 으로 묶었다. `코치와 대화` 는 왼쪽 정렬.

표기주차 / 후면 직각 주차 · 힌트 모드

장점

  • 좌핸들 기준 운전석 팔이 덜 뻗는다 — `시작` 왼쪽 끝까지 실제 약 1300 dp 가까워진다. 글 읽는 시선도 왼쪽에서 시작
  • 과제 이름과 바꾸기가 같은 줄 — 묶임이 가장 단순한 형태(시안 1 · 3 과 조합 가능)

주의점

  • 구현 — 왼쪽 패널 + 오른쪽 열 구조가 앱 전 화면의 뼈대(홈 · 시트 · 코치 대화 · 브리핑 · 점검 · 회차 판정 · 리포트 · 프로필). 하나만 뒤집으면 화면을 넘길 때 열이 좌우로 튄다. 일러스트(차 방향 · 빛 방향)도 다시 그려야 자연스럽다. 캡처 · 계측 좌표 전면 갱신
  • 가독성 — 조수석 동승자(연수 강사 · 가족)는 오히려 멀어진다. 시연 녹화(10/7~8)와 겹친다
  • 정직성 — 영향 없음

공수 큼전 화면 레이아웃 반전 · 일러스트 좌우 · 캡처·계측 갱신 — 마감 전에는 권하지 않음(발표에서 "다음 단계" 로 언급)

시안 9

과제 묶음 패널

오른쪽 위 모서리를 자른 Lavender 면 하나에 눈썹 `오늘 할 과제` · Ink 분류 꼬리표 `주차` · 과제 이름 · 모드 세그먼트 · 이유 · `과제·모드 바꾸기 ›` 를 모두 넣는다. `시작` 은 패널 바로 아래.

표기Ink 꼬리표 `주차` + `후면 직각 주차` + 세그먼트 `힌트`

장점

  • "오늘 할 과제" 에 관한 모든 것이 한 면 안 — 묶임이 시각적으로 가장 강하다. 각진 면은 기하학 포스터 컨셉과 맞는다
  • 링크 글자는 남지만 패널 모서리에 붙어 "이 면을 바꾼다" 로 읽힌다. 모드는 세그먼트로 한 번 누름

주의점

  • 구현 — 패널 컴포저블 신규 + 시안 4 의 홈 세그먼트 상태 끌어올리기. 예약 카드가 있는 날은 패널 + 예약 카드가 겹쳐 높이가 모자람(예약 카드를 패널 안 한 줄로)
  • 가독성 — 패널 안 글자가 작다(이유 10 px · 링크 11 px). Lavender 면이 프로필 알약 · 코치 알약과 같은 색이라 "누르는 것" 과 "면" 의 구분이 약해질 수 있다
  • 정직성 — 문제없음

시안 10

코치 질문 + 두 답 알약

제목(코치의 질문)에 대한 대답처럼 같은 높이 알약 두 개를 나란히 — Signal `좋아요, 시작 →` 와 Lavender `⇄ 다른 걸로`. 이름 줄은 바로 위에 붙는다.

표기[주차] 후면 직각 주차 · 힌트 모드

장점

  • "화내지 않는 조수석" 대화 톤과 맞다 — 질문 → 예/아니오. 바꾸기가 `시작` 과 같은 높이로 올라와 존재감이 맞춰진다
  • 첫 실행이 깔끔하다 — 답이 "직접 / 코치와" 두 길로 바뀌어 아무 과제도 미리 정하지 않는다

주의점

  • 구현 — 알약 행 하나 + 문구. `시작` 문구가 `좋아요, 시작` 으로 바뀌어 시트의 `시작` 과 달라진다(계측 문구 계약 갱신)
  • 가독성 — `시작` 폭이 약 2/3 로 줄어 주 동작의 크기가 작아진다(그래도 실제 약 660 dp). 두 알약이 같은 높이라 첫 실행에서 어느 쪽이 주 동작인지 색으로만 갈린다
  • 정직성 — 제목이 과제와 맞지 않을 때(`다른 걸로` 로 점검을 고른 뒤 제목이 여전히 "주차부터") 어색해진다 — 제목도 선택된 과제를 따라 바뀌어야 한다

공수 작음알약 행 1개 · 링크 제거 · 첫 실행 두 답 · 제목이 선택 과제를 따르는지 확인

열 가지 비교

묶임 = 과제 표시와 바꾸기 손잡이가 붙어 있는 정도. 손 닿음 = 운전석(왼쪽)에서 바꾸기 손잡이까지. 공수는 마감 10/9 · 녹화 10/7~8 기준.

안묶임바꾸기의 무게모드만 바꾸기첫 실행손 닿음공수
1 과제 알약표시 = 손잡이알약(프로필과 같은 급)시트(두 번)빈 알약 + `과제 고르기 →`보통작음
2 과제 카드 + 단추한 카드둥근 단추시트빈 카드 `+`멂(오른쪽 끝)중간
3 분할 알약이름 줄 바로 아래`시작` 과 한 덩어리시트단일 `과제 고르기 →`멂(오른쪽 끝)작음
4 두 줄 선택기칸 = 손잡이칸 + 세그먼트한 번빈 칸 · 잠긴 세그먼트보통중간

7 시작 안에 과제시작 = 표시원형 단추시트단일 알약 두 줄가까움(알약 왼쪽)작음
8 좌우 반전같은 줄작은 알약시트단일 `과제 고르기 →`가장 가까움큼

시안 1 "과제 알약" + 첫 실행 `과제 고르기 →`

사용자가 직접 말한 "프로필 버튼처럼" 을 그대로 따르면서, 표시와 손잡이를 하나로 만들어 떨어짐 문제를 구조로 없앤다. 분류가 `주차 ›` 로 알약 맨 앞에 붙고, 시트에서 바꾸고 돌아오면 그 알약 글자가 바뀌어 "실제로 바뀌었다" 가 보인다. 바꿀 것이 알약 하나 · 링크 제거 · 첫 실행 분기뿐이라 녹화(10/7~8) 전 하루 안에 들어간다.

  1. Codex: 이름 줄을 과제 알약(높이 90 dp · Lavender · `주차 › 후면 직각 주차 · 힌트 모드 ›`)으로, 링크 `과제·모드 바꾸기` 제거, `코치와 대화` 는 줄 오른쪽 끝 그대로
  2. Claude: 첫 실행(기록 없음)에서 `ModeAdvisor` 가 과제를 미리 고르지 않는 상태 추가 — 홈은 빈 알약 + 주 알약 `과제 고르기 →`(시트 열기), 고른 뒤 `시작 →` 으로 복귀 · 계측 문구 계약 갱신
  3. 더 원하면(여유 있을 때): 시안 9 의 세그먼트만 가져와 알약 아래에 두면 "모드만 바꾸기" 가 한 번 누름이 된다(공수 중간). 시안 8 좌우 반전은 전 화면 공수가 커서 마감 뒤 / 발표의 "다음 단계" 로
