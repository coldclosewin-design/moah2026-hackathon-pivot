# 라운드 26 시안 — 공통 브리프 (2026-10-07)

사용자가 사내 에뮬에서 태그 `inhouse-20261006-6` / `-20261007-1` 을 직접 눌러 보고 준 앱 전반 피드백 중 **"시안을 보고 고르고 싶다"** 는 항목의 시안 페이지를 만든다.
각 페이지는 **정적 HTML 한 장**(외부 파일·폰트·스크립트 없이, 인라인 CSS/SVG 만 — `<script>` 금지, 보기 창이 스크립트를 돌리지 않는다), 브라우저 폭 1600px 에서 보기 좋게.
형식의 좋은 예: `docs/design/round25-proposals/1-coach-button.html`, `2-profile-eyebrow.html` — 먼저 하나를 읽고 같은 짜임으로.

## 앱의 디자인 언어 (반드시 지킨다 — 6번 다크 모드 페이지만 색 예외)

- 2560×1268 dp 가로 자동차 화면(실제 기기 2560×1440, 위아래 시스템 바). 시안은 화면을 **1/3 축소(853×423 px)** 하거나, 관련 부분만 같은 축척으로 잘라 보여 준다. "실제 화면은 약 3배" 를 페이지 위에 적는다.
- 색 토큰 다섯 개만: `--ink:#070827` `--paper:#FCFCFA` `--peri:#5B60A1`(Periwinkle) `--lav:#E5E6F0`(Lavender) `--signal:#F52D48`(빨강, 주 알약·선택 강조) + `--muted: rgba(7,8,39,.60)`. **새 색 금지.** 투명도 변형은 허용.
- 컨셉 = "기하학 포스터": 큰 면 분할(왼쪽 Ink 패널/일러스트 + 오른쪽 Paper), 각진 면, 둥근 알약 버튼, 굵은 글씨 대신 크기 대비(**Bold 금지** — font-weight 400/500 만, `<b>` 도 500).
- **이번 라운드 확정(사용자 10/7) — 시안에 이미 반영해서 그린다**:
  - 주 알약(Signal 빨강)은 **평면**(입체 질감·하이라이트 없음, 그림자도 아주 약하게 또는 없음). 높이 약 140 dp(1/3 ≈ 46px), 흰 글자 + `→`.
  - 보조 알약 = Lavender 채움, 높이 112 dp(1/3 ≈ 37px).
  - 코치 멘트는 **마침표마다 줄바꿈**, 짧게.
  - 홈 맨 아래 흐린 한 줄(지난 코치 말 "출발 전 점검부터 천천히 시작해 보실래요?")은 **없앤다**.
  - 프로필 알약은 지금보다 **얇게**, 항목 구분을 분명히: `연수생 · 장롱 10년차 · 목표: 아이 등하원 ›` 같은 식(콜론/구분점).
  - 과제 표기는 **분류가 보이게**: `주차 › 후면 직각 주차 · 가이드 모드` 류(정확한 표기법은 1번 페이지가 시안마다 하나씩 써 본다).
- 글자: 한국어. 눈썹 32 dp(Periwinkle 또는 Ink), 본문 40 dp, 제목 72 dp — 1/3 축소 시 약 11/13/24px.
- 운전자 화면 문장에는 숫자를 넣지 않는다(점수·횟수·초). 가이드 단계 `1/7`·계기 값(속도)은 허용.
- **주행 중(> 5 km/h) 화면에는 터치 타깃·점수가 없다**(절대 규칙 10). 홈·시트·코치 대화·브리핑·점검(정차)은 정차 화면.
- 폰트: `"Noto Sans KR","Malgun Gothic","Apple SD Gothic Neo",system-ui,sans-serif`.
- 바꾸지 않는 것: 분류 알약 트랙(주차·주행·점검·지식, 먹 선택), 과제 카드 C(그림 + 제목 + 난이도), 관리자 준비실 + 띠, 기하학 일러스트 스타일.

## 앱 사실 (시안이 틀리게 그리지 않도록)

- **홈(지금)**: 왼쪽 약 45% 차 일러스트(Paper 바탕), 오른쪽: 프로필 알약 `연수생 · 장롱 10년차 · 목표 아이 등하원 ›`(누르면 프로필 시트) → 제목 2줄(예: "시동 켜기 전,\n순서를 익혀 볼까요?") → `출발 전 점검 · 가이드 모드` → 이유 한 줄("처음은 제가 순서대로 함께할게요.") → (예약 있으면 예약 카드) → 주 알약 `시작 →`(지금은 입체 질감) → 아래 한 줄: 글자 링크 `과제·모드 바꾸기`(왼쪽) + 보조 알약 `🎤 코치와 대화`(오른쪽) → 맨 아래 흐린 지난 코치 말. 시연 빌드는 맨 아래 Ink 관리자 띠.
- **첫 실행**(기록 없음): 프로필 질문 화면 뒤 홈은 추천 규칙(`ModeAdvisor`)이 고른 과제를 미리 띄운다 — 지금은 `출발 전 점검 · 가이드 모드`. 사용자는 "처음엔 임의로 정하지 말고 실제 과제를 고르는 버튼" 을 원한다.
- **과제·모드 바꾸기** 를 누르면 오른쪽 열이 **과제 시트**로 바뀐다: 눈썹 `연습할 과제` → 분류 트랙(주차·주행·점검·지식) → `<분류> 세부 과제` → 과제 카드 네 칸(그림 + 이름 + 난이도 상/중/하, 선택 카드는 Periwinkle 면 + 빨간 체크) → 모드 트랙(가이드·힌트·평가 / 지식은 `지식 테스트` 한 칸) → 오른쪽 `제휴 시험장` 글자 링크 → `← 돌아가기` · `시작 →`. 과제 18개(주차 4 · 주행 5 + 장내기능 모의시험 · 점검 2 · 지식 6).
- 모드: 가이드 = 단계마다 말하고 확인(점검은 한 항목씩 `코치 1/7`) · 힌트 = 틀린 순간에만 말함 · 평가 = 조용히 채점. 홈 이유 줄 문구: 가이드 "처음은 제가 순서대로 함께할게요." / 힌트 "틀린 순간에만 말할게요." / 평가 "이번엔 조용히 지켜볼게요."
- **브리핑("운전대 화면")**: 시작을 누르면 약 2.5 초 — 왼쪽 Paper 위 눈썹 `연습 준비` → 제목 2줄(예: "문부터 지시등까지\n순서대로 볼게요.") → `출발 전 점검 · 가이드 모드` → 흐린 한 줄 → 아래 파형 아이콘 + "음성 안내 중", 오른쪽 Ink 면 위 큰 핸들 일러스트. TTS 가 "출발 전 점검, 가이드 모드. 제가 단계마다 말하고 확인할게요. 오늘은 … 봅니다." 를 읽는 동안 휙 지나간다. 사용자: 정체성이 불분명하고 지속 시간이 아쉽다.
- **출발 전 점검(정차, Maneuver 화면 checklist)**: 왼쪽 Ink 패널 — 위에 단계 막대(7칸), 항목 7줄 세로 목록(도어 열림/닫힘 · 안전벨트 채움 · 기어 P · 브레이크/시동 · 좌 지시등 · 우 지시등 · 비상등), 각 줄 오른쪽에 상태(빨강 = 아직/틀림, 흰색 = 됨), 맨 아래 흐린 눈썹 "출발 전 점검 · 확인 상태". 지금 할 항목은 줄 배경이 살짝 밝아지는 정도. 오른쪽 Paper: `출발 전 점검 · 1회차` · `0 km/h 실신호` · `코치 1/7` · 큰 지시문("운전석 문을 닫아 주세요.") · `다 됐어요 →`.
- 점검의 모드 차이(지금 코드): 가이드 = 한 항목씩 지시(`코치 n/7`)하고 되면 다음으로 · 힌트 = 지시 없이, 순서가 틀리거나 빠지면(예: 브레이크 없이 시동) 그때만 말함 · 평가 = 말 없이 끝에 판정. **그런데 왼쪽 목록이 세 모드 모두 똑같이 상태를 다 보여 줘서** 힌트·평가에서도 할 일이 다 보인다 → 사용자: "차이가 없는 듯".
- **코치 문장 출처**: 회차 멘트 = AI(사내 Copilot) 또는 규칙, "서두.\n조언." 두 문장 · 최대 90자 / 세션 총평(오늘의 기록 큰 글자) = 두 문장 최대 160자 / 홈 대화 = 한두 문장 최대 80자 / 가이드·힌트 = 규칙 문장(짧음). 실제 예: 총평 "오늘 첫 주행치고 훌륭했어요, 감각이 꽤 살아나고 있네요. 다음엔 후진 중 갑작스러운 속도 변화에 조금 더 신경 써 보세요." — 사용자: 길고 줄바꿈이 거슬린다, 코치처럼 짧게. 또 AI 가 "조금씩 감이 오시는 것 같아요" 같은 높임 오용을 낸다.
- 오늘의 기록(리포트): 왼쪽 Ink 패널 `연습한 회차 01 회` + `마지막 회차의 판정` 네 줄, 오른쪽 눈썹 `오늘의 기록` → 총평 큰 글자 → `후면 직각 주차 · 가이드` → `다시 시작 →`(지금 전체 폭) → `자세히 보기` `진단서` 링크 → 신호 출처.
