A1알약에서 피어남

오른쪽 위 ‘코치와 대화’ 알약의 테두리가 그대로 늘어나 흰 시트가 되고, 돌아가기를 누르면 시트가 같은 알약으로 접혀 들어간다.

장점
  • 누른 자리에서 시트가 나와 ‘어디서 왔는지’ 가 보인다
  • 돌아갈 때 같은 길로 되감겨 오가는 짝이 맞는다
  • 시트 모양·문구는 지금(21) 그대로
주의 · 공수 · 가독성 · 정직성
  • 공수 중간 — SharedTransitionLayout + sharedBounds(BOM 2024.12 에 있음, 실험 API opt-in). 반나절 안
  • 크기가 변하는 동안 시트 글자는 숨겼다가 마지막 220 ms 에 올린다(글자 찌그러짐 없음)
  • 정차 홈 전용 — 운전 중 규칙·정직성 영향 없음
공수 중간오가는 길 대칭시트 모양 유지
들어갈 때450 ms · 알약 → 시트(위치 · 크기 · 모서리 19→18) cubic-bezier(.2,0,0,1) · 테두리는 그림자로 바뀜
알약 글자는 0–40 ms 에 시트 바탕이 덮음 · 홈 글자 0–180 ms 사라짐 (.4,0,1,1) · 바탕 흰 → 회색 0–450 ms · 시트 글자 230–450 ms 위로 8 dp

A2바닥에서 올라오는 시트

홈은 그대로 두고 살짝 뒤로 물러나며(96 % · 어두운 막), 흰 시트가 바닥에서 올라와 덮는다. 돌아가면 아래로 내려간다.

장점
  • 공수 작음 — AnimatedVisibility(slideInVertically) + 막 fadeIn 뿐
  • 홈이 뒤에 비쳐 ‘잠깐 들른 대화’ 로 읽힌다
  • 라운드 27 문장 시트(C1 · 카드가 아래에서 올라와 겹침)와 같은 문법
주의 · 공수 · 가독성 · 정직성
  • 오른쪽 위 알약을 눌렀는데 아래에서 올라와 방향이 엇갈린다
  • 시트 높이가 지금 카드와 비슷해 ‘덮는다’ 느낌은 남는다(위 52 dp 만 홈이 비침)
  • 손잡이 막대는 표시만 — 끌어 내리기는 넣지 않는다(공수)
공수 작음C1 과 같은 문법방향은 엇갈림
들어갈 때420 ms · 스프링 dampingRatio .85 · stiffness 400 (≈ cubic-bezier(.2,.8,.2,1)) · 막 0 → 34 % · 홈 크기 1 → .965
돌아갈 때300 ms cubic-bezier(.4,0,1,1) · 시트 아래로 · 막·홈 크기 (.4,0,.2,1) 로 되돌림

A3홈 문장이 말풍선으로

홈의 큰 질문 문장이 줄어들며 코치 말풍선 자리로 옮겨 가 말풍선 첫 줄과 교차한다. 말풍선 바탕은 문장 크기에서 줄어든다.

장점
  • ‘홈 문장 = 코치가 건넨 말’ 이라는 걸 움직임이 설명한다
  • 대화가 이어지는 느낌이 다섯 안 중 가장 강하다
  • 시연 영상에서 가장 눈에 띈다
주의 · 공수 · 가독성 · 정직성
  • 공수 중간~큼 — 두 글자 자리 측정(onGloballyPositioned) + graphicsLayer 이동·크기 + 글자 교차, 돌아갈 때 거꾸로
  • 홈 문장과 말풍선 문장이 다르다 — 섞이는 순간(180–330 ms)을 짧게 해 ‘같은 말’ 로 오해하지 않게
  • 알약은 위에 그대로(지금과 같음)
