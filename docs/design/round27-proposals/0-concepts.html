추천 — 06 하이브리드, 단 내일은 1단계만

왜 06 인가

  • 사용자 지시 1~9 가 각각 자리를 얻는 유일한 안 — 홈=레퍼런스 1, 톤=Onyx/Platinum, 고르기=레퍼런스 3, 결과서=레퍼런스 4, 차=핀 C
  • 01(흰 벽)과 결과가 거의 같아서, 1단계만 해도 이미 "새 컨셉" 으로 보인다
  • 밤 시연이 걱정되면 02 를 같은 토큰 표의 어두운 판으로 갈아 끼우면 된다

공수 — 마감 10/9 기준

  • 1단계 · 작음(반나절) — CoachColors 토큰 값 교체(Ink→Onyx, Paper→White, Periwinkle→Graphite, Lavender→#F0F0F0, 주 버튼 Signal→Onyx), 홈 그림 → 흰 바탕 + 가는 선 + ↗
  • 2단계 · 중간 — 주 버튼 한 부품에 핀 A 차오름, 선택 칩에 검은 입체 Modifier
  • 3단계 · 큼(마감 뒤) — 점 격자 차(Canvas), 쌓이는 카드, 기호 타일 애니메이션

지켜야 할 것

  • Signal 을 버튼에서 빼면 "빨강 = 위험" 하나만 남는다 — 경고 문장·급제동 표시는 계속 빨강
  • 정직성 배지: 채움(실신호) · 테두리(시뮬레이션) · 점선(미측정) — 색 없이 모양으로
  • 주행 중 잠금 화면엔 움직이는 점·숫자 없이 한 면 + 문장
