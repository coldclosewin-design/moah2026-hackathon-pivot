H1

거대한 질문

제목 두 줄이 곧 "LET'S TALK". 레퍼런스 1 을 가장 곧이곧대로 옮긴 안 — 그림을 빼고 흰 벽에 질문만 건다.

배치

  • 왼쪽 위 워드마크 · 오른쪽 위 "코치와 대화" + 가는 마이크(레퍼런스의 MENU + 자리)
  • 오른쪽 정보 블록 = 프로필·이유(작은 굵은 라벨 + 본문)
  • 가는 선 아래 오른쪽에 검은 시작 알약, ↗ 은 제목 끝 장식

장점

  • 지금 홈과 요소가 1:1 — 그림 패널만 빼면 된다
  • 제목 46px(실제 138dp) — 운전석에서 가장 잘 읽힘

주의

  • 코치와 대화가 작아 보임 → 누르는 영역은 120dp 높이 유지
  • ↗ 이 버튼처럼 보일 수 있음 — 누르면 시작해도 되게 같은 동작을 건다

H2

시작해 볼까요

거대한 한 줄이 한국어 "시작해 볼까요" 이고, 줄 전체가 시작 버튼. 과제·모드는 오른쪽 위 정보 블록으로 올라간다.

배치

  • 정보 블록 두 칸: 오늘의 과제(밑줄 링크) · 프로필
  • 거대한 줄 + ↗ + 굵은 선 = 한 덩어리 버튼(빨간 점선)
  • 그 위 작은 줄 = 이유(레퍼런스의 "Got A Project In Mind?")

장점

  • 레퍼런스 1 인상이 가장 강함. "무엇을 누르면 되나" 가 화면 전체로 답해짐

주의

  • 문구 변경 — 제목 한 문장이 "과제·모드" 블록과 "시작해 볼까요" 로 나뉜다. 접근성 이름(과제·모드 바꾸기 / 시작)은 유지
  • 과제 링크가 15px(실제 45dp)로 작아짐 — 누르는 높이 112dp 확보 필요
  • 첫 실행: 거대한 줄이 흐려져 "꺼짐" 을 보여 줘야 함

과제 이름이 주인공

거대한 글자 = 오늘 연습할 과제 이름 그 자체. 굵은 밑줄 하나로 "눌러서 바꿀 수 있다" 를 말한다.

배치

  • 과제 이름 100px(실제 300dp) + 5px 밑줄 = 과제 바꾸기
  • 아래 30px 문장에 모드 링크 · 이유 · 가는 선 · 시작/대화

장점

  • "오늘 무엇을 하나" 가 한눈에 — 과제 중심 앱이라는 제품 이야기와 맞음
  • 문구 그대로(한 문장이 두 크기로 나뉠 뿐)

주의

  • 과제 이름이 길면 한 줄에 안 들어감 → 글자 크기 자동 축소 규칙 필요
  • 문장 시작이 "를" 이라 어색할 수 있음 — 문법 조사 처리 확인

점 격자 차가 주인공

지금 홈의 왼쪽 일러스트 자리를 하프톤 점 격자 차(핀 C)로. 점이 커졌다 작아지며 차가 지나간다 — 미등만 빨간 점 몇 개.

배치

  • 왼쪽 절반 = 점 격자 차(살아 움직임), 오른쪽 = 지금과 같은 글 블록
  • 도로 점선도 점으로, 뒤로 옅어지는 점 꼬리

장점

  • 지금 레이아웃 그대로 — 그림만 교체. 발표 영상에서 "움직이는 정체성"
  • 정지 화면에서도 하프톤 질감이 남는다

주의

  • Canvas 로 점을 매 프레임 그려야 함(가장 큰 공수). 마감엔 정지 프레임 한 장 이미지로 대체 가능(작음)
  • 홈은 정차 화면이라 움직여도 규칙 위반 아님. 주행 중 화면엔 금지

카드 대시보드

레퍼런스 3·6 의 문법 — 연회색 그라데이션 위 흰 둥근 카드, 시작만 검은 입체 큰 카드(대시보드의 검은 강조 카드 자리).

배치

  • 왼쪽 큰 흰 카드 = 질문, 오른쪽 검은 입체 카드 = 시작(카드 전체가 버튼, ↗ 포함)
  • 아래 줄 흰 카드 둘 = 프로필 · 코치와 대화

장점

  • 누를 곳이 "검은 덩어리 하나" — 운전석 거리에서도 오해 없음
  • 시작 카드에 과제·모드 요약이 다시 적혀 확인 효과

주의

  • 레퍼런스 1 의 "흰 벽 + 거대 글자" 느낌은 약해짐
  • 그림자·그라데이션 공통 Modifier 필요. 첫 실행엔 검은 카드가 납작 회색으로 바뀌어야 함

종이 포스터 03

레퍼런스 5 를 밝은 종이로 — 거대한 회차 번호가 오른쪽 아래로 잘려 나가고, 가는 둥근 테두리와 원 궤도, 옅은 종이 질감.

배치

  • "03" = 이번이 몇 번째 연습인지(회차 메타 — 숫자 허용 범위)
  • 왼쪽 열에 프로필·질문·시작·대화. 시작만 Signal(포스터의 빨간 도장)

  • 회차가 쌓이는 게 홈에서 바로 보임 — "진단 리포트로 쌓인다" 는 제품 이야기와 연결
  • 리포트 화면(왼쪽 큰 02)과 한 가족

주의

  • 숫자가 운전자 "문장" 은 아니지만 홈에 큰 숫자 — 규칙 예외 설명 필요
  • 종이 질감 이미지 한 장 + 숫자 잘림 처리. 글 열이 좁아 제목 34px 로 줄어듦

↗ 이 곧 시작

레퍼런스 1 의 큰 ↗ 를 진짜 시작 버튼으로. 누르면 검은 원이 ↗ 자리에서 피어나 왼쪽으로 번지며 "시작" 까지 덮고, ↗ 는 → 로 눕는다(핀 A). 왼쪽 화면은 실제로 움직인다.

배치

  • 오른쪽 아래 100px(실제 300dp) 원 + ↗ · 왼쪽에 "시작" 40px — 둘을 감싼 알약 전체가 누르는 영역
  • 코치와 대화는 오른쪽 위(MENU + 자리), 프로필은 정보 블록

장점

  • 장식(↗)과 기능(시작)이 하나 — 레퍼런스 인상 + 분명한 행동
  • 핀 A 를 가장 크게 보여 주는 자리라 발표 영상에서 눈에 띔

주의

  • 쉬는 상태가 "테두리 원" 이라 첫눈에 버튼인지 덜 분명 — 원 안을 옅은 Platinum 으로 채우는 변형 가능
  • 애니메이션 220~320ms 안으로(누른 뒤 화면 전환이 늦어지면 안 됨)

H8 프레임 띠위 화면의 CSS 애니메이션을 0 · 1/3 · 2/3 · 끝 으로 멈춘 것(PNG 용). 실제 길이 280ms, 놓으면 거꾸로.

끝 — 알약 전체 검정, 글자 반전, ↗→ (놓으면 거꾸로)

추천 — H1 을 바탕으로, 시작 버튼만 H8 의 움직임

왜

  • H1 은 지금 홈과 요소가 1:1 이라 그림 패널만 빼고 토큰을 바꾸면 끝 — 마감 내일에 가장 안전
  • 레퍼런스 1 의 인상(흰 벽 · 거대한 두 줄 · 가는 선 · ↗ · 작은 워드마크 · 오른쪽 위 정보 블록)을 다 갖는다
  • H8 의 "↗ → 검게 피어나는 시작" 은 H1 의 시작 알약에 핀 A 로 얹으면 된다(시간 나면)
  • 밤 시연이면 H4 = 같은 배치의 토큰 반전

공수(마감 10/9)

H1 거대한 질문작음
H2 시작해 볼까요중간(문구 분리)
H3 과제 이름이 주인공작음~중간
H4 Onyx 밤작음
H5 점 격자 차큼 · 정지 이미지면 작음

H7 종이 포스터중간

그대로 지킬 것

  • 제목 속 과제·모드 밑줄 = 과제·모드 바꾸기(접근성 이름 유지)
  • 시작 112~140dp, 코치와 대화도 누르는 높이 112dp 이상(작게 보여도)
  • 첫 실행 = "처음 오셨네요 / 과제 고르기 ▾ 부터" + 꺼진 시작 — 꺼짐은 색이 아니라 점선·흐림으로
  • 홈은 정차 화면 — 움직임 허용, 주행 중 잠금 화면은 별개
