# 라운드 27 시안 — 새 디자인 컨셉(기능 그대로, 생김새만) 공통 브리프 (2026-10-08)

사용자가 **앱 전체 디자인 컨셉을 바꾸고 싶다**며 레퍼런스를 줬다. 기능·흐름·문구 규칙은 그대로, **색·형태·글자·구성·움직임**만 새로 잡는다.
"전문가로서 페이지 및 기호/버튼 등 5~10개 이상의 안을 제시하면서 함께 확립" — 사용자는 시안을 보고 고르거나 섞는다.

## 형식 (지난 라운드와 같다)

- 각 페이지 = **정적 HTML 한 장**(외부 파일·웹폰트·`<script>` 없이, 인라인 CSS/SVG 만). **CSS 애니메이션(@keyframes)은 허용** — 움직임 시안은 실제로 움직이게. 대신 PNG 로는 안 보이니 **같은 움직임을 프레임 띠(0 / 1/3 / 2/3 / 끝)로도** 그려 둔다.
- 폭 1600px 에서 보기 좋게. 화면 목업은 2560×1268 dp 자동차 화면을 **1/3 축소(853×423)**, "실제 화면은 약 3배" 를 위에 적는다.
- 칸마다 **이름(짧은 컨셉) · 한 줄 설명 · 장점 · 주의점(구현 공수 · 운전 중 가독성 · 정직성)**. 맨 아래 **추천 + 공수(작음/중간/큼)**. 마감 **10/9(내일)** — 공수가 중요하다.
- 시안끼리 같은 데이터(같은 문구)를 써서 차이가 형태로만 보이게.
- 파일: `docs/design/round27-proposals/<번호>-<주제>.html` + 같은 이름 `.png`(headless Edge 폭 1600, 페이지 길이만큼):
  `"/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --headless=new --disable-gpu --hide-scrollbars --user-data-dir="<스크래치 아래 새 폴더>" --window-size=1600,<H> --screenshot="<절대 경로>.png" "file:///<절대 경로>.html" 2>&1 | tail -1`
  명령 하나씩, 몇 초 뒤 파일 확인 → Read 로 보고 넘침·겹침·깨진 글자 고쳐 다시. 셸은 Git Bash — 한국어는 heredoc 말고 Write 도구로. **커밋·브랜치 변경 금지.**
- **레퍼런스 사진(아래)은 보기만 한다 — 저장소에 복사·커밋·페이지에 삽입 금지**(남의 작업물). 브랜드 이름(spline·WeTransfer·Skillset 등)도 페이지에 쓰지 않는다 — "레퍼런스 1(큰 글자 홈)" 처럼만.

3. **UI 컨셉 = 레퍼런스 3 톤**: 연회색 그라데이션 바탕 위 **흰 둥근 카드(트랙)**, 선택된 것만 **검은 입체 알약/둥근 사각**(위가 살짝 밝은 그라데이션 + 아래로 부드럽고 깊은 그림자), 안 고른 것은 **연회색 납작 칩** + 회색 글자. 체크·페이지 번호·보기 전환 토글 모두 같은 문법.
4. **전반 애니메이션** = 핀 A(버튼): 테두리만 있는 알약 `→ 이름` 에서, 누르면/선택되면 **왼쪽 화살표 원이 커지며 검은 면이 알약 전체를 채운다**(글자는 흰색으로 반전), 놓으면 되돌아간다. 부드럽고 짧게.
5. **통계·종합 결과서**(오늘의 기록 · 자세히 보기 · 진단서 · 시험 결과) = 레퍼런스 4: 검은 바탕 · **테두리만 있는 큰 알약 안에 거대한 숫자 + 아래 작은 대문자 라벨** 2×2 · 아래 작은 글자 단·표(나라별 % 같은 촘촘한 표).
6. **정보가 많은 페이지**(과제 시트 · 시험장 · 자세히 보기 · 진단서 · 지식 해설) = 핀 B: 흰 카드가 **아래에서 올라와 앞 카드 위에 겹쳐 쌓이는** 구성, 큰 문장 안에 회색으로 약하게 한 낱말 + 문장 속 작은 아이콘 알약(노란 원 안 막대 기호 같은 것), 둥근 큰 카드.
7. **자동차·움직이는 것** = 핀 C: **크기가 다른 점의 격자(하프톤 도트 매트릭스)** 로 그린 움직이는 형체(점들이 커졌다 작아지며 달리는 모습). 지금 앱의 차 그림(위에서 본 차 · 주차 궤적 · 코스 지도 위 차 · 홈 일러스트)을 이 문법으로.
8. **기호 애니메이션** = 핀 D: 어두운 둥근 사각 타일 안의 흰 단색 기호 — 원 진행(로딩) · 점 셋 · 퍼지는 원 · 튀는 공 · 시계 · 와이파이 막대 · 선 아이콘이 그려지는 효과. 앱의 기호(음성 안내 중 · 신호 상태 · 체크 · 마이크 · 진행 · 잠금 등)를 이 문법으로.
9. 나머지(레퍼런스 5 = 어두운 판 위 거대한 숫자 "01" + 작은 대문자 · 가는 둥근 테두리 · 오래된 종이 질감 / 레퍼런스 6 = 연회색 대시보드 · 흰 둥근 카드 · 검은 강조 카드 · 둥근 기간 칩 · 막대 그래프 검은 둥근 막대)는 선호하는 타입.
