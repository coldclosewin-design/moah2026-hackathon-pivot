4 · 정보가 많은 화면 — 아래에서 올라와 겹쳐 쌓이는 흰 카드, 여섯 가지

핀 B 문법: 흰 둥근 카드가 아래에서 올라와 앞 카드 위에 겹쳐 쌓인다(앞 카드는 살짝 작아지며 위쪽 띠만 남는다) · 큰 문장 안에 회색으로 약한 낱말 하나 · 문장 속 작은 아이콘 알약 힌트 · 큰 둥근 모서리. 레퍼런스 3 문법(흰 트랙 위 검은 입체 알약 = 선택, 연회색 납작 칩 = 안 고른 것)을 그대로 얹었다.

화면 목업 = 2560×1268 dp 의 1/3 (853×423) · 실제 화면은 약 3배 프레임 띠 = 0 · 1/3 · 2/3 · 끝 (작게) · 같은 움직임의 실시간 판은 @keyframes 로 함께 숫자·영문: Segoe UI Variable Display / Bahnschrift 흉내 — 앱 글꼴 후보 Roboto Flex 또는 OFL 그로테스크
강조색 정책 (이 페이지 공통)무채색 + 작은 노란 원 하나(아이콘 알약 속 #F2C230). 노란 원 = "모드 막대"(가이드 막대 셋 · 힌트 둘 · 평가 하나)와 해설 기호에만. Signal 은 점검의 "틀림" 상태에만.
쌓임 규칙새 카드 = 아래에서 올라옴(220 ms, ease-out) · 앞 카드 = 96.5% 로 줄며 위 띠 40–50 px(실제 120–150 dp)만 남김 · 남은 띠는 누르면 그 카드로 되돌아감(접근성 이름 유지).

정직성시험장 = "예시 — 실제 예약 연계 없음", 점검 = 신호마다 실신호 · 시뮬레이션 · 미측정 모양 점. 카드 문법이 바뀌어도 줄지 않게 각 카드 머리에 둔다.

장점

  • "한 가지씩" 이 형태로 보인다 — 지금 할 카드 하나만 크고, 끝낸 것·남은 것은 띠. 라운드 26 의 "지금 줄 확대" 와 같은 생각을 카드 더미로.
  • 신호 출처가 카드 머리마다(반 찬 점 = 시뮬레이션, 점선 = 미측정) — 항목별 정직성이 가장 촘촘.
  • 모드 차이가 카드 앞·뒷면으로 크게 갈린다(아래 띠).

주의점

  • 공수 중간 — 카드 더미 레이아웃 + 지금 항목이 바뀔 때 위로 밀리는 움직임. 상태기계 변경 없음(지금 항목 = 기존 preDrive 인덱스).
  • 위·아래 띠 글자 12px(36 dp) — 정차 화면이라 허용하나 40 dp 아래. 띠는 "있다" 만 보이면 되고, 읽을 건 큰 카드뿐.
  • Signal 을 "틀림" 칩 하나에만 남김(경고 = 유일한 색). 평가 모드에선 이 색도 숨긴다.

굵기: 큰 문장·지금 카드 이름 Medium, 띠 Regular.

장점

  • 공수 작음 — Compose ModalBottomSheet 한 겹 + 지금 시트 내용 그대로 + 토큰 교체. 시험장 시트는 같은 컴포넌트 두 번째 호출.
  • 계측 테스트·대본이 찾는 버튼 이름(시작 · 돌아가기 · 제휴 시험장)이 그대로.
  • 핀 B 의 "아래에서 올라와 겹친다" 를 가장 흔한 안드로이드 문법으로 — 학습 비용 0.

주의점

  • 핀 B 의 "여러 장이 계단처럼 쌓인 모양" 은 두 겹까지만 — 인상은 1안보다 약하다.
  • 시트 손잡이 끌어내리기(드래그 닫기)는 주행 중 의도치 않게 닫힐 일 없게 정차 중에만 — 5 km/h 넘으면 시트 자체를 닫고 잠금 화면.
  • 버튼 높이 42px(126 dp) · 트랙 30px(90 dp) — 트랙만 36px 로 올릴 것.

굵기: 시트 제목 Medium, 나머지 Regular.

안적용 화면핀 B 느낌한 번에 보이는 선택지정직성 위치버튼 이름 유지공수
1 쌓이는 시트과제 시트가장 강함단계별 하나—예중간~큼
2 문장 시트과제 시트강함(문장)0 (바꿀 때만)—예 + 낱말 버튼중간
3 겹친 덱제휴 시험장강함앞 한 장왼쪽 칩예중간
4 해설 카드지식 퀴즈보통보기 넷—예작음~중간
5 점검 카드 더미출발 전 점검강함지금 하나카드마다예중간
6 바닥 시트 한 장과제 시트 · 시험장약함(두 겹)지금과 같음시험장 칩그대로작음

추천 · RECOMMENDATION 공수 작음 (+ 시간 남으면 작음~중간 하나)

6 바닥 시트 한 장을 기준으로, 시트 제목만 2 의 문장 문법 · 시간이 남으면 4 의 해설 카드 하나 더.

마감이 내일이다. 6은 화면 구성·버튼 이름·계측 테스트를 건드리지 않고 "흰 카드가 아래에서 올라와 겹친다" 를 ModalBottomSheet 한 컴포넌트로 들여온다 — 과제 시트 위에 시험장 시트가 한 겹 더 쌓이는 장면(프레임 띠 끝)이 핀 B 를 가장 싸게 보여 준다. 시트 제목을 "오늘은 무엇을 연습할까요?" 처럼 회색 낱말 하나 + 모드 설명 앞 노란 아이콘 알약으로 바꾸는 것(2의 문법)은 문자열·작은 컴포저블 하나다. 4의 해설 카드는 퀴즈 화면 한 곳의 slideIn 하나라 여유분으로 좋다. 1·3·5는 상태·애니메이션 작업이 커서 마감 뒤 다음 버전 후보로 남긴다.

  1. Claude: 색 토큰(White 카드 · Chip #F1F1F1 · Jet 입체 · Yellow #F2C230 은 아이콘 알약에만) + 쌓임 규칙(최대 두 겹, 5 km/h 넘으면 모두 닫힘)을 docs/design/ 계약에 기록
  2. Codex: 과제 시트·제휴 시험장을 바닥 시트로 · 선택 = 검은 입체 알약 · 안 고른 것 = 납작 칩 · 시트 제목 회색 낱말 + 아이콘 알약 — 공수 작음
  3. 시간이 남으면 Codex: 퀴즈 보기 2×2 + 해설 카드 올라오기 — 공수 작음~중간
