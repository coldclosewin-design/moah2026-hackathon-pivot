검은 돌 알약 — 레퍼런스 3 그대로공수 중간

연회색 그라데이션 바탕 · 흰 둥근 트랙 · 고른 것만 위가 밝은 검은 입체 알약, 안 고른 것은 회색 글자 또는 연회색 납작 칩.

장점

  • 고른 것 하나만 깊이가 있어 운전석 거리에서도 “어느 것이 켜졌나” 가 색이 아니라 형태로 읽힌다.
  • 버튼 · 트랙 · 체크 · 단계 번호 · 말 칩이 모두 같은 알약 하나라 부품 수가 준다(SoftPill 하나 재사용).

주의점 — 공수 · 운전 중 가독성 · 정직성

  • 공수 중간 — 세로 그라데이션 Brush + 그림자 2겹 + 위 1 px 하이라이트를 한 컴포저블로. 나머지는 토큰 교체.
  • 가독성 — 흰 트랙 위 회색 글자는 햇빛에 약하다 → 안 고른 글자 #6E6E6E 이상 · 본문 40 dp 유지.
  • 정직성 — 배지는 색 대신 ● ◐ ○ 모양이라 무채색에서도 그대로 읽힌다.

테두리 알약 — 레퍼런스 2공수 작음~중간

Platinum 단색 바탕 위 모든 것이 1.2 px Onyx 테두리 알약, 고르면 속이 채워진다. 시작 버튼은 왼쪽 원 화살표(핀 A 의 정지 모양).

장점

  • 핀 A(원이 커지며 채움) 움직임과 가장 자연스럽게 이어진다 — 정지 · 누름 · 고름이 같은 ‘채움’ 문법.
  • 그림자 0 이라 구현 · 성능 모두 가볍고 화면이 인쇄물처럼 단정하다.

주의점 — 공수 · 운전 중 가독성 · 정직성

  • 공수 작음~중간 — BorderStroke + 원 화살표 하나.
  • 가독성 — 시안의 1.2 px 은 실제 3.6 dp, 햇빛에선 얇다 → 실제 2 dp 이상 · 안 고른 글자도 Onyx. 주 행동과 안 고른 칩이 같은 ‘테두리’ 라 위계가 약해 시작만 원 화살표로 가른다.
  • 정직성 — 같다. 미측정 점선 표식이 테두리 문법과 잘 맞는다.
