옆모습 · 위에서 본 차 모두 G7 유리만 Onyx — 지도 표식만 G2 처럼 굵게

V4 의 '같은 굵기 선' 을 그대로 두고 한 곳만 채운다. 쉬는 상태는 테두리, 자리를 잡으면 채워진다 — 컨셉 01 의 알약이 눌리면 검게 채워지는 것과 같은 말이다. 고른 과제 카드(Onyx)에서는 선이 흰색이 되고 지붕 면도 흰색이 되어, 카드 전체가 '눌린 알약' 처럼 뒤집힌다. 작은 자리에서는 검은 지붕 한 덩어리가 위치 · 방향을 먼저 알려 주므로 선만인 안(G1 · G2 · G10)보다 운전석 거리에서 강하다.

1단계 · 작음 (1 h)vehicleSilhouette(body, panel, glass) 시그니처 그대로 — 몸은 drawRoundRect(Stroke), 지붕은 drawRoundRect(Fill = glass), 앞 선 drawLine. 약 25줄. 과제 카드 · 궤적 · 지도 · 주차 중 도식 네 곳이 같이 바뀌고 호출부는 색 값만.
2단계 · 작음 (30 min)지도 표식처럼 작게 그릴 땐 선 굵기를 배율로 줄이지 않고 카드와 같은 굵기로 고정(G2 의 장점만 가져온다 — 0.62배에서도 선이 가늘어지지 않게). 궤적 · 지도 선은 Onyx · Ash 토큰, 진행 꺾쇠 Signal → Onyx.
3단계 · 작음–중간홈 옆모습 G7 을 Canvas 하나로(둥근 사각 · 사다리꼴 · 원) + Animatable 900 ms 구르기, 바퀴 각 = 이동 ÷ 반지름, 멈추면 유리 300 ms 채움. 브리핑 핸들은 G7 핸들 webp 교체(코드 0줄).
섞는다면홈 옆모습만 G3 알약(더 부드럽고 P2 알약과 같은 모양) + 위에서 본 차 G7. 시간이 모자라면 위에서 본 차 G10(2줄) + 홈 정지 그림. 가독성만 보면 G9 가 1등이지만 선 문법을 잃는다.
