# 라운드 8 영상 피드백 → 반영 계획 (2026-09-28, 라운드 8)

사용자가 라운드 8 재녹화(`main = 012702c`, `build/demo-round8.mp4` 173 s — 예약 배지 상태로 시작)를 보고 준 피드백 3건. 형식은 `03`~`05` 와 같다. 원문은 하단.

## 0. 성격

셋 다 **화면**이다. ① 시트의 과제 칸 모양(테두리 → 면 카드) ② Setup → 시트 전환의 일러스트 모핑 ③ Done 추정 궤적이 "주차에서 빠져나가는 모습"으로 읽힘 — **두 번째 지적**(라운드 4 에서 같은 말, 라운드 5 에서 "뒤가 위" 로 180° 회전). 이번엔 사용자가 해법까지 지정했다("역재생"). ③은 물리적 시간 순서와 부딪히므로 **결정 D1** 로 두 안을 놓고 묻는다(§2).

## 2. 결정이 필요한 것

### 2.1 Done 추정 궤적 (D1)

사실: 궤적은 신호(속도·기어·조향각)로 **시간 순서대로** 추정한 것이고, 라운드 5 부터 Maneuver 와 같은 "뒤가 위" 관습이다. 못한 주차의 도착 자세가 45~60° 밖에 안 돌아간 것(4구간·보정)도 "덜 들어간" 것처럼 보이는 데 한몫한다.

| 안 | 무엇 | 장점 | 단점 |
|---|---|---|---|
| **(가) 역재생** (사용자 지정) | 재생을 도착 → 시작으로: `pathThroughTime(path, total − t)` 로 뒤집고, 실차는 남은 궤적의 끝(= 시간상 앞)에서 시작해 `Lavender` 윤곽(시작 자세)에 **들어가며** 끝난다. 후진 셰브론·급정지 점은 지금 그대로(지점 기준) | 지금 그림 그대로 한 줄 바꿈. 사용자가 원하는 "들어가는" 느낌 | **시간이 거꾸로** — 화면 아래 "신호로 추정한 궤적" 문장과 어긋난다. 후진 구간이 전진처럼, 전진 보정이 후진처럼 보인다. 급정지 점이 "출발 직후"에 찍힌다. 3 s 재생을 두 번 보면 들통난다 |
| **(나) 도착 칸** (추천) | 시간 순서는 그대로 두고 **읽히는 것**을 바꾼다: 시작 윤곽(`Lavender` 직사각형)을 **없애고**, 도착 자세(`Ink` 실차)를 둘러싼 **주차 칸**(라운드 6 과제 칸과 같은 U자 두 줄, `Periwinkle` 4 dp)을 처음부터 그린다 → 차가 빈 칸으로 **들어가며** 끝난다. 시작점은 작은 `Lavender` 점 하나 | 정직(시간·물리 그대로). 못한 주차에서도 "칸에 비스듬히 들어감"으로 읽힌다 — 리포트 문장과도 맞는다 | 칸 폭·깊이는 차 크기 기준 가정(차 폭 × 1.25, 길이 × 1.15). 그림이 조금 바뀌어 캡처·계측 픽셀 검사 갱신 |

권장: **(나)**. 이유 — 이 앱의 약속은 "카메라 없이 **과정**을 정직하게 잰다" 이고, 덱 마지막 줄이 "칸에 반듯이 들어갔는지는 모릅니다" 이다. 시간을 뒤집으면 그 문장과 화면이 서로 다른 말을 한다. (가) 를 고르면 그대로 만든다(발주서 §3 에 두 안 다 규격이 있다).
