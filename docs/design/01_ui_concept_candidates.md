# UI 컨셉 후보 (2026-09-18)

> **17번(피벗) 저장소 주석**: 이 문서는 Gift Drive 시절 기록이다. 20개 후보 중 선물 은유(2·18·19)를 뺀 나머지 스킨·레이아웃과, 문서 끝의 **"핸드오프에서 배운 규칙"** 은 운전 연수 화면에도 그대로 쓸 수 있어 남겨 두었다. d-road 선정 결과·컨셉 경쟁 기구(`-PuiConcept`)는 이번 아이템에서 쓰지 않는다(`NEXT.md` 미루는 항목).

현재 디자인(classic) 외의 컨셉을 Codex 로 시험하기 위한 후보 목록. **핵심 2화면(주행·도착)만 먼저** 만들어 스크린샷으로 비교하고, 고른 하나만 5화면으로 완성한다. 진행 방식·보존 장치는 이 문서 끝.

## 후보 20개

### 스킨형 — 색·글꼴·형태만 바꿈

1. **편지지** — 크림색 종이 질감, 손글씨풍 제목. 지인의 메모가 주인공. 도착 화면이 봉투가 열린 느낌
2. **선물 포장** — 짙은 남색 + 금색 리본 선. 카드가 리본으로 묶여 있다가 공개 때 풀리는 구도
3. **심야 라디오** — 검정 + 호박색 단색. 자막 패널이 라디오 주파수 창, 음성 안내가 DJ 멘트
4. **새벽 안개** — 회청색 그라데이션, 얇은 선, 넓은 여백. 가장 차분함
5. **네온 시티** — 어두운 보라 + 청록/분홍 발광선. 시연 영상에서 가장 눈에 띔
6. **계기판 순정** — 완성차 계기판 같은 무채색 + 포인트 색 하나. "양산 가능해 보인다"
7. **필름 카메라** — 따뜻한 갈색 톤, 사진 테두리, 날짜 스탬프 글꼴. 메모리 카드가 인화 사진
8. **한지·먹** — 미색 바탕, 먹색 굵은 제목, 붉은 낙관 포인트. 아빠의 두부집 코스와 어울림

### 레이아웃형 — 화면 구성을 새로 짬

9. **한 단어 주행** — 주행 화면에 속도와 단어 하나만 초대형. 진행·힌트·주문은 하단 얇은 한 줄
10. **길 위의 점** — 화면 가로 전체가 길 한 줄. 차가 왼→오로 움직이고 힌트·주문 상태가 길 위에 찍힘. 목적지 점은 물음표
11. **나침표** — 중앙 큰 원형 나침. (제약: `JourneyPhase` 에 방위각이 없어 장식용 연출만 가능)
12. **자막 극장** — 위아래 검은 띠, 음성 문장이 중앙에 크게, 속도는 구석에 작게
13. **카드 덱** — 도착 화면의 메모·쿠폰·예약·산책을 겹친 카드 더미로. 맨 위 카드만 크게
14. **엽서 한 장** — 도착 화면 전체가 엽서. 왼쪽 메모, 오른쪽 우표(쿠폰)·소인(날짜·장소)·주소란(다음 장소)
15. **타임라인 여권** — 코스 전체를 타임라인에 스탬프로. 도착할 때마다 도장
16. **분할 콕핏** — 좌 1/3 고정(속도·잠금·주문) / 우 2/3 단계별 내용. 단계가 바뀌어도 시선이 안 흔들림
17. **풀스크린 타이포** — 아이콘·카드 없이 초대형 글자만. 도착 화면은 메모 문장이 화면을 채움
18. **선물 상자 단계** — 주행 중 중앙에 상자. 힌트마다 포장이 한 겹씩 벗겨지고 도착 때 열림
19. **지인의 얼굴** — 선물한 사람의 이니셜 아바타가 중심. "민지가 안내하는 중" → 도착 시 말풍선 메모
20. **창밖 풍경 띠** — 상단 1/3 에 추상 풍경 띠가 지나는 동네에 맞춰 바뀜

## D안 검토 — 10 / 18 / 20

판단 기준은 "UI 만 고쳐서 되는가"(주행 화면이 실제로 받는 데이터: `DrivingDisplayState`)와 "Codex 가 Canvas 로 그렸을 때 결과물 품질이 예측되는가".

| | 10 길 위의 점 | 18 선물 상자 | 20 창밖 풍경 띠 |
|---|---|---|---|
| 필요한 데이터 | `progress`, `hintsGiven`, `order.status`, `stopIndex/stopCount` — 전부 잠금 중에도 제공됨 | `hintsGiven`(0~3), 도착 여부 — 제공됨 | `lastStoryArea` — **잠금 중에는 null** (`toDisplayState` 가 `!locked` 일 때만 넘김) |
| UI 만으로 가능 | ✅ | ✅ (단, 공개 구간은 힌트가 없어 상자가 변하지 않음 → 둘째 구간이 밋밋) | ❌ 매퍼에 풍경 키 필드를 추가해야 함(Claude 영역). 달리는 동안 바뀌어야 의미가 있는 컨셉인데 달리는 동안 데이터가 없다 |
| 그림 난이도 | 선·점·작은 차 아이콘. 결과 품질이 예측 가능 | 상자·포장지·리본 일러스트. 코드로 그린 그림이 어설프면 컨셉 전체가 무너짐 | 산·도시·물 실루엣 3~4종 + 전환. 일러스트 의존도 가장 큼 |
| 주의분산 | 느린 등속 이동 하나. 낮음 | 힌트 시점에 벗겨지는 애니메이션 3회. 중간 | 띠 전환. 중간 |
| 제품 설명력 | 다중 정거장·숨긴 목적지·힌트·주문이 **한 장에** 보임. 스크린샷 하나로 Gift Drive 가 설명됨 | "선물"이라는 이름과 가장 직결. 클라이맥스가 강함 | 로컬 스토리 기능이 보이지만 핵심 흐름은 설명 못 함 |
| 추가 공수(주행+도착) | 약 반나절 | 반나절~1일 (그림 다듬기 반복 예상) | 1일 + 매퍼 변경·테스트 |

**권장: 10.** 기존 기능을 건드리지 않는다는 이번 작업의 전제를 그대로 지키고, A~C(글자·분할 중심)와 성격이 가장 달라 비교 가치가 크며, 결과물 품질이 Codex 의 그림 실력에 덜 좌우된다. 도착 화면은 15(타임라인 여권)의 축소판 — 같은 길이 이어지고 도착한 정거장에 도장이 찍힌 아래로 카드가 열리는 구성 — 으로 짝을 맞춘다.

18 은 은유가 가장 강하지만 (1) 일러스트 품질 위험 (2) 공개 구간에서 할 일이 없는 구조적 빈틈이 있다. 10 을 만들어 보고 시간이 남으면 그때 시도할 2순위. 20 은 잠금 규칙과 충돌하므로 제외 권장.

주의(10): 힌트 지점(진행 30/60/90%)과 주문 전이 지점은 상태기계 상수다. 화면이 그 위치를 **미리** 그리면 상수가 두 곳에 생긴다 → 길 위에는 "이미 일어난 일"만 찍는다(받은 힌트 수만큼 점, 현재 주문 상태는 차 옆 칩).
