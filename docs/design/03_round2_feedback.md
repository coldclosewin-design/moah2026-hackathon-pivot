## 2. 사용자 결정 필요 (D)

1. **숫자 노출 범위** — 제안: 운전자용(Maneuver 정차 줄·Done 멘트)에서는 숫자 제거, Report **자세히 보기**·진단서에서만. 총평의 "60점에서 100점까지" 도 제거하고 "첫 회차보다 훨씬 좋아졌어요" 로 순화할지.
2. **궤적 시뮬레이션(#16)** — 넣을지. 넣으면 Claude 반나절(추정기 + 테스트) + Codex 반나절(그리기). 시연의 핵심 장면이 되지만 "추정" 임을 화면에 써야 한다.
3. **패널 플래그** — 외부 시연 영상은 패널을 눌러야 시나리오가 돌아간다. 영상용으로 ① 패널을 아주 작게 두고 누르는 장면을 그대로 두거나 ② 시작 직후 자동 접힘으로 시선에서 지우거나(제안) ③ `emu_flow` 처럼 스크립트가 누르고 패널은 숨김(`-PdemoPanel=false` 에서는 스크립트도 못 누른다 — 별도 adb 브로드캐스트 필요, 라운드 4). 제안은 ②.
