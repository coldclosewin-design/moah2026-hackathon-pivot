T1↗ 원이 피어나 시트가 된다

누른 ↗ 원이 먼저 검게 차고(A1), 그 원이 그대로 화면 전체로 번지며 회색 시트 바탕이 된다. 바탕이 다 차면 문장 → 칩 → 버튼이 60 ms 간격으로 16 px 떠오른다(C1). 돌아가기 = 반대로 원이 ↗ 자리로 줄어든다.

장점
  • ‘누른 곳에서 다음 화면이 나온다’ — 손가락과 화면이 한 줄로 이어져 팝업 같은 끊김이 없다
  • 두 화면이 반투명으로 겹치는 순간이 없다(지금 어색함의 핵심 제거)
  • 돌아가기도 같은 원으로 줄어 ‘어디서 왔는지’ 가 남는다
주의점
  • 원 마스크(clip) + 내용 순차 등장 = 공수 중간(작음 쪽), 약 1–2 시간
  • 회색 바탕이 원 모양으로 번지는 400 ms 동안 홈 글자가 원 밖에 남아 있음(의도)
  • 정차 화면 전용 — 주행 중엔 이 전환이 없다(홈은 정차에서만)

T3↗ 원이 ‘시작’ 알약으로 늘어난다

움직이는 건 버튼 하나. ↗ 원이 눌려 검게 차고, 왼쪽으로 늘어나며 시트의 ‘시작 →’ 알약 자리에 내려앉는다. 그동안 홈 글자는 위로 24 px 빠지고 시트 글자는 아래에서 24 px 올라온다.

장점
  • T2 의 ‘이어짐’ 을 버튼 하나로만 — 공수는 절반
  • 눌렀던 것이 다음 화면의 ‘누를 것’ 이 되어 다음 행동이 바로 보인다
  • 위·아래 엇갈림이라 겹쳐 보이는 순간이 짧다
주의점
  • 버튼 모양 보간(크기·반경·위치) 커스텀 = 공수 중간
  • 제목은 그냥 바뀌므로 ‘같은 과제’ 라는 연결은 T2 보다 약함
  • 시트가 이미 ‘시작’ 을 다른 자리에 두면 착지점이 어긋남 — 위치 고정 필요
공수 중간총 520 ms

추천 — 홈 P3 세 칸 표 + 시트 S4 H8 흰 벽 · 대안 짝 P4 + S2

P3 은 점 대신 이름표(단계·장롱·목표) 위 · 값 아래로 위계를 만들어 ‘무엇을 말하는지’ 가 한눈에 읽히고(가독성), 장식이 가는 선 둘뿐이라 미니멀하다. S4 는 같은 ‘이름표 위 · 값 아래’ 표를 다섯 칸으로 펼친 것이라 홈 → 시트가 같은 종이의 다음 장이 된다(UX 연속). 큰 제목이 요약을 말하고 표는 고칠 때만 본다.

  • 더 따뜻한 쪽: P4(두 줄 문장) + S2(문장 프로필) — 문장 시트와 쌍둥이. 공수는 조금 큼.
  • 최소 공수: P4 + S6(지금 레이아웃에서 포스터만 요약 판으로).
  • ‘앱이 본 것’ 은 어느 안이든 눈 기호(E1) + ‘앱이 본 것 ·’ 앞말로 출처를 남긴다.
