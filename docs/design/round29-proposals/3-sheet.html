부드러운 감속 — 지나침 없음 공수 작음

곡선만 바꾼다. 340 ms 동안 빠르게 출발해 길게 감속(easeOutQuint), 지나침 0. 글자 색은 140 ms 교차, 카드 줄은 120 ms 사라짐 → 80 ms 뒤 200 ms 나타남.

값

  • 알약 340 ms · cubic-bezier(.22,1,.36,1)
  • 글자 색 140 ms ease(떠나는 칸 즉시 · 도착 칸은 55 % 지점부터)
  • 카드 줄 교차 out 120 · in 80→280 ms

장점

  • 값 세 개만 바꾸면 끝 — 가장 싸다.
  • 지나침이 없어 "맺히는" 끝맛이 차분하다 — 큰 화면에서 덜 출렁.

주의점

  • 활기는 B1 보다 적다.
  • 카드 줄은 교차 페이드만 — 방향감은 없다(→ M4).

M2

스프링 돌 — 속도가 이어지는 지나침 공수 작음

같은 지나침이라도 곡선이 아니라 스프링으로. 감쇠비 0.8 · 강성 300 → 약 480 ms 안에 1.5 % 만 살짝 넘었다 돌아온다. 손을 떼는 순간의 속도가 이어져 물방울처럼 맺힌다.

값

  • Compose spring(dampingRatio = 0.8f, stiffness = 300f)
  • CSS 흉내 linear() 41 점 · 최대 1.015
  • 카드 줄 교차 out 120 · in 80→320 ms

장점

  • 연속으로 빠르게 눌러도 중간에서 자연스럽게 방향을 튼다(트윈은 다시 0 에서 시작).
  • Compose 에선 tween → spring 한 줄 교체.

주의점

  • 끝이 480 ms 로 길어 보인다 — 실제 느낌 시간은 300 ms 안쪽(나머지는 1 % 이내 흔들림).
  • AnimationSpec 이 시간 기반이 아니라 테스트에서 끝 프레임 기다리기를 바꿔야 할 수 있다(계측 테스트).

부드러운 젤리 — 앞이 먼저, 뒤가 따라옴 공수 중간

앞 가장자리가 200 ms 에 먼저 닿고, 뒤 가장자리가 70 ms 늦게 출발해 260 ms 에 따라온다. 잠깐 길어졌다가 줄어드는 물방울 모양 — 지난 B2 보다 늘어남을 줄였다(두 칸 반 이하).

값

  • 앞 가장자리 200 ms · cubic-bezier(.33,0,.2,1)

  • 가장 "말랑"한 손맛 — 사용자가 다른 화면에서 말한 물방울 느낌과 같은 말투.

주의점

  • 움직이는 동안 알약이 두 칸을 덮는 순간(약 100 ms)이 있다.

M4

돌 + 카드 줄이 같은 방향으로 넘어감 공수 중간

알약이 오른쪽으로 가면 지금 카드들은 왼쪽으로 48 dp 빠지며 사라지고(160 ms), 새 카드들이 오른쪽 64 dp 에서 40 ms 간격으로 들어와 선다(280 ms). 돌아갈 땐 반대 방향.

값

  • 알약 320 ms · cubic-bezier(.22,1,.36,1)
  • 나가는 카드 160 ms · cubic-bezier(.4,0,1,1) · −48 dp
  • 들어오는 카드 80 ms + 40 ms × n 지연 · 280 ms · cubic-bezier(.22,1,.36,1) · +64 dp → 0

장점

  • "넘어간다"가 알약 하나가 아니라 면 전체에서 일어난다 — 끊기는 원인(카드 줄 즉시 교체)을 직접 없앤다.
  • 방향이 위치(주차 → 지식은 오른쪽)와 일치해 분류가 공간처럼 읽힌다.

주의점

  • AnimatedContent + slideInHorizontally · 카드별 지연 — 중간 공수.
  • 카드가 들어오는 동안 누르면 무시하지 말고 바로 고르게(계측 테스트가 탭 직후 카드를 찾는다 — 끝까지 기다리는 대기 필요).

글자까지 한 몸 — 경계에서 색이 뒤집힘 공수 중간

흰 글자 한 벌을 알약 안에 넣고 알약과 반대로 움직여, 글자 색이 알약 가장자리에서 정확히 바뀐다. 곡선은 양끝이 부드러운 easeInOut 320 ms.

값

  • 알약 · 안쪽 글자 320 ms · cubic-bezier(.65,0,.35,1)(서로 반대 방향)

  • 카드 줄 교차 out 120 · in 80→280 ms

추천 · C

C1 둥근 카드 + 지도 창 + 흰 판 — 시간이 남으면 C8 의 "올라오는 시트" 로

  • C1 은 지금 화면 구성 · 동선 · 테스트 라벨을 그대로 두고 재료만 바꿔 "딱딱함" 을 걷어낸다 — 오늘 안에 끝난다.
  • 예시 표기를 예약 버튼 옆으로(모든 안 공통) — 정직성이 예약하는 순간 같은 눈높이에서 읽힌다.
  • "팝업 느낌" 을 더 원하면 C8(목록 → 아래에서 올라오는 시트, C1 420 ms) 또는 과제 시트와 완전히 같은 C2. 둘 다 공수 중간.
  • 공수: C1 작음 · C8 / C2 중간.
