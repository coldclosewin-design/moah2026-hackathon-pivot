라운드 31 · 3 — 앱 로고 "Drive Coach" · 동그라미 안 그림 20안

사내 런처는 모든 앱 아이콘을 동그라미 안 그림으로 그린다. 그래서 각 안은 108×108 벡터(Android adaptive icon 캔버스) 가운데 72 만 보이는 원으로 미리 본다 — 큰 240 px(흰 바탕 + Onyx 그림 + 노란 점 허용) · 작은 72 / 48 px 를 흰 바탕·Onyx 바탕으로 · 노란 점을 뺀 단색까지. 그림은 원 안의 안전 영역(지름 66, 반지름 33) 안에 두고, 선 굵기 5–7 · 둥근 끝 — 화면 속 V4 차와 같은 문법이다. 이름은 "Drive Coach"(홈 상단의 DRIVE COACH 와 같은 글꼴)로 아이콘 옆에 한 줄로 놓아 본다. 실제 브랜드 마크는 베끼지 않았다.

바탕 흰 #FFFFFF · 그림 Onyx #222526바탕 Onyx · 그림 흰노란 점 #F2C230 한 곳(선택)108×108 viewBox · 보이는 원 = 가운데 72 · 안전 반지름 33SVG → VectorDrawable 그대로script 없음

미리보기 규칙

  • 원 = adaptive icon 의 마스크. viewBox="18 18 72 72" 로 가운데 72 만 보인다. 런처가 원을 그리므로 그림 자체에는 원을 넣지 않는다(배경 레이어 = 바탕색 단색).
  • 작은 72 / 48 px 는 사내 런처 격자에서 실제로 보이는 크기 — 여기서 뭉개지면 탈락.
  • 색 쌍은 두 가지: 흰 바탕 + Onyx 그림 / Onyx 바탕 + 흰 그림. 노란 점은 한 곳만, 노란 면 위에 그리는 선은 항상 Onyx(--ink).
  • 단색(mono) 미리보기 = 노란 점을 바탕색으로 바꾼 것 — 노랑을 쓰지 않기로 하면 그대로 그 모습이다.

VectorDrawable 로 옮길 때(Codex)

  • android:viewportWidth/Height="108", width/height="108dp". 각 <path>: fill → android:fillColor, stroke → android:strokeColor, stroke-width → android:strokeWidth, stroke-linecap/linejoin="round". fill="none" 이면 fillColor 를 생략.
  • <circle>·<rect> 는 path 로: 원 M cx-r,cy a r,r 0 1 0 2r,0 a r,r 0 1 0 -2r,0 Z, 둥근 사각은 a rx,rx 모서리.
  • stroke-dasharray 는 VectorDrawable 에 없다 — 15 · 16 의 점선은 짧은 선분을 여러 path 로 쪼개서(또는 trimPath) 그린다.
  • 색 변수: var(--fg)=그림색, var(--bg)=바탕색, var(--acc)=#F2C230, var(--ink)=#222526. 아래 코드 칸은 흰 바탕 기준으로 이미 바꿔 적었다. Onyx 바탕은 #222526 ↔ #FFFFFF 맞바꿈.
  • 런처 라벨 android:label="Drive Coach"(지금은 "드라이브 코치") — 이름 바꾸기는 strings.xml 한 줄.
