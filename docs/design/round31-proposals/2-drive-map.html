주행 화면 — 지도와 코치 문장 카드가 겹치지 않게 · 10안

지금(28b)은 코스 지도가 화면 정중앙, 코치 카드가 오른쪽 아래에 떠서 장내 코스의 오른쪽 아래 길을 가린다(일반 도로 ㄱ자 코스는 운 좋게 안 겹칠 뿐). 아래 10안은 모두 같은 데이터 — 일반 도로 코스 1회차 · 힌트 모드 · 28 km/h · 지금 신호 교차로 · 다음 우회전 · 문장 "신호를 봐요. / 빨간불이면 정지선 앞에 멈춰요." — 로 지도와 글이 서로 다른 자리를 갖게 한다. 목업은 2560×1268 dp 를 1/3 로 줄인 853×423(실제 화면은 약 3배). 안마다 속도 · "신호등 미측정" · 시뮬레이션 표기 · "운전에 집중해 주세요" 자리를 적었다. 돌발(Signal) · 정차(다 됐어요) 변형은 각 안의 "자리" 칸 마지막 줄.

지금 화면에서 본 문제(캡처 lesson-28b-drive-*.png)

  • 지도 `CourseMap` 이 가운데 정렬 — 장내 코스(순환)는 오른쪽 아래 모퉁이와 횡단보도가 카드 뒤로 들어간다.
  • 카드가 떠 있어 "지도 위 말풍선" 처럼 읽히지만 차 위치와 무관한 자리 — 어디를 보라는 건지 알 수 없다.
  • "운전에 집중해 주세요" 가 카드 바로 위에 붙어 카드의 제목처럼 보인다. 정직성 줄(시험장 위치·신호 · 시뮬레이션)은 왼쪽 아래에 홀로.
  • "신호등 미측정" 상태는 왼쪽 아래 두 줄로만 — 지도 위 신호등 점은 그대로라 미측정인지 알 수 없다.

모든 안의 공통 약속

  • 글(코치 문장)과 지도는 겹치지 않는 자기 영역을 갖는다 — 지도는 자기 영역 안에서 `meet` 로 맞춰 그린다(코스 종류와 무관).
  • 정직성 줄 = ◐ 위치 시뮬레이션 · ◌ 신호등 미측정 · ● 속도 실신호 한 줄(11 px = 33 sp). 미측정이면 지도의 신호등 점도 점선 빈 원으로 바뀐다.
  • 속도는 흰 알약(72 dp 숫자) 또는 어두운 판 위 큰 숫자. 모드는 노란 힌트 알약 한 곳. 글 = 제목 72 dp + 한 마디 48 dp.
  • 돌발 = 글이 있는 면만 Signal 로 바뀜. 정차(≤ 5 km/h) = 그 면 아래에 검은 알약 `다 됐어요` 가 들어옴(자리를 미리 비워 둔다).

  • 구현 메모: `Row { Box(Modifier.weight(2f)) { CourseMap(fit = Meet) } ; Surface(width = 740.dp, shape = RoundedCornerShape(60.dp)) { Column { 속도 · 힌트 · 지금 칩 · 다음 칩 · 제목(72 dp) · 한 마디(48 dp, 최대 2줄) · Spacer(weight) · 잠금 문구 또는 `다 됐어요` } } }`. 돌발은 `Surface(color = Signal)` 전환만.
  • 정직성: 정직성 줄(◐ 위치 시뮬레이션 · ◌ 신호등 미측정 · ● 속도 실신호)은 지도 아래 왼쪽 고정, 미측정이면 지도 신호등 점을 점선 빈 원으로 + 시트에 점선 칩 `신호등 미측정`.
  • 글이 운전석에서 먼 오른쪽인 점이 걸리면 O9 처럼 좌우를 바꾼 변형(시트 왼쪽 · 지도 오른쪽)이 한 줄 변경 — 단 점검 화면의 시트 자리와 어긋나므로 둘을 같이 바꾼다.
  • 차선책: O6(위 띠 한 줄) — 공수 같고 글이 시선에 가장 가깝지만, 띠 아래 워드마크·과제명 자리를 다시 잡아야 하고 돌발 때 빨간 띠가 시스템 바에 붙는다. O2 는 지도가 작아진다.
  • 쓰지 않을 것: O4(겹침을 남긴 채 비치게만) · O7(확대 = 정밀해 보임, 공수 큼).
