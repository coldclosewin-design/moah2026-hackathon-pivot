## 페이지 배정

1. `1-mode-roller.html` — **홈 제목 속 모드 고르기를 롤링형으로** 5안. 지금은 `가이드 ▼` 아래로 두 겹 카드가 떨어지는 드롭다운(그림자 셈, 뒤 카드 불필요). 안: 세로 드럼(가이드/힌트/평가 세 줄이 돌아감, 가운데 줄이 제목 자리) · 가로 롤(낱말이 옆으로 밀림) · 제목 낱말 자체가 넘어감(눌렀을 때 그 자리에서 다음 모드로 굴러감, 세 번 누르면 한 바퀴) · 밑줄 낱말을 위아래로 쓸어 넘김 · 낱말 아래 작은 세 점 + 굴러감 등. **문장 "후면 직각 주차 ▼ 를 가이드 ▼ 모드로 해 볼까요?" 의 제목 크기·밑줄은 그대로**, 모드 낱말만 움직인다. 그림자 없음 또는 아주 약하게. 과제 쪽 `▼`(과제 시트가 열림)와 구분되게. 실제 CSS 움직임 + 프레임 띠 + ms·이징.
2. `2-drive-map.html` — **주행 화면에서 지도와 코치 문장 카드가 겹치지 않게** 10안. 지금은 지도(코스 도면 + 흰 차)가 화면 정중앙, 코치 카드가 오른쪽 아래에 떠서 도로를 가린다. 안: 지도를 왼쪽 2/3 로 밀고 카드는 오른쪽 세로 띠 · 지도 위 카드 대신 아래 가로 띠(지도는 위로) · 카드가 지도의 빈 모서리로 옮겨 다님(코스 도면의 빈 사분면을 데이터로 고름) · 카드를 반투명 흰 판 + 지도 선이 비침 · 지도를 둥근 창(세로 긴 타원)에 넣고 카드는 창 밖 · 코치 문장을 지도 위 말풍선이 아니라 화면 위 띠 한 줄 · 지도 축소(현재 구간만 확대, 전체는 작은 썸네일) 등. **주행 중 화면 규칙**: 터치 타깃 0 · 점수 없음 · 글자 32 sp 이상 · 문장은 짧게(제목 12자 + 한 마디 24자). 속도·"신호등 미측정"·시뮬레이션 표기·`운전에 집중해 주세요` 자리는 안마다 적는다. 정지 10안 + 추천.
3. `3-app-logo.html` — **앱 이름 "Drive Coach" + 동그라미 안 그림 로고 20안**. 각 안: 지름 1/1(큰 미리보기 240 px) + 작은 크기(72 px · 48 px — 런처에서 읽히는지) + 바탕/그림 색(흰 바탕 + Onyx 그림, Onyx 바탕 + 흰 그림, 노란 포인트 한 점 허용). 주제: 운전 연수(초보 표식 — 한국 '초보운전' 느낌의 새싹/잎 · L 플레이트 문법은 쓰지 않거나 변형) · 조수석/동승(둘이 앉은 좌석 · 손 위에 손) · 핸들(간결한 링 + 세 살) · 주차 칸에 차(V4 차 + 두 선) · 원목 장난감 차 옆모습(단순화 선) · 체크(가이드→힌트→평가 세 단계) · 말풍선 + 핸들(화내지 않는 조수석) · 나침반/화살표 ↗(앱의 시작 원) · 길 위 점선 + 차 등. 각 안에 **SVG 코드(단일 path 몇 개, 24×24 또는 108×108 좌표)** 를 그대로 넣어 Codex 가 VectorDrawable 로 옮길 수 있게. 추천 3개(이유 한 줄).
