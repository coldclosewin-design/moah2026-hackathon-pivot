점진

첫 실행에 아무것도 묻지 않는다. 눈썹은 "연수생 · 처음 뵙겠습니다". 첫 세션이 끝나면 관측(연습한 과제·급조작·되감기)이 먼저 채워지고, 리포트 끝 카드에서 질문 하나(가장 쓸모 있는 "무서운 상황" 부터)를 묻는다. 세션마다 하나씩, 다섯 세션이면 다 찬다. "다음에요" 는 언제나.

화면 수

진입

저장
칩 누르는 즉시 한 항목씩. 관측은 세션 끝마다. 같은 로컬 파일.
시연 영향
시연 리포트 끝에 질문 카드가 한 장 더 생긴다 — 대본 시간 약 10초 추가, 또는 프리셋이 "다 답한 프로필" 을 심어 카드를 안 띄운다.
난이도
하. 카드 하나 + 질문 순서 + 저장. 가장 작다.

장점

  • 운전자에게 가장 가볍다 — 차에 타자마자 설문이 없다. "화내지 않는 조수석" 다운 태도.
  • 관측이 먼저 쌓여 "앱이 본 것" 이 진술보다 앞선다 — 제품 논리(과정 측정)와 맞는다.

주의점

  • 첫 세션의 제안·말투는 프로필 없이 정해야 한다 — 기본값이 보수적(가이드 모드 · 후면 주차)이면 된다.
  • 다 채워지기까지 다섯 세션 — 시연 한 번으론 "프로필 기능" 이 안 보인다. 영상엔 B 시트를 같이 보여 줘야 한다.

네 시안이 공유하는 바닥

저장

  • 앱 전용 폴더에 파일 하나(profile.json): statement(진술 5) + observation(관측) + version. 기존 ProgressStore 옆에 ProfileStore.
  • 앱 시작에 읽고, 저장은 "저장 →"·칩 즉시·세션 끝 세 시점 중 시안이 정한 곳에서.
  • 사내 에뮬: 앱 폴더는 재설치(adb install -r 은 유지, uninstall 은 삭제)·에뮬 초기화에 사라진다 → 관리자 프리셋이 파일을 다시 심는다. INTEGRATION.md B절에 가정 한 줄.

프로필이 실제로 바꾸는 것

  • 홈 눈썹 한 줄 · 첫 제안 과제(무서운 상황 → 과제 분류) · 첫 모드(장롱 기간이 길면 가이드).
  • 회차 멘트 서두 톤(AdviceRules 입력) — 채점 숫자는 절대 안 바꾼다.
  • 관측은 진단서 "자세히 보기" 에만 숫자로, 프로필 시트에는 말로.

질의응답으로 정할 것

하나씩 답을 받으면 바로 핸드오프로 옮길 수 있게, 질문마다 기본값(답이 없으면 이렇게)을 적었다.
