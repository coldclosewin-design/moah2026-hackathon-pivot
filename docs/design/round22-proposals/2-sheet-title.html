한 단계 뒤로 (Muted)

제목만 Ink 60%(`--muted`) 28 dp 로 한 단계 물린다. 섹션 눈썹(주차 세부 과제·모드)은 Periwinkle 32 dp 그대로.

장점

  • 사용자 요청을 가장 곧이곧대로 — 색 하나·크기 하나만 바뀐다
  • 제목이 회색으로 물러나면서 Periwinkle 눈썹이 "누를 묶음의 이름" 으로 앞에 선다
  • `--muted` 는 이미 리포트 보조 문구에 쓰는 토큰이라 새 색이 아니다

주의점

  • 구현 가장 쉬움 — 눈썹 스타일에 색·크기 인자 둘 추가
  • 제목이 가장 눈에 안 띄는 글자가 된다 — "화면 이름" 을 읽어야 하는 첫 진입 때 약간 희미할 수 있다

화면 이름 (Wordmark)

제목을 Ink 100% 28 dp 에 자간을 넓혀(워드마크 DRIVE COACH 와 같은 letter-spacing 느낌) "화면의 이름표" 로 만든다. 섹션 눈썹은 Periwinkle 32 dp 유지.

  • 왼쪽 워드마크와 오른쪽 제목이 같은 글자 성격(Ink·넓은 자간)으로 묶여 화면 머리가 한 줄로 읽힌다

  • 크기는 줄었지만 Ink 100% 라 첫 진입 때도 또렷하다

주의점

  • 구현 쉬움 — `letterSpacing` 한 값 추가. 한글은 자간을 너무 넓히면 낱자가 흩어지므로 0.12~0.14 em 이 상한

  • Ink 글자가 늘어 포스터의 "검정은 왼쪽 면" 균형이 조금 흔들린다

포스터 룰 (Rule)

제목을 Periwinkle 70% 26 dp 로 줄이고, 그 아래에 오른쪽 폭 전체의 얇은 Lavender 선 하나 — 포스터의 머리 괘선. 섹션 눈썹은 Periwinkle 32 dp 유지.

장점

  • 선 하나가 "여기까지 머리, 아래부터 내용" 을 긋는다 — 제목과 분류 트랙이 한 덩어리로 붙어 보이는 문제가 같이 풀린다
  • 색 계열은 Periwinkle 그대로라 눈썹과 가족이면서 투명도·크기로 한 단계 아래
  • 기하학 포스터의 괘선 문법 — 왼쪽 면 분할과 같은 언어

주의점

  • 구현 쉬움 — Divider 하나. 단 트랙과 선 사이를 40 dp 이상 띄우지 않으면 트랙이 선 위에 얹힌 것처럼 보인다
  • Lavender 선은 Paper 위에서 아주 옅다(의도) — 에뮬 캡처보다 실물에서 더 흐릴 수 있다
  • Periwinkle 70% 는 새 토큰이 아니라 투명도 변형이지만, 한 화면에 Periwinkle 농도가 셋(100·70·트랙)이 된다

왼쪽으로 (Panel)

제목을 오른쪽에서 빼서 왼쪽 패널, 워드마크 아래 일러스트의 Periwinkle 면 위에 Paper 글자로 놓는다. 오른쪽 Paper 는 분류 트랙부터 바로 시작.

장점

  • 오른쪽 첫 글자가 섹션 눈썹 하나뿐이 되어 위계 문제가 "사라진다" — 제목과 눈썹이 같은 열에 없다
  • 오른쪽이 약 57 dp 위로 올라가 아래쪽(모드 행·버튼) 여유가 생긴다 — ③ 모드 간격 시안과 같이 쓰면 효과가 크다
  • 워드마크 + 화면 이름이 왼쪽 패널에 세로로 쌓여 포스터의 "표지" 처럼 읽힌다

주의점

  • 구현 중간 — 제목이 일러스트 위에 겹치므로 일러스트 면 색이 그 자리에서 항상 진해야 한다(지금 일러스트는 고정이라 가능, 단 홈·시험장 시트에서도 같은 자리)
  • 제목이 과제 열과 떨어져 "이 트랙이 무엇의 분류인가" 가 한 박자 늦게 읽힐 수 있다
  • 시선이 왼쪽으로 한 번 갔다 와야 한다 — 운전석(왼쪽)에서는 오히려 가깝다

분류 라벨 (Context)

제목을 24 dp Ink 60% 로 작게 줄여 분류 트랙 바로 위 왼쪽에 붙이고(트랙의 라벨처럼), 섹션 눈썹은 분류 이름을 넣어 "주차 · 세부 과제" Periwinkle 28 dp 로.

장점

  • 제목이 트랙 라벨 역할을 맡아 "연습할 과제 → 주차 / 주행 / …" 이 한 문장으로 읽힌다
  • 눈썹에 가운뎃점이 들어가 "주차" 가 선택 상태이고 "세부 과제" 가 섹션임이 글자만으로 구분된다
  • 제목이 트랙 위 16 dp 로 붙고 그만큼 트랙·카드가 위로 올라가 아래 여유가 약 20 dp 생긴다

주의점

  • 구현 쉬움 — 눈썹 문구에 분류 이름 삽입, 크기 둘 변경. "모드" 눈썹도 28 dp 로 같이 맞춘다
  • 24 dp 는 이 앱에서 가장 작은 글자가 된다 — 실물 2560 폭에서는 읽히지만 "제목" 으로는 가장 약하다
  • 라운드 21 ②에서 "눈썹과 트랙 사이를 띄우자" 고 했던 방향과 반대(붙인다) — 사용자 확인 필요
