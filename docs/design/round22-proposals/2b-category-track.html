분류 트랙(주차·주행·점검·지식) — 색·글자 크기 위계 시안 다섯 가지

분류 트랙과 그 아래 세부 과제 카드가 지금은 같은 짝(바탕 Lavender · 선택 Periwinkle)을 써서 "큰 분류" 와 "고를 카드" 가 한 층으로 보인다. 라벨은 56 dp 로 오른쪽에서 가장 큰 글자다. 색 전문가 관점에서 명도(밝기) 위계로 트랙을 카드와 다른 층으로 떼고, 라벨은 40–48 dp 로 살짝 줄인다. 카드는 지금 그대로 둔다.

밤 (Night)

트랙을 Ink 로 칠해 화면에서 가장 어두운 층으로 올리고, 선택 알약은 Paper 로 뚫는다 — 아래 밝은 카드와 명도가 정반대.

트랙 바탕Ink 100% · 안쪽 그림자 Ink 60%
트랙 높이96 dp
선택 알약Paper · 글자 Ink · 질감 B 어두운 판(그림자 Ink 60% + 위 하이라이트)
비선택 글자Lavender 70% (≈ #A2A3B4 on Ink)
라벨 크기 · 자간44 dp · 0.04 em (어두운 바탕의 밝은 글자는 살짝 벌려야 번짐이 준다)

대비 · 선택 Ink / Paper ≈ 19 : 1 · 비선택 Lavender 70% / Ink ≈ 7.9 : 1 · 층 구분 트랙 Ink / 카드 Lavender ≈ 15.8 : 1 — 다섯 안 중 가장 큼

장점

  • "분류 = 어두운 띠, 과제 = 밝은 판" 이 한눈에 갈린다. 선택 카드(Periwinkle)와 선택 알약(Paper)이 색으로 전혀 겹치지 않는다
  • 왼쪽 일러스트 아래의 Ink 면과 같은 색이라 "기하학 포스터" 의 큰 면 분할 언어 그대로
  • 비선택 글자도 7.9 : 1 로 넉넉 — 낮 햇빛 반사에서도 가장 잘 읽힌다

주의점

  • 오른쪽 Paper 면에 검은 띠가 생겨 시선을 가장 먼저 끈다 — 고르는 주인공(카드)보다 분류가 다시 앞에 설 위험. 그래서 높이 96 dp·라벨 44 dp 로 덩치를 줄였다
  • 질감 B 의 아래 그림자는 Ink 위에서 안 보인다 — 알약 위 1 px 하이라이트와 아래 Lavender 테두리로 입체를 대신 낸다
  • 카드 선택 상태와 혼동 없음. 다만 잠금 화면(Ink 평면)과 인상이 겹칠 수 있어 시연 대본에서 확인 필요

먹 (Ink)

트랙 바탕은 Lavender 를 반으로 옅게 물리고, 선택 알약만 Ink 로 — 바탕은 카드보다 한 단계 밝게, 선택은 카드보다 한 단계 어둡게.

트랙 바탕Lavender 50% (≈ #F0F1F5 on Paper) · 안쪽 그림자 지금 그대로
트랙 높이96 dp
선택 알약Ink · 글자 Paper · 질감 B(SelectedChip 그대로, 색만 교체)
비선택 글자Ink 60% (--muted)
라벨 크기 · 자간48 dp · 0

대비 · 선택 Paper / Ink ≈ 19 : 1 · 비선택 Ink 60% / 트랙 ≈ 5.0 : 1 · 층 구분 선택 알약 Ink / 선택 카드 Periwinkle ≈ 3.4 : 1, 트랙 / 카드 바탕 ≈ 1.1 : 1 (일부러 약하게)

장점

  • 명도 사다리가 정확히 세 칸 — 트랙(가장 밝음) → 카드(중간) → 선택 알약(가장 어두움). 선택 카드 Periwinkle 은 그 사이라 "선택이 둘" 로 안 읽힌다
  • 구현이 가장 작다 — 트랙 바탕 투명도, 선택 색, 비선택 색, 글자 크기 네 값. 라운드 21 의 트랙 모양·질감은 그대로
  • Ink 알약은 홈 화면 왼쪽 Ink 면·워드마크와 같은 "먹색" 이라 화면 전체가 묶인다

주의점

  • 트랙 바탕 차이는 미세하다(의도) — 층 구분은 바탕이 아니라 선택 알약의 색이 맡는다. 바탕까지 확실히 갈라 보이길 원하면 A·D
  • 질감 B 그림자가 Ink 알약 아래에선 약하게 보인다 — 위 하이라이트 16% 를 유지해 납작해 보이지 않게
  • 운전석 가독성: 48 dp 는 카드 제목 40 dp 보다 한 단계 크게 남아 위계가 무너지지 않는다. 혼동 위험 없음

종이 (Paper)

트랙을 보라기 없는 회색(Ink 6%)으로 바꿔 카드의 푸른 Lavender 와 색온도로 가르고, 선택은 그 홈 위로 떠오른 Paper 알약.

트랙 바탕Ink 6% (≈ #EDEDED on Paper, 중성 회색) · 안쪽 그림자 Ink 14% — 파인 홈
트랙 높이96 dp
선택 알약Paper · 글자 Periwinkle · 질감 B 그대로(그림자 + 위 하이라이트)
비선택 글자Ink 60% (--muted)
라벨 크기 · 자간44 dp · 0

대비 · 선택 Periwinkle / Paper ≈ 5.6 : 1 · 비선택 Ink 60% / 트랙 ≈ 5.0 : 1 · 층 구분 알약 Paper / 트랙 ≈ 1.15 : 1 — 대비가 아니라 그림자 높이로 구분

장점

  • 질감 B 와 가장 잘 맞는다 — "파인 홈 + 올라온 알약" 은 그림자·하이라이트가 제일 잘 보이는 조합
  • 선택 = 밝게(트랙) / 선택 = 진하게(카드)로 방향이 반대라 두 단계가 섞이지 않는다
  • 회색 트랙은 "설정 줄", 보라 카드는 "콘텐츠" 로 읽혀 색 수를 늘리지 않고 성격이 나뉜다

주의점

  • 선택 알약과 트랙의 명도 차가 작아 그림자에 기댄다 — 에뮬 캡처·영상 압축에서 그림자가 뭉개지면 선택이 약해 보일 수 있다
  • 운전석에서 비스듬히 보면 그림자가 덜 보인다 — 알약 글자를 Periwinkle 로 둬 색으로도 한 번 더 표시
  • 중성 회색은 이 앱에 처음 나오는 인상(토큰은 Ink 투명도라 새 색은 아님) — 다른 화면에 퍼지지 않게 트랙에만

반전 (Invert)

지금 짝을 뒤집는다 — 트랙 전체가 Periwinkle, 선택 알약이 Paper. 카드는 "Lavender 위 Periwinkle 선택", 트랙은 "Periwinkle 위 Paper 선택".

트랙 바탕Periwinkle 100% · 안쪽 그림자 Ink 28%
트랙 높이96 dp
선택 알약Paper · 글자 Periwinkle · 질감 B(그림자 Ink 28% + 위 하이라이트)
비선택 글자Paper 75% (≈ #D4D5E4 on Periwinkle)
라벨 크기 · 자간44 dp · 0.02 em

대비 · 선택 Periwinkle / Paper ≈ 5.6 : 1 · 비선택 Paper 75% / Periwinkle ≈ 4.0 : 1 (큰 글자 기준 3 : 1 통과, 일반 글자 4.5 : 1 미달) · 층 구분 트랙 / 카드 바탕 ≈ 4.7 : 1

장점

  • 색을 하나도 바꾸지 않고 "역할만 맞바꿔" 차별 — 브랜드 인상(보라)은 가장 그대로 유지
  • 트랙이 진한 띠가 되어 오른쪽 면의 "머리" 가 생긴다. A 보다 덜 무겁다
  • 선택 알약(밝음)과 선택 카드(진함)의 방향이 반대라 선택 표시끼리 겹치지 않는다

주의점

  • 혼동 위험: 트랙 띠 전체가 선택 카드와 같은 Periwinkle 이라 "트랙이 통째로 선택됐다" 로 읽힐 수 있다 — 다섯 안 중 가장 큰 위험
  • 비선택 글자 4.0 : 1 은 낮 햇빛 반사에서 가장 약하다. 44 dp 아래로 줄이면 안 된다
  • 화면에 Periwinkle 덩어리가 셋(트랙·선택 카드·모드 "힌트")이 되어 오른쪽이 무거워진다

밑줄 (Underline)

트랙의 채움을 걷어내 Paper 위 글자 줄로 만들고, 선택은 Ink 글자 + 아래 Signal 막대 — 채운 면(카드)과 선(분류)으로 층을 가른다.

트랙 바탕Paper(채움 없음) · 아래 2 dp Lavender 기준선
트랙 높이88 dp
선택 표시알약 대신 6 dp 둥근 막대(Signal, 칸 폭의 36%) · 글자 Ink · 질감 없음(평면)
비선택 글자Periwinkle 100%
라벨 크기 · 자간40 dp · 0.04 em

대비 · 선택 Ink / Paper ≈ 19 : 1 · 비선택 Periwinkle / Paper ≈ 5.6 : 1 · Signal 막대 / Paper ≈ 3.8 : 1 (비텍스트 3 : 1 통과)

장점

  • 가장 가볍다 — 분류가 "탭" 이 되고 카드가 오른쪽 면의 주인공으로 확실히 선다
  • Signal 막대가 선택 카드의 빨간 체크와 같은 색이라 "빨강 = 지금 고른 것" 규칙이 한 화면에 통일된다
  • 높이 88 dp 로 줄어 아래 모드 행·버튼 쪽 여유가 가장 많이 생긴다

주의점

  • 라운드 21 에서 확정한 "분류 알약 트랙" 모양을 바꾼다 — 사용자 확인 필요. 질감 B 를 쓰지 않는 유일한 안
  • 40 dp 는 카드 제목과 같은 크기라 분류·과제 글자 크기 위계가 사라진다 — 색(Ink vs Periwinkle)만으로 구분
  • 운전석에서 터치 타깃이 글자 줄처럼 보여 "누를 수 있는가" 가 약해진다. Signal 이 주 알약 "시작" 과 겹쳐 빨강 면적이 늘어난다

한눈에 비교 — 트랙 다섯 + 같은 카드 줄

1/3 축척. 모두 주차 선택. 카드 줄은 지금 그대로 하나만 두어 트랙과의 층 차이만 보이게.

트랙 바탕(가장 밝음) → 카드(중간) → 선택 알약(가장 어두움, 19 : 1)으로 명도 사다리가 정확히 세 칸이 되어 "선택이 둘" 문제가 풀리고, 라운드 21 의 알약 모양·질감은 그대로 둔 채 값 네 개만 바꾼다. 층을 더 세게 가르고 싶으면 A 밤이 다음 후보.
