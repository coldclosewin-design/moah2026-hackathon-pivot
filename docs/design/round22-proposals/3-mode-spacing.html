모드 행(가이드 · 힌트 · 평가)과 돌아가기 · 시작 사이 — 간격·배치 시안 다섯 가지

`돌아가기`·`시작` 의 위치와 크기는 그대로 두고, 모드 행과 제휴 시험장 링크만 옮겨 손가락이 헷갈리지 않는 간격을 만든다. 같은 규칙을 제휴 시험장 시트(시간 · 코스 행 vs 돌아가기 · 예약)에도 적용한다.

사용자 피드백 (원문) #모드 — 가이드/힌트/평가 부분과 돌아가기 시작 부분이 너무 인접해 있어서 좀 더 UX 고객 편의와 디자인을 고려한 시안 5개 정도 제안 받고 싶어 (돌아가기/시작은 그대로인 점 참고) + 제휴시험장도 이를 고려하여 같이 고민
아래 화면은 모두 실제의 1/3, 시트 아랫부분(카드 행 바닥 → 돌아가기 · 시작)만 잘라 보임 — 실제 화면은 약 3배

공통 조건 · 돌아가기(약 310 × 112 dp) · 시작(1075 × 140 dp) 의 위치·크기 불변 · 과제 시트에는 숫자 없음(시간대 라벨은 시험장 시트에만) · 누르는 면은 높이 88 dp 이상 · 새 색 없음 · 빨간 괄호는 시안이 만든 빈 띠(치수는 오른쪽 글에) · 지금 실측: 모드 칩 약 220 × 90 dp, 칩 바닥 → 시작 윗변 약 17 dp, → 돌아가기 윗변 약 34 dp / 시험장 코스 칩 바닥 → 예약 윗변 약 68 dp

보이는 문제

  • 모드 칩 바닥과 `시작` 윗변 사이가 약 17 dp — 손가락 폭(약 60 dp)보다 좁아 "힌트" 를 누르려다 `시작` 을 누를 수 있다
  • "모드 선택" 과 "출발" 이라는 다른 종류의 행동이 한 덩어리로 보인다 — 칩이 시작 알약의 라벨처럼 읽힌다
  • 위쪽(카드 ~ 링크 ~ 모드)은 느슨하고 아래만 빽빽해 리듬이 거꾸로다
  • 시험장 시트도 같다 — 시간 · 코스 두 줄이 연이어 내려와 코스 칩과 `예약` 이 약 68 dp 로 붙는다

간격만 (Breathe)

구조는 그대로, 모드 행을 카드 행 쪽으로 끌어올리고 제휴 시험장 링크를 모드 행 오른쪽 끝으로 옮긴다. 구분선은 뺀다. 칩 높이를 돌아가기와 같은 112 dp 로.

장점

  • 바뀌는 것이 간격·링크 위치·칩 높이뿐 — 사용자가 익숙한 순서(카드 → 모드 → 시작)가 유지된다
  • 칩 바닥과 `시작` 사이 빈 띠 약 110 dp — 손가락 두 개 폭. 잘못 누름이 구조적으로 사라진다
  • 링크가 오른쪽 끝으로 가며 "모드" 와 "시험장" 이 한 줄의 양끝 — 세로 줄 수가 넷에서 셋으로

주의점

  • 구현 가장 쉬움 — Spacer 값·Row 정렬·칩 높이
  • 링크가 오른쪽 끝(운전석에서 가장 먼 자리)으로 간다 — 자주 쓰는 길이 아니라 허용
  • 빈 띠가 넓어 "아래에 더 있나" 로 보일 수 있으나 시트는 스크롤하지 않으므로 문제 없음

과제 시트 · 카드 바닥 → 32 → 모드 눈썹(32) → 12 → 칩 112 → 빈 띠 110 → 시작 윗변. 칩 220 × 112 dp, 칩 사이 13. 돌아가기 윗변까지는 127

시험장 시트 · 카드 바닥 → 24 → 시간 행 88 → 16 → 코스 행 88 → 빈 띠 133 → 예약 윗변. 시간·코스 라벨은 행 왼쪽 그대로

빈 띠 (Shelf)

눈썹 "모드" 를 빼고 칩 셋을 카드 행 바로 아래 왼쪽에 붙인다. 제휴 시험장 링크는 같은 줄 오른쪽. 버튼 행 위에는 넉넉한 빈 띠 하나만 남는다.

장점

  • 세로 줄이 카드 → 칩 → 버튼 셋뿐 — 화면에서 가장 단순한 리듬. 빈 띠가 약 160 dp 로 가장 넓다
  • "가이드 · 힌트 · 평가" 는 그 자체로 뜻이 분명해 눈썹 없이도 읽힌다(선택 칩이 Periwinkle 로 라벨 역할)
  • 시험장 시트는 시간·코스 라벨을 빼고 칩을 왼쪽 끝부터 — 시간 칩 셋이 시험장 카드 셋과 같은 열에 맞춰져 열이 정돈된다

주의점

  • 구현 쉬움 — 눈썹 제거·정렬·칩 폭 계산(시험장: 시간 칩 = 카드 폭, 코스 칩 = 4등분)
  • 눈썹이 사라지면 첫 사용자가 "이 칩이 무엇의 선택인지" 한 박자 늦을 수 있다 — 홈의 "가이드 모드" 문구가 보완
  • 시험장의 "시간 · 코스" 라벨 제거는 칩 내용(시간대·코스 이름)이 스스로 설명한다는 전제 — 계측(라벨 텍스트 검사)이 있으면 갱신

과제 시트 · 카드 바닥 → 24 → 칩 112 → 빈 띠 162 → 시작 윗변. 링크는 칩 행과 같은 높이 오른쪽 끝

시험장 시트 · 카드 바닥 → 24 → 시간 행 88(칩 폭 537 = 카드 폭) → 16 → 코스 행 88(칩 폭 396) → 빈 띠 133 → 예약

알약 트랙 (Segment)

모드를 눈썹 없이 라운드 21 ② 와 같은 알약 트랙 부품으로 — 폭은 카드 행의 절반, 한 줄로 압축해 카드 아래로. 링크는 같은 줄 오른쪽.

장점

  • 이미 있는 부품(분류 트랙)을 재사용 — 화면 전체의 "고르는 것은 알약 트랙" 문법이 하나로 통일된다
  • 칩 셋보다 한 덩어리라 "셋 중 하나" 가 더 분명하고, 트랙 전체가 터치 면이라 빗나가도 맞는다
  • 시험장은 시간 트랙(3칸)·코스 트랙(4칸)을 전체 폭으로 — 칩 폭을 따로 계산할 필요가 없다

주의점

  • 구현 쉬움 — 분류 트랙 컴포저블에 항목 수·폭 인자만. 단 트랙 높이는 88 dp 로 분류 트랙(96)보다 살짝 낮춰 위계 구분
  • 한 화면에 알약 트랙이 둘(분류·모드) — 위쪽 트랙이 "큰 분류", 아래가 "모드" 임을 폭(절반)과 위치로만 구분한다
  • 시험장 시트는 트랙이 둘 연달아 — 비는 시간대(흐린 글자)를 트랙 안에서 표현하면 "눌리지 않음" 이 칩보다 덜 보인다

과제 시트 · 카드 바닥 → 24 → 트랙 88(폭 832 = 카드 행 절반) → 빈 띠 186 → 시작 윗변

시험장 시트 · 카드 바닥 → 24 → 시간 트랙 88(전체 폭) → 16 → 코스 트랙 88 → 빈 띠 133 → 예약

모드 레일 (Rail)

모드 칩을 카드 행과 같은 열에 세로로 붙은 띠로 — 카드 행 바닥에 Lavender 레일(세 칸)이 한 몸으로 붙는다. 과제를 고른 손가락이 바로 아래에서 모드를 고른다.

장점

  • 시선·손가락 흐름이 "카드 → 바로 아래 모드 → 멀리 시작" 으로 한 방향. 모드가 과제의 속성이라는 뜻이 형태로 보인다
  • 카드와 레일이 한 덩어리가 되어 그 아래 빈 띠(약 150 dp)가 가장 또렷한 "경계" 가 된다
  • 시험장은 시간 레일 · 코스 레일이 카드 아래로 차례로 붙는다 — 카드 셋 폭 = 시간 칸 셋, 같은 열

주의점

  • 구현 중간 — 카드 행 아래 Row 를 같은 폭으로 붙이고 카드 그림자와 레일 그림자가 겹치지 않게 처리. 선택 카드의 빨간 체크 배지는 레일에 가리므로 카드 오른쪽 위로 옮긴다
  • 레일 칸이 넓어(칸당 555 dp) "칩" 처럼 보이지 않는다 — 선택 칸을 Periwinkle 로 채워야 눌리는 것임이 보인다
  • 라운드 21 확정 카드 C 의 바깥 형태(아래 제목 띠)는 유지되지만 카드 묶음 전체의 윤곽이 바뀐다 — 사용자 확인

과제 시트 · 카드 바닥 → 0 → 레일 88(세 칸 각 555 dp) → 24 → 제휴 시험장 링크(40) → 빈 띠 146 → 시작 윗변

시험장 시트 · 카드 바닥 → 0 → 시간 레일 88 → 0 → 코스 레일 88 → 빈 띠 175 → 예약

왼쪽 패널 (Panel)

모드 선택을 왼쪽 Ink 패널(차 일러스트 쪽) 하단으로 옮긴다 — Lavender 글자 알약 칩 셋. 오른쪽 Paper 는 과제 카드 · 시험장 링크 · 버튼만.

장점

  • 오른쪽 세로 줄이 카드 → 링크 → 버튼으로 줄고, 모드는 운전석(왼쪽)에서 가장 가까운 자리에 온다
  • 모드 칩과 돌아가기 · 시작이 같은 높이에 나란히 — "설정(왼쪽) → 출발(오른쪽)" 의 가로 흐름
  • Ink 위 Lavender 글자 칩은 포스터의 면 분할 안에 들어가 장식처럼 보이지 않고 패널 일부가 된다

주의점

  • 구현 중간 이상 — 왼쪽 패널은 지금 일러스트 전용 Box 라 칩을 얹으려면 패널 하단에 Ink 띠(약 180 dp)를 깔고 일러스트를 그만큼 위로 자른다. 홈 화면 패널과도 맞춰야 한다
  • 모드가 과제 열에서 떨어져 "이 모드가 저 과제의 것" 이라는 연결이 가장 약하다 — 홈 문구 "후면 직각 주차 · 가이드 모드" 가 보완
  • 시험장 시트는 시간만 왼쪽으로, 코스는 시험장마다 다르므로 카드 아래에 남긴다 — 두 시트의 왼쪽 패널 내용이 달라진다

과제 시트 · 왼쪽 패널: 눈썹 "모드"(Lavender 65%, 24 dp) → 12 → 칩 88 × 180 dp 셋(글자 Lavender · 선택 = Lavender 채움 + Ink 글자), 바닥 여백 75. 오른쪽: 카드 바닥 → 24 → 링크 → 빈 띠 186 → 시작

시험장 시트 · 왼쪽 패널: 눈썹 "시간" → 시간 칩 셋(88 × 216). 오른쪽: 카드 바닥 → 24 → 코스 행 88 → 빈 띠 237 → 예약

시안 A · 간격만 (Breathe)

돌아가기 · 시작을 한 픽셀도 옮기지 않고 칩 바닥과 시작 사이에 약 110 dp(손가락 두 개) 빈 띠를 만들며, 눈썹·순서·부품이 전부 그대로라 계측과 라운드 21 확정 사항을 건드리지 않는다. 칩 높이를 돌아가기와 같은 112 dp 로 올려 터치 면도 88 dp 를 넘긴다. 시험장 시트는 같은 규칙(행 사이 16, 버튼 위 133)으로 한 번에 끝난다. 세로 줄을 더 줄이고 싶으면 C 알약 트랙이 다음 후보.
