# 라운드 22 시안 — 공통 브리프 (2026-10-05 밤)

사용자가 동결 태그 `inhouse-20261006-1` APK 를 직접 눌러 보고 준 피드백(`docs/design/11_round22_feedback.md`) 중 "시안을 보고 고르고 싶다" 는 항목의 시안 페이지를 만든다. 각 페이지는 **정적 HTML 한 장**(외부 파일·폰트·스크립트 없이, 인라인 CSS/SVG 만 — `<script>` 금지, 보기 창이 스크립트를 돌리지 않는다), 브라우저 폭 1600px 에서 보기 좋게.

## 앱의 디자인 언어 (반드시 지킨다)

- 2560×1268 dp 가로 자동차 화면(실제 기기 2560×1440, 위아래 시스템 바). 시안은 화면을 **1/3 축소(853×423 px)** 하거나, 관련 부분만 같은 축척으로 잘라 보여 준다. 실제 크기 감각을 위해 "실제 화면은 약 3배" 를 페이지 위에 적는다.
- 색 토큰 다섯 개만: `--ink:#070827` `--paper:#FCFCFA` `--peri:#5B60A1`(Periwinkle) `--lav:#E5E6F0`(Lavender) `--signal:#F52D48`(빨강, 주 알약·선택 강조) + `--muted: rgba(7,8,39,.60)`. **새 색 금지.** 투명도 변형은 허용.
- 컨셉 = "기하학 포스터": 큰 면 분할(왼쪽 Ink 패널 + 오른쪽 Paper), 각진 면, 둥근 알약 버튼, 굵은 글씨 대신 크기 대비(Bold 금지 — font-weight 400/500 만).
- 질감 B(라운드 13 확정): 버튼·카드에 **살짝 그림자 + 위쪽 1px 하이라이트** — `box-shadow: 0 4px 10px rgba(7,8,39,.10), 0 1px 2px rgba(7,8,39,.06), inset 0 1px 0 rgba(255,255,255,.9)`. 모든 카드형 면에 이 그림자를 쓴다. 잠금 화면만 평면.
- 주 알약 = Signal 빨강, 흰 글자, 오른쪽 `→`, 높이 약 140 dp(1/3 축소 시 약 46px), **폭은 Setup `시작` 알약과 비슷하게 넉넉히**(1/3 축소 시 약 190px 이상). 보조 알약(라운드 21 ③ 확정) = Lavender 채움 + 질감 그림자, 높이 112 dp(1/3 축소 약 37px), `← 돌아가기`.
- 글자: 한국어. 눈썹(Eyebrow) 32 dp = 섹션 이름(예: "연습할 과제", Periwinkle). 본문 40 dp, 제목 72 dp. 1/3 축소 시 약 11/13/24px.
- 운전자 화면 문장에는 숫자를 넣지 않는다(점수·횟수·초). 단 **과제 시트 화면은 숫자 0**(계측이 검사한다). 리포트 "자세히 보기"·진단서·시간대 라벨(14:00–15:00)·거리(3 km)는 숫자 허용.
- 폰트: `"Noto Sans KR","Malgun Gothic","Apple SD Gothic Neo",system-ui,sans-serif`.
- 라운드 21 에서 확정된 것은 바꾸지 않는다: 분류 알약 트랙(주차·주행·점검·지식), 과제 카드 C(위 그림 면 + 아래 제목 띠), 보조 알약 `돌아가기`, Done 판정 2×2, 자세히 보기 두 회차 나란히.

## 페이지 형식

- 맨 위: 제목(주제), 한 줄 설명, **사용자 피드백 원문 인용**(`11_round22_feedback.md` 의 해당 항목 그대로).
- **지금** 한 칸(현재 캡처 `../../screenshots/lesson/<파일>.png` 를 `<img>` 로 1/3 크기) + 시안 A~E 칸(페이지마다 요청된 개수). 칸마다 **이름(한 단어 컨셉) · 한 줄 설명 · 장점 · 주의점(구현 난이도·운전 중 가독성)**.
- 시안끼리 같은 데이터(같은 문구)를 쓴다 — 차이가 배치·형태로만 보이게.
- 맨 아래: "추천" 하나와 이유 한 줄.
- 파일 이름: `docs/design/round22-proposals/<번호>-<주제>.html`. 페이지 안 링크는 상대 경로만.

## 앱 사실 (시안이 틀리게 그리지 않도록)

- 홈 화면: 왼쪽 차 일러스트, 오른쪽 눈썹 `연수생 · 장롱 10년차 · 목표 아이 등하원`(프로필 한 줄) → 제목 "오늘은 가볍게,\n주차부터 해 볼까요?" → `후면 직각 주차 · 가이드 모드` → 이유 한 줄 → 주 알약 `시작 →` → 글자 링크 `과제·모드 바꾸기`. 우상단에 접힌 시연 알약(`시연`), 맨 아래 `AI 코치 · <상태>` 줄.
- 과제 시트: 눈썹 `연습할 과제` → 분류 알약 트랙 → 눈썹 `주차 세부 과제` → 카드 넷 → 글자 링크 `제휴 시험장` → 눈썹 `모드` + 칩 셋(가이드·힌트·평가) → 같은 줄 아래 `← 돌아가기`(보조 알약) · `시작 →`(주 알약). `돌아가기`·`시작` 의 위치·크기는 그대로 둔다(사용자 지시).
- 제휴 시험장 시트: 눈썹 `제휴 시험장` → "예시입니다 — 실제 예약 연계 없음" → 지도 카드 셋(선택 = 빨간 테두리 6 dp, 카드 바탕은 안 바뀜) → 눈썹 `시간` + 시간 칩(14:00–15:00 …) → 눈썹 `코스` + 코스 칩 → 주 알약 `예약 →` → `← 돌아가기`.
- 진단서(리포트 안 페이지): 눈썹 `진단서` → "예시입니다 — 실제 전송·계약은 없습니다" → 왼쪽 눈썹 `공유 범위` + 라디오 셋(총점만 / 항목별 / 원시 신호, 각각 설명 한 줄) · 오른쪽 눈썹 `예상 혜택` + 줄 셋("보험료 할인 — 운전습관연계보험(UBI) 안전운전점수 연계 예시", "적성검사 일부 면제 — 운전 숙련 인증 연계 예시", "제휴 시험장 대여료 할인") → 글자 링크 `공유 예시 보기`(지금은 토스트 "예시 화면입니다" 만) → 아래 `← 돌아가기` · `다시 시작 →` 가 거의 붙어 있음.
- 자세히 보기: 두 회차 카드 나란히 + 변화량 칩, 그 아래 "다음엔 …" 한 줄, `← 돌아가기`, 맨 아래 고정 `신호 출처` 눈썹 + `실신호 0 · 시뮬레이션 8 · 미측정 0` + 오른쪽 "주차 과정만 측정했어요." 카드 안 지표 줄 `조향 왕복 3 · 기어 전환 2 · 근접 1 · 급정지 1` 이 카드 폭을 넘어 `1` 만 다음 줄로 떨어진다.
- 시연 패널(`시연` 알약을 누르면 오른쪽에 펼쳐짐): 눈썹 `시뮬레이션 신호` → 시나리오 칩(잘한 주차 / 못한 주차 …, 과제별) → 재생 상태 눈썹 → `정차`·`문 열기` 등 조작 → 맨 아래 `AI 코치 · <상태>`(+`AI 연결`). Real(사내) 빌드에서는 패널 자체가 없다(`demo == null`).
- 상태기계·채점은 바꾸지 않는다. 시안은 화면과 문구, 진입 흐름까지만.
