7b · 프로필 — 온보딩 + 시트 + 점진 조합

7번 시안에서 고른 세 결을 한 흐름으로 묶는 조합 다섯. 첫 실행은 A 의 모양과 흐름으로, 언제든 B 처럼 다섯 줄을 한눈에 보고 고치며, 빈 칸은 세션이 끝날 때마다 D 가 하나씩 채운다. 진술 다섯 · 칩 답 · 질문 데이터는 7번과 같다.

「프로필 시안 - A의 디자인 및 유저플로우 느낌이 좋고 B의 한 번에 보는 느낌도 좋고 C는 빼도 될 거 같아 초기 셋팅만 하는데 STT 대화 까지는 사치인 거 같아 D도 포함되면 좋을 거 같아 -> 결국 A+B+C 인데 이 구성으로 좋은 제안 5가지 정도 생각해서 제안해줘」— 사용자 결정, 라운드 22 (7-profile.html 을 보고)

해석: 원문은 "A+B+C" 지만 C(대화)는 빼고 D 를 넣으라고 했으므로, 이 페이지는 A(온보딩) + B(한눈 시트) + D(점진) 조합이다 — 대화·STT 없음.

모든 목업은 1/3 축척 · 실제 화면은 약 3배 (853×423 = 2560×1268 dp)답은 전부 칩 · 키보드·숫자 입력 없음
지금

프로필은 홈 눈썹 한 줄뿐이고 고정값(SeedCatalog.demoProfile)이다. 리포트 요약에는 질문을 받을 자리가 없다 — D 카드는 다시 시작 알약 위 빈 줄 자리에 들어간다.

P4

카드 덱

프로필 다섯 항목이 과제 카드 C 와 같은 문법(위 그림 면 + 아래 띠)의 카드다. 답한 카드는 채워지고, 빈 카드는 테두리만. 카드를 누르면 A 모양의 질문 한 장이 열리고, 답하면 덱으로 돌아온다. 덱 자체가 B 의 한눈 시트이고, 세션이 끝나면 D 가 빈 카드 하나에 빨간 점을 달아 리포트에서 묻는다.

화면 수
덱 1(첫 실행엔 전체 화면, 이후 시트) + 질문 화면 1 레이아웃 + 리포트 카드 1.
진입
첫 실행 덱 → 카드 → 질문 → 덱. 홈 눈썹 → 같은 덱. 리포트 카드에서 바로 답하거나 덱에서.
건너뛰기 처리
"나중에" 또는 몇 장만 채우고 "다 됐어요". 빈 카드는 테두리 + 세션 뒤 빨간 점, 답하면 점이 사라진다.
저장
앱 내부 profile.json — 질문 장에서 칩을 누를 때. 관리자 모드에서 초기화 · 시연 프리셋 "장롱 10년차" 로 복원.
시연 영향
프리셋으로 덱이 다 찬 채 시작. 과제 시트(카드 넷)와 모양이 닮아 영상에서 "과제 고르기" 로 오해할 수 있어 설명 한 줄 필요.
난이도
중~상. 부품 넷(프로필 카드 · 덱 · 질문 화면 · 새 카드 점) + 덱 ↔ 질문 왕복.

장점

  • 앱에서 이미 배운 카드 문법 — 새 모양을 배우지 않는다. 그림 면이 있어 가장 "포스터" 답다.
  • 답할 순서를 운전자가 고른다. 빨간 점이 D 의 "새로 생긴 것" 을 조용히 알린다.

주의점

  • 탭이 가장 많다(카드 → 칩 → 돌아옴) — 다섯 다 답하면 열하나.
  • 과제 카드와 혼동 — 덱 화면엔 분류 알약 트랙을 두지 않아 구분.

홈 통합

따로 온보딩 화면이 없다. 첫 실행에 홈의 오른쪽 칼럼 — 눈썹 · 제목 · 시작 알약 자리 — 가 A 흐름의 질문 셋(무서운 상황 · 마지막 운전 · 필요한 일)을 차례로 보여 주고, 셋째 답 뒤 제목이 "오늘은 가볍게, 주차부터 해 볼까요?" 로 바뀌며 평소 홈이 된다. 시트는 B, 남은 둘은 D.

화면 수
새 화면 0 — 홈의 "질문 상태" 하나 + 프로필 시트 1 + 리포트 카드 1.
진입
프로필 파일이 없을 때 홈이 질문 상태로 열린다. 눈썹 → 시트. 카드는 리포트 요약.

저장

시연 영향

주의점
