# 컬러 테마 확장 초안 — 채택 보류

2026-09-26

사용자는 최초 한 페이지 비교 중 **기하학 포스터**를 선호했고, 이후 추가한 주차 안내·리포트·레이어 보드에는 기존 흑백 종이 컨셉이 남아 있어 만족스럽지 않다고 평가했다. 따라서 이 폴더의 확장안은 최종 UI 제안으로 채택하지 않는다.

기존 산출물과 프롬프트는 비교 이력으로 보존한다. 설정 복사본은 각 첫 비교 시안과 동일하고, 나머지는 내장 image_gen으로 생성한 초안이다. 레이어 보드 v2는 바퀴 중복에 대한 수정 시도이며, 사용자 방향 전환에 따라 최종 검토·채택을 진행하지 않았다.

다음 작업은 [최초 기하학 포스터](../02-geometric-poster-v1.png)의 큰 색면, 과감한 크롭, 비대칭 구도를 중심으로 앱 전체 흐름을 다시 설계하는 것이다. 흑백 B안 선호는 흑백 안들 사이에서의 기록으로 유지한다.
