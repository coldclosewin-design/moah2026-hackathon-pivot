# 디자인 레퍼런스

사용자가 모은 이미지·링크. `../02_design_brief.md` "채울 것" 표의 근거. 파일 하나에 한 줄씩 **무엇이 좋은지** 적는다.

- 사내 자료(infoLINK·Template App·M.ADI 화면)는 넣지 않는다(정책).
- 이미지는 `png`/`jpg`, 큰 것은 폭 1600 px 이하로.
- 링크만 있는 것은 아래 표에.

| 파일/링크 | 무엇이 좋은가 | 어느 화면에 |
|---|---|---|
| `../geometric-poster-development/01-setup-v1.png` | **채택 기준.** 크게 잘린 자동차, 남색·흰색 큰 색면, 문장 하나 + 빨간 버튼 하나 | Setup, 전체 시각 규칙 |
| `../geometric-poster-development/steering-alternatives/b-oblique-rim-v1.png` | 핸들 B · 사선 단면 — 사용자 선호("두 번째가 좋은 거 같아"). 설정 자동차와 같은 원근·크롭 | Briefing |
