# 디자인 탐색 인덱스

2026-09-26 · 생성 시안, 프롬프트, 사용자 선택 기록

현재 앱 UI의 기준은 **기하학 포스터**다. 큰 남색·흰색 색면, 과감한 크롭, 비대칭 구도와 제한된 빨간 행동 포인트를 사용한다. 실제 구현 범위와 검증은 UI 라운드별 PR에서 다룬다.

| 순서 | 탐색 기록 | 사용자 피드백·선택 |
|---|---|---|
| 1 | [종이 UI](paper-ui/README.md) · [첨부 레퍼런스](references/) | TOEM 손그림과 미색 종이 레이어를 탐색했다. 주차 안내와 레이어 구성은 긍정 평가했고, 설정·리포트의 과한 채움·정보량·무거운 제목은 줄이기로 했다. 대표본은 설정 v2 / 주차 v2 / 리포트 v1 / 보드 v3다. |
| 2 | [미니멀 A/B/C](paper-ui/minimal-explorations/README.md) | 흑백 후보 중 **B · 가벼운 대화**를 선호했다. 가벼운 제목, 작은 선 그림, 여백 중심의 대화형 구성이다. 실제 폰트 파일을 확정한 것은 아니다. |
| 3 | [Pinterest 컬러 3안](pinterest-concepts/README.md) | 밤의 청록 실루엣 / 남색·빨강 기하학 포스터 / 파랑·주황 손그림을 비교해 **최초 기하학 포스터**를 디벨롭 기준으로 선택했다. 링크가 직접 읽히지 않아 제공된 첨부 스틸을 시각 근거로 삼았다. |
| 4 | [기하학 포스터 디벨롭](geometric-poster-development/README.md) | 큰 색면·선명한 대비·절제된 인터페이스를 설정·준비·주차·리포트로 확장했다. [이전 컬러 확장 초안](pinterest-concepts/full-sets/README.md)은 흑백 종이 컨셉을 차용한 인상이 남아 채택하지 않고 비교 이력으로 보존했다. |
| 5 | [핸들 A–D](geometric-poster-development/steering-alternatives/README.md) | 준비 화면의 핸들이 너무 미니멀하다는 피드백으로 설정 자동차 수준의 묘사 밀도를 보강했다. 형태 4안 중 두 번째 **B · 사선 단면**을 선호해 전체 컨셉 모음의 대표 이미지로 반영했다. 준비 v1·디테일 보강 v2도 보존했다. |

> “흑백테마 중에서는 B 가벼운 대화 타입이 제일 좋은 거 같아.”
>
> “기하학 포스터가 마음에 들어서 그것을 디벨롭해서 전반적인 UI 구성을 제안 받고 싶어.”
>
> 핸들 대안: “두 번째가 좋은 거 같아.”

흑백 B 선택은 흑백 후보 사이의 기록으로 유지하며, 현재 구현 방향은 최초 기하학 포스터다. 모든 이전 이미지와 전체 생성·수정 프롬프트를 각 폴더에 보존했다. 이 자료는 디자인 탐색 결과이며 실제 차량의 가독성·터치·주행 사용성을 검증한 결과는 아니다. 이미지의 글자는 시스템 폰트 구현을 위한 견본이며 별도 폰트 파일을 도입하지 않았다.

이 인덱스는 작업 트리에 있던 `NEXT.md`, `journal/2026-09-26.md`, `journal/README.md`의 디자인 세션 변경을 옮겨 보존한 것이다. 해당 세 문서의 최신 통합 기록은 Claude가 관리한다.
