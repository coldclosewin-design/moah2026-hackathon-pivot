# 디자인 브리프 — 운전 연수 어시스턴트 UI 재설계 (2026-09-26, 채움 — 기준: 기하학 포스터)

첫 화면 5장(PR #5)은 **기능 확인용 보편 UI**다. 이 문서는 사용자의 레퍼런스로 전반 디자인을 다시 잡을 때 Codex 발주서가 가리키는 한 장이다. 아래 "채울 것" 은 사용자가 레퍼런스와 함께 답하고, "지켜야 할 것" 은 디자인이 어떻게 바뀌어도 변하지 않는다.

## 순서 (16번 UI 컨셉 방식의 축소판)

| 라운드 | 무엇 | 산출물 | 합격 기준 |
|---|---|---|---|
| 0 | 이 브리프 + `references/` | 사용자 답 + 이미지 | — |
| 1 | **핵심 2화면**(`Maneuver`·`Report`)만 새 디자인, 드래프트 PR | `tools/lesson_shots.sh` 캡처 → 사용자 방향 확정·수정 지시 | `Lesson contract passed` |
| 2 | 5화면 + 시연 패널 전체 적용 | PR → 리뷰 → 머지 | `lesson_shots.sh` PASS + `emu_flow.sh` PASS·clashes 0 |
| 3 | 시연 영상 B안 녹화, 덱 스크린샷 교체 | | |

라운드 1 에 **경쟁 시안을 여러 개 만들지 않는다** — 레퍼런스가 있으므로 방향은 하나, 미리보기로 톤을 맞춘다. 두 방향이 갈리면 그때만 2안.

## 채울 것 (사용자 — 레퍼런스와 함께)

| 항목 | 질문 | 답 |
|---|---|---|
| 레퍼런스 | `references/` 의 이미지·링크·앱 이름. 각각 **무엇이 좋은지 한 줄** | **기하학 포스터**(`geometric-poster-development/`, 시안 4장 + 핸들 B). 사용자가 Pinterest 3안 중 "큰 색면·선명한 대비·절제된 인터페이스" 로 고름. 종이 UI·미니멀 A/B/C 는 탐색 이력(`design/README.md`) |
| 온도 | 계기판처럼 차갑게 ↔ 종이·손글씨처럼 따뜻하게 | 편집 디자인·포스터 톤 — 그래픽은 차갑고 곧게, **문장은 따뜻하게**("서두르지 않아도 괜찮아요"). 손글씨·종이 질감은 버림 |
| 밀도 | 정보를 한 화면에 많이 ↔ 한 단어씩 크게 | **한 화면에 문장 하나, 값 두 개.** 나머지는 "자세히 보기" 뒤로. 카드·표 반복 금지 |
| 도식 | 위에서 본 차가 사실적(실루엣·바퀴 회전) ↔ 아이콘·다이어그램 | `Maneuver` 는 **평면 기하 도식**(흰 차체·보랏빛 바퀴 막대 4개, 앞바퀴만 회전, 빨간 후진 화살표). 주차 칸·경로·센서 호는 그리지 않음. 설정·준비의 자동차·핸들은 **장식 일러스트**(실시간 값 아님) |
| 색 | 배경 어둡게 유지? 강조색 하나? 나빠진 것을 붉게 하지 않는 톤 규칙은 유지 | 바탕은 **흰색**(`#FCFCFA`)으로 전환, 큰 남색(`#070827`) 덩어리, 보랏빛(`#5B60A1`) 보조, 옅은 구분선(`#E5E6F0`), 빨강(`#F52D48`)은 **주 행동 버튼과 화살표에만**. 나빠진 값은 회색 — 규칙 유지. **예외(9/28, 라운드 6 시안 05)**: 과제 시트 1층의 펼친 카테고리 글자·밑줄·▼ 와 선택 칸의 체크 원 — 정차 중 선택 화면 한 곳에 한정 |
| 글자 | 제목·본문·자막의 위계. (서체는 시스템 기본만 — 아래) | Regular 400 중심, 수치만 Medium 500, Bold 금지. 메인 문장 72–88 sp · 수치 80–96 · 본문 40 · 보조 32(하한). 자막 = 메인 문장(별도 자막 바 없음) |
| 모션 | 힌트가 뜨고 사라지는 방식, 회차 멘트 등장, 리포트 게이지 채워짐 — 얼마나 움직일지 | **최소.** 힌트는 페이드 인/아웃(4 s), 화면 전환은 색면이 옆으로 밀리는 한 동작(≤ 300 ms), 게이지 없음(큰 숫자만). ✅ 사용자 확인 2026-09-26 |
| 싫은 것 | 지금 화면에서 바꾸고 싶은 것, 레퍼런스에서 가져오지 말 것 | 어두운 녹색 바탕·둥근 카드 여러 장·원형 게이지·굵은 제목(지금 화면). 종이 섬유·찢은 모서리·손그림 윤곽·겹친 기록장·입체 그림자(종이 UI). 시안의 글자는 견본일 뿐 — 폰트 파일 도입 금지 |
| 조수석 | 자막 판("조수석")의 인격 — 말풍선? 자막바? 이름 표시? | 말풍선·아바타·이름 없음. 읽는 영역에 눈썹 `조수석` + 큰 문장. 목소리는 화면이 아니라 문장 톤으로 |

답은 2026-09-26 Codex 디자인 세션의 시안 README 와 사용자 선택에서 도출했다. 라운드 1 발주서: `docs/handoffs/2026-09-26_codex_ui_round1.md`.
