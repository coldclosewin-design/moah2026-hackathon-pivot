자세히 보기 — 다섯 가지 구성

리포트 "자세히 보기"의 오른쪽 면만 다시 짠다. 왼쪽 포스터(연습한 회차 02)는 그대로 두고, 모든 카드에 질감 그림자를 쓴다.

사용자 피드백 (라운드 21)너무 많은 정보가 한 곳에 있어서 UX/UI 관점을 적용하여 … 전반적인 디자인 컨셉을 해치지 않는 이쁜 구성을 5가지 정도 제안
시안은 1/3 축소(853×423 px) — 실제 화면은 약 3배(2560×1268 dp). 이 화면은 숫자 허용.

시안 A

나란히

회차마다 카드 한 장. 두 카드를 좌우로 세우고 가운데 화살표로 "전 → 후"를 읽게 한다.

장점

  • 같은 지표가 같은 높이에 있어 눈을 가로로만 움직이면 비교가 끝난다.
  • 최근 회차 카드에 Periwinkle 윗선과 변화량(+40, −2) 칩 — 좋아진 것이 색으로 먼저 보인다.
  • 코스 버전도 같은 틀(점수·합격 칩·감점 목록)에 그대로 들어간다.

주의점

  • 회차가 셋 이상이면 카드가 좁아진다 — "첫 회차 vs 최근 회차" 두 장만 보이고 나머지는 숨겨야 한다.
  • 구현 난이도 낮음(Row 두 개). 주차 중이 아니라 정차 화면이라 가독성 문제 없음.

시안 B

표

행 = 지표, 열 = 회차. 더 나은 쪽 칸만 Lavender 알약으로 칠한다.

장점

  • 정보량은 지금과 같지만 줄 맞춤 하나로 정리돼 가장 "정확해" 보인다 — 진단서와 같은 언어.
  • 점수 두 줄은 크게, 과정 일곱 줄은 작게 — 위계가 표 안에서 해결된다.
  • 코스 버전은 행 = 구간으로 바꾸면 그대로 맞는다(감점 사유가 회차 열에 들어감).

주의점

  • 포스터 감성보다는 문서 느낌 — "이쁜" 쪽으로는 C·A보다 덜하다.
  • 회차 열은 셋까지가 한계(그 이상은 첫·최근만). 코스 표는 "어느 회차에서든 감점된 구간"만 행으로 둔다.
  • 구현 난이도 낮음(고정 열 너비 Row 반복).

시안 C

막대

맨 위는 큰 숫자 두 개(결과), 그 아래 카드 한 장에 지표마다 회차별 가는 막대 두 줄(과정).

장점

  • "결과 → 과정" 읽는 순서가 크기로 정해진다. 막대 길이만 보면 숫자를 안 읽어도 좋아진 게 보인다.
  • 숫자는 막대 끝에 작게 남아 정보량은 그대로 — 진단서 수준의 정확도 유지.
  • 코스 버전은 합격선 점선 하나로 "왜 불합격이었나"가 그림으로 설명된다. 포스터 컨셉(면·선)과 가장 잘 어울린다.

주의점

  • 막대는 지표별로 그 지표의 최댓값에 맞춰 늘인다(지표끼리 길이 비교 불가) — 범례에 "짧을수록 좋아요"를 꼭 둔다.
  • 0 값은 점(5px)으로 그린다. 회차가 셋 이상이면 막대 줄이 늘어 높이가 빠듯 — 첫·최근 두 줄로 제한.
  • 구현 난이도 중간(Canvas 없이 Box 너비 비율로 충분).

시안 D

탭

요약 / 회차 / 신호 출처를 작은 탭(설정 화면 "모드" 타일과 같은 모양)으로 나눠 한 번에 한 가지만 보인다.

장점

  • 한 화면의 정보량이 가장 적다 — 피드백("한 곳에 너무 많다")에 가장 직접적인 답.
  • 요약 탭은 큰 숫자 + 핵심 변화 네 개뿐이라 첫인상이 깔끔하다.
  • 회차가 늘어도 회차 탭만 길어진다(스크롤) — 확장성 좋음.

주의점

  • 신호 출처 자세한 설명이 세 번째 탭으로 숨는다 — "실신호/시뮬레이션을 정직하게 보여 준다" 원칙이 약해지지 않게, 요약 탭 아래에 개수 한 줄은 남겼다(시안).
  • 터치 한 번이 더 든다(정차 화면이라 허용 범위). 상태(선택 탭) 하나가 늘어 구현 난이도 중간.
  • 요약 탭에 무엇을 올릴지(네 개 고르기) 규칙이 필요하다 — 변화량 큰 순 등.

시안 E

펼침

회차마다 접힌 카드 한 줄. 최근 회차만 펼쳐 세부 지표를 타일로 보이고, 나머지는 눌러야 펼친다.

장점

  • 지금 화면의 "회차 줄" 구조를 그대로 살려 Codex 구현 변경이 작다(행 → 카드 + 펼침).
  • 접힌 줄은 요약 한 줄뿐이라 화면이 가볍고, 신호 출처도 같은 카드 규칙으로 정리된다.
  • 회차가 많아도 카드가 아래로 쌓일 뿐이라 확장성 좋음.

주의점

  • 회차 사이 비교는 펼쳐서 위아래로 봐야 한다 — "좋아진 것"이 A·C만큼 즉시 보이지 않는다.
  • 펼침 상태·애니메이션 관리가 필요(난이도 중간). 계측 테스트가 펼침 전후를 모두 잡아야 한다.
추천
C · 막대

결과(큰 숫자) → 과정(막대) 순서가 크기만으로 정해져 같은 정보량이 "한 곳에 몰린" 느낌 없이 읽히고, 코스 버전도 합격선 점선 하나로 같은 틀에 들어간다.

회차가 셋 이상이면 "첫 회차 · 최근 회차" 두 줄만 막대로 그리고, 신호 출처는 맨 아래 한 줄로 항상 보이게 둔다. 문서 느낌을 원하면 B(표)가 차선.
