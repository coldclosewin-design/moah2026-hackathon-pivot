제휴 시험장 카드 — 시안 다섯 가지

서초 · 강남 · 분당 카드를 크고 읽기 쉽게, 그림자로 입체감 있게. 시간·코스는 카드 아래로 밀려나도 괜찮다는 전제로 다시 배치했다.

사용자 피드백 (원문) 카드(서초/강남/분당) 색깔도 너무 단조로워서 카드에 그림자 효과로 약간의 입체감과 안에 카드 내용이 너무 가독성 가시성이 떨어지고 크기가 작아 눌려담긴 느낌이 강하여 시간/코스를 아래로 배치하는 한이 있어도 카드를 좀 이쁘고 내용이 잘 담긴 것으로 5가지 정도 샘플로 제안 받아서 리뉴얼 하고 싶어

평면 Lavender 상자 셋

세 카드가 같은 Lavender 면에 글자 네 줄을 눌러 담았다. 선택은 얇은 Periwinkle 테두리 하나.

보이는 문제

  • 카드 높이 약 220 dp 안에 이름·거리·코스·자리 네 줄 — 줄 간격이 없어 눌린 느낌
  • 지역 이름과 "서초 · 3 km" 가 같은 지역명을 두 번 말한다
  • 코스가 한 줄 문장이라 넘치면 잘린다(장내기능 모의시험이 추가되면 더 길어짐)
  • 선택 표시가 1~2 px 테두리뿐 — 운전석 거리에서 어느 카드가 골라졌는지 약하다
  • 카드 아래 빈 띠(약 400 dp)가 남는데도 카드는 작다

캡처는 장내기능 모의시험 추가 전. 시안은 서초 코스 넷(주차 3종 · 도로 A · 도로 B · 장내기능 모의시험) 기준.

시안 A

들림 (Lift)

Paper 카드를 그림자로 띄우고, 지역 이름을 제목 크기로 키우고, 거리는 알약·코스는 작은 태그로 나눈다.

장점

  • 과제 시트의 과제 카드와 같은 선택 문법(Periwinkle 채움 + 빨간 체크) — 앱 안에서 한 가지 규칙
  • 정보가 "이름 / 거리 / 코스 / 자리" 네 층으로 갈라져 한눈에 읽힌다
  • 코스가 태그라 넘쳐도 줄바꿈될 뿐 잘리지 않는다
  • 시간·코스는 "라벨 + 칩" 한 줄씩으로 접어 카드 키운 만큼 아래로 내려도 예약 알약과 겹치지 않는다

주의점

  • 구현 쉬움 — 기존 카드에 그림자·태그 행·체크 배지만 추가
  • 태그 글자 33 dp 안팎 — 정차 화면이라 괜찮지만 이보다 작게 줄이지 않는다
  • 세 카드가 모두 같은 색(Paper)이라 "단조로움" 이 완전히 사라지지는 않는다

선택 표시 · Periwinkle 채움 + 흰 글자 + 아래 가운데 빨간 체크(과제 카드와 같음)

시안 B

지도 (Track)

카드 위쪽에 Ink 미니 트랙 지도를 얹고, 아래 Paper 에 이름·코스·자리를 적는다. 거리는 지도 위 알약.

장점

  • 세 시험장이 그림으로 서로 달라 보인다 — 단조로움 해소가 가장 크다
  • Ink 띠가 왼쪽 Ink 패널과 이어져 "기하학 포스터" 와 잘 맞는다
  • 선택하면 지도 위 경로가 빨갛게 — "이 코스를 탄다" 는 의미가 읽힌다

주의점

  • 구현 중간 — 시험장마다 지도 모양 데이터(또는 Canvas 경로) 필요. 지금 있는 코스 지도 데이터를 줄여 쓰면 된다
  • 지도 썸네일은 정확한 축척이 아니라 "모양 표시" 임을 지켜야 한다(가짜 정밀도 금지)
  • 코스 목록이 두 줄 회색 글씨 — 태그(A)보다 한 단계 약하다

선택 표시 · 빨간 테두리 2 px(실제 6 dp) + 지도 경로가 Signal 로 바뀜

목록 (Rows)

시험장 하나 = 가로 한 줄. 왼쪽 이름, 가운데 코스 태그, 오른쪽 거리·자리. 가까운 순으로 위에서 아래.

장점

  • 가로 폭을 다 쓰니 코스 태그 넷이 한 줄에 다 들어간다 — 잘림·줄바꿈 없음
  • 거리가 오른쪽 끝에 세로로 정렬돼 "어디가 가까운가" 비교가 가장 쉽다
  • 시험장이 늘어나도(넷·다섯) 같은 틀로 늘어난다

  • 구현 쉬움 — Row 세 개
  • 줄 높이 약 140 dp — 터치는 충분하지만 "카드" 의 존재감은 A·B·E 보다 약하다
  • 설정 화면 같은 표 느낌이 나서 포스터 콘셉트와는 거리가 조금 있다

시안 D

펼침 (Expand)

고른 시험장 카드가 넓게 펼쳐져 그 안에 시간·코스를 담는다. 나머지 둘은 오른쪽에 작게 쌓인다.

장점

  • "이 시험장의 시간·코스" 라는 소속이 그림으로 분명 — 코스 목록과 코스 칩이 중복되지 않는다
  • 펼친 카드가 화면의 주인공이라 크기·여백이 가장 넉넉하다
  • 시간·코스가 별도 줄로 떠다니지 않아 아래 빈 띠가 없어진다

주의점

  • 구현 어려움 — 선택이 바뀔 때 카드 크기·위치가 바뀌는 전환 애니메이션, 아무것도 안 고른 첫 상태 디자인(세 카드 같은 크기)이 따로 필요
  • 카드를 바꿀 때 시간·코스 선택이 초기화되는 규칙을 정해야 한다
  • 계측(androidTest)이 찾는 시간·코스 노드 위치가 바뀐다 — Codex 테스트 수정 동반

선택 표시 · 카드 자체가 넓어짐 + 위쪽 빨간 띠. 작은 카드는 "고르지 않은 것"

시안 E

포스터 (Poster)

Ink 카드에 지역 이름을 아주 크게(약 120 dp), 모서리에 시험장마다 다른 기하 도형. 왼쪽 Ink 패널과 한 벌.

장점

  • 가장 "포스터" 답다 — 왼쪽 일러스트와 같은 Ink 면이라 화면 전체가 하나의 구도
  • 지역 이름이 커서 운전석에서도 "서초" 가 바로 읽힌다
  • 도형(원·삼각·사각)이 시험장을 구분하는 기억 단서가 된다

주의점

  • 구현 쉬움~중간 — 도형은 Canvas 한두 줄. 어두운 면 위 Lavender 글씨 대비는 지켜야 한다(투명도 .7 아래로 내리지 않기)
  • Ink 면이 셋 늘어 화면이 무거워진다 — 아래 칩(Lavender)과 무게 차이가 크다
  • Ink 카드는 화면 다른 곳에 없는 형식이라 잠금 화면 Ink 와 혼동되지 않게 그림자를 꼭 유지

선택 표시 · 모서리 도형이 Signal 로 바뀜 + 아래 빨간 띠. 고르지 않은 카드는 Periwinkle 도형

추천

시안 A · 들림 — 여유가 있으면 B 의 미니 지도를 A 카드 위에 얹기

과제 카드와 같은 선택 문법(Periwinkle 채움 + 빨간 체크)이라 앱 전체 규칙이 하나로 맞고, 구현이 가장 가벼우면서 "크게 · 층을 나눠 · 그림자" 세 요구를 다 채운다. 단조로움을 더 덜고 싶으면 B 의 지도 띠만 더하면 된다.
