장점

판정 패널

맞았나·틀렸나는 왼쪽 Ink 포스터가 크게(✕ Signal / ✓ Paper 굵은 선) 말하고, 오른쪽은 A의 카드 안 배지 + 해설 카드 + 넓은 알약으로 차분하게 둔다.

장점

  • 결과가 화면에서 가장 큰 그림이 된다 — 리포트·Done 화면의 "왼쪽 포스터가 말한다" 컨셉과 같은 문법.
  • 오른쪽은 A와 같아 "내 답 / 정답" 위치·크기 정렬 문제가 함께 풀린다(배지가 카드 안 오른쪽 끝, 같은 크기).
  • 문제 화면 → 정답 화면 전환에서 오른쪽 배치가 그대로라 끊김이 없다. 왼쪽 "02"만 ✕/✓ 로 바뀐다.

주의점

  • 큰 문항 번호 "02"가 정답 화면에서는 사라진다(진행은 "2 / 10"으로 남음).
  • 왼쪽 패널에 상태 하나(문제 / 맞음 / 틀림)가 생겨 구현 난이도 중간. ✕ 는 Signal, ✓ 는 Paper — 색 토큰 추가 없음.
추천
E · 판정 패널

결과는 왼쪽 포스터가 크게, 근거(보기·해설)는 오른쪽이 차분하게 — 역할이 갈려 간격이 자연스럽고, 카드 안 배지로 "내 답 / 정답" 위치·크기가 한 줄로 맞는다.

알약은 "시작"과 같은 240×46px(실제 720×140 dp)로 오른쪽 아래 고정. 왼쪽 판정 그림이 부담스러우면 A(배지)만 단독으로 적용해도 정렬 문제는 해결된다.
