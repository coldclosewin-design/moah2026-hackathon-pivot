과제 분류 메뉴 (주차 · 주행 · 점검 · 지식) — 시안 다섯 가지

"연습할 과제" 눈썹과 메뉴 사이를 띄우고, 이것이 누르는 메뉴라는 것을 분명히 보이되 기하학 포스터 콘셉트를 벗어나지 않게.

사용자 피드백 (원문) 연습할 과제 상위 제목과 조금 가깝게 배치되어 있어 살짝 내려오도록 조정이 필요하고 살짝 단조로워서 메뉴임을 확실히 나타내면서 컨셉디자인과 이질감이 없는 제안을 5가지 정도 받고 수정 진행하고 싶어
아래 화면은 모두 실제의 1/3, 과제 시트 윗부분만 잘라 보임 — 실제 화면은 약 3배

공통 조건 · 과제 시트에는 숫자를 하나도 넣지 않는다(계측이 검사) — 번호 매김 없음 · 네 칸은 오른쪽 폭(약 1664 dp)을 정확히 4등분(칸당 약 416 dp) · "주행" 의 (10/4 부터 모든 과제가 시작 가능 — "준비 중" 표시는 없다.)

지금

큰 글자 넷 + 빨간 밑줄

눈썹 바로 아래 Periwinkle 큰 글자 넷. 고른 것만 Signal 글자 + 짧은 밑줄 + 작은 아래 삼각형.

보이는 문제

  • 눈썹 "연습할 과제" 와 메뉴 글자 사이가 약 25 dp — 제목과 메뉴가 한 덩어리로 붙어 보인다
  • 고르지 않은 셋은 그냥 큰 글씨라 "누를 수 있다" 는 단서(틀·면·선)가 없다
  • 네 칸의 경계가 보이지 않아 "같은 폭 4등분" 이 느껴지지 않는다
  • 메뉴 아래 "주차 세부 과제" 제목과의 위계도 약하다(크기만 다름)

시안 A

알약 트랙 (Segment)

Lavender 알약 트랙 하나에 네 칸. 고른 칸에 Periwinkle 알약이 그림자와 함께 올라앉는다.

장점

  • "넷 중 하나를 고르는 스위치" 라는 뜻이 가장 확실 — 자동차 공조·주행 모드 UI 와 같은 문법
  • 알약 모양이 화면의 주 알약(시작 →)과 같은 형태 언어라 이질감이 적다
  • 트랙 전체가 터치 면이라 손가락이 빗나가도 맞는다

주의점

  • 구현 쉬움 — Row + weight(1f) 네 칸, 고른 칸 배경만 애니메이션
  • 글자가 트랙 안에 들어가 72 → 약 56 dp 로 작아진다
  • 선택 색이 Periwinkle 이라 바로 아래 고른 과제 카드(Periwinkle)와 색이 겹쳐 메뉴와 카드의 위계가 비슷해 보일 수 있다

선택 표시 · Periwinkle 알약 + 흰 글자 + 질감 그림자. 빨강은 쓰지 않는다

네 칸 같은 폭 · 트랙 안쪽을 정확히 4등분, 알약 자체가 칸 폭 — 경계가 저절로 보인다

시안 B

기호 탭 (Glyph)

각 메뉴 위에 기하 기호 하나 — 주차 = 사각(칸), 주행 = 가로선 화살표(앞으로), 점검 = 원, 지식 = 삼각. 아래에 가는 바닥선.

장점

  • "기하학 포스터" 콘셉트를 메뉴 자체로 옮긴다 — 원·사각·삼각·선이 왼쪽 일러스트의 면 분할과 같은 언어
  • 기호 + 글자 두 단서라 운전석에서 위치로 기억하기 쉽다(숫자 없이도 구분)
  • 고른 것만 기호가 Signal 로 "채워짐" — 빈 도형 / 찬 도형 대비가 분명
  • 지금 구조(글자 + 짧은 빨간 밑줄)를 그대로 살려 변경 폭이 작다

주의점

  • 구현 쉬움 — 기호 넷은 Canvas 한두 줄씩. 아이콘 리소스 추가 없음
  • 기호의 뜻(삼각 = 지식)은 임의적 — 장식으로 읽히고 설명이 필요할 수 있다
  • 메뉴 높이가 약 60 dp 늘어난다 — 아래 카드 줄도 그만큼 내려간다

선택 표시 · 기호 Signal 채움 + 글자 Signal + 바닥선 위 짧은 Signal 막대(지금의 삼각형 대신)

네 칸 같은 폭 · 4등분 칸 가운데 정렬, 전체 폭 바닥선이 네 칸을 한 줄로 묶는다

시안 C

카드 탭 (Tile)

네 메뉴를 질감 그림자가 있는 Paper 타일로. 고른 타일은 Ink 로 채우고 아래로 작은 삼각 꼭지가 세부 과제를 가리킨다.

장점

  • "누르는 것" 이라는 단서가 가장 강하다 — 모든 칸이 버튼처럼 떠 있다
  • Ink 채움은 아래 과제 카드(Periwinkle·Lavender)와 다른 색이라 "상위 메뉴" 위계가 분명
  • 지금의 아래 삼각형을 꼭지로 살려 "이 메뉴의 세부 과제" 연결이 그대로

주의점

  • 구현 쉬움 — 기존 모드 칩(가이드·힌트·평가)과 같은 컴포넌트 재사용 가능
  • 카드(메뉴) 아래 또 카드(과제) — 면이 많아져 화면이 빽빽해질 수 있다
  • Ink 면이 왼쪽 패널 외에 하나 더 생겨 시선이 메뉴로 많이 끌린다

선택 표시 · Ink 채움 + 흰 글자 + 아래 삼각 꼭지. 빨강은 쓰지 않는다

네 칸 같은 폭 · 타일 네 개를 같은 weight 로, 틈 24 dp — 칸 경계가 면으로 보인다

시안 D

굵은 막대 (Rule)

글자는 지금 크기 그대로, 아래에 전체 폭 가는 선. 고른 칸은 칸 폭 전체에 굵은 Signal 막대가 얹힌다.

장점

  • 지금 모습에서 가장 적게 바뀐다 — 사용자가 익숙한 큰 글자 유지(72 dp)
  • 막대가 칸 폭 전체라 "4등분 탭" 이 또렷 — 칸 사이 얇은 세로 구분선도 더했다
  • 각진 막대 + 가는 선 = 포스터의 면 분할 문법

주의점

  • 구현 가장 쉬움 — 밑줄 폭·두께만 바꾸고 선 하나 추가
  • "메뉴임" 을 알리는 단서가 선 하나라 C·E 보다 약하다 — 단조로움 해소가 가장 작다
  • 질감 그림자를 쓸 면이 없다(막대는 평면)

선택 표시 · 칸 폭 전체 Signal 막대(약 15 dp 두께) + 글자 Ink. 나머지 글자 Periwinkle

네 칸 같은 폭 · 막대 길이 = 칸 폭이라 선택이 옮겨 갈 때 막대가 정확히 한 칸씩 미끄러진다

시안 E

폴더 탭 (Index)

서류철 색인 탭처럼 — 고른 탭이 아래 세부 과제 판과 한 장으로 이어지고, 나머지 탭은 뒤에 꽂힌 Lavender 탭.

장점

  • "이 탭의 내용이 아래 판" 이라는 관계가 형태로 보인다 — 메뉴임이 가장 분명
  • 세부 과제·카드가 그림자 진 판 위에 놓여 화면 위계가 셋(메뉴 / 판 / 카드)으로 정리된다
  • 고른 탭 위쪽의 얇은 Signal 선이 지금의 빨간 밑줄 역할을 이어받는다

주의점

  • 구현 중간 — 탭과 판의 이음매(그림자 끊기)를 커스텀 Shape 로 처리해야 깔끔하다
  • 판이 아래쪽 모드·시작 알약 영역까지 감싸면 화면이 두 겹이 된다 — 판은 세부 과제 카드 줄까지만
  • 판 안쪽 여백만큼 카드 폭이 약 70 dp 줄어든다

선택 표시 · Paper 탭이 판과 이어짐 + 위쪽 Signal 선 + 글자 Ink. 나머지는 Lavender 탭·Periwinkle 글자

네 칸 같은 폭 · 탭 네 개 같은 weight, 틈 12 dp. 판 폭 = 탭 네 개 합

추천

시안 B · 기호 탭

지금 구조(큰 글자 + 짧은 빨간 밑줄)를 살리면서 원·사각·삼각·선 기호로 "메뉴" 단서와 기하학 포스터 콘셉트를 동시에 얻고, 구현도 가장 가볍다. 메뉴임을 더 강하게 보이고 싶으면 E 폴더 탭이 다음 후보.
