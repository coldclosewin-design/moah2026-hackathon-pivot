# 라운드 25 시안 — 공통 브리프 (2026-10-06 저녁)

사용자가 녹화 기준 태그 `inhouse-20261006-5` APK 를 직접 눌러 보고 준 피드백 + 사내 검증 #5 요청 중 "시안을 보고 고르고 싶다" 는 항목의 시안 페이지를 만든다.
각 페이지는 **정적 HTML 한 장**(외부 파일·폰트·스크립트 없이, 인라인 CSS/SVG 만 — `<script>` 금지, 보기 창이 스크립트를 돌리지 않는다), 브라우저 폭 1600px 에서 보기 좋게.
라운드 22 시안 페이지(`docs/design/round22-proposals/4b-home-ai-ad.html`, `7b-profile-abd.html`)가 형식의 좋은 예다 — 먼저 하나를 읽고 같은 짜임으로.

## 앱의 디자인 언어 (반드시 지킨다)

- 2560×1268 dp 가로 자동차 화면(실제 기기 2560×1440, 위아래 시스템 바). 시안은 화면을 **1/3 축소(853×423 px)** 하거나, 관련 부분만 같은 축척으로 잘라 보여 준다. "실제 화면은 약 3배" 를 페이지 위에 적는다.
- 색 토큰 다섯 개만: `--ink:#070827` `--paper:#FCFCFA` `--peri:#5B60A1`(Periwinkle) `--lav:#E5E6F0`(Lavender) `--signal:#F52D48`(빨강, 주 알약·선택 강조) + `--muted: rgba(7,8,39,.60)`. **새 색 금지.** 투명도 변형은 허용.
- 컨셉 = "기하학 포스터": 큰 면 분할(왼쪽 Ink 패널/일러스트 + 오른쪽 Paper), 각진 면, 둥근 알약 버튼, 굵은 글씨 대신 크기 대비(**Bold 금지** — font-weight 400/500 만, `<b>` 도 500).
- 질감 B: 버튼·카드에 살짝 그림자 + 위쪽 1px 하이라이트 — `box-shadow: 0 4px 10px rgba(7,8,39,.10), 0 1px 2px rgba(7,8,39,.06), inset 0 1px 0 rgba(255,255,255,.9)`. 잠금 화면만 평면.
- 주 알약 = Signal 빨강, 흰 글자, 오른쪽 `→`, 높이 약 140 dp(1/3 축소 약 46px). 보조 알약 = Lavender 채움 + 질감 그림자, 높이 112 dp(1/3 약 37px).
- 글자: 한국어. 눈썹 32 dp(Periwinkle 또는 Ink), 본문 40 dp, 제목 72 dp — 1/3 축소 시 약 11/13/24px.
- 운전자 화면 문장에는 숫자를 넣지 않는다(점수·횟수·초). 과제 시트는 숫자 0. 시간대 라벨(14:00–15:00)·거리(3 km)·속도는 허용.
- **주행 중(> 5 km/h) 화면에는 터치 타깃·점수가 없다**(절대 규칙 10). 홈·시트·코치 대화는 정차 화면.
- 폰트: `"Noto Sans KR","Malgun Gothic","Apple SD Gothic Neo",system-ui,sans-serif`.
- 확정되어 바꾸지 않는 것: 분류 알약 트랙(주차·주행·점검·지식, 먹 선택), 과제 카드 C, 보조 알약 `돌아가기`, 홈 A1(시작 아래 링크 줄), 관리자 준비실 D + 띠 C, 프로필 P2.

## 앱 사실 (시안이 틀리게 그리지 않도록)

- 홈: 왼쪽 차 일러스트, 오른쪽 눈썹 `연수생 · 장롱 10년차 · 목표 아이 등하원`(누르면 프로필 시트 — 지금은 누를 수 있다는 표시가 없다) → 제목 "오늘은 가볍게,\n주차부터 해 볼까요?" → `후면 직각 주차 · 가이드 모드` → 이유 한 줄 → (예약 있으면 예약 카드) → 주 알약 `시작 →` → 57 dp 아래 한 줄: 글자 링크 `과제·모드 바꾸기` + 보조 알약 `코치와 고르기`(관리자 "시뮬레이션 음성 입력" 켬이면 마이크 아이콘 + `코치에게 말하기`). 시연 빌드는 맨 아래 Ink 관리자 띠(시나리오 칩 · 정차 · 출발 · 문 열기 · 문 닫기 · AI 상태 · 더 보기).
- 코치 시트: 오른쪽 열이 시트로 바뀜(왼쪽 일러스트 유지): 눈썹 `코치와 이야기` → 말풍선 → 칩(예약한 시험장으로 / 주차 연습 / 지난번 이어서) → "고르면 바로 그 자리로 가요." → (입력 켬) 입력 칸 + `보내기 →` + "음성 입력 · 시뮬레이션" 배지 → `← 돌아가기`. 운전자가 글을 보내면 AI(사내 Copilot, 사외는 키워드 규칙)가 문장 + 의도 하나로 답하고, 의도가 정해지면 시트가 닫히며 과제 시트·홈 제안·예약 카드·프로필 시트로 간다.
- 잠금: 속도 > 5 km/h 면 정차 화면(Done·Report·Quiz)은 Ink 평면 + "운전에 집중해 주세요" 만, 터치 타깃 0 — 관리자 띠도 숨긴다. 그래서 시연 중 Fake 차가 움직이면 띠의 `정차` 를 누를 길이 없다(사용자 지적).
- 시험장 시트: 눈썹 `제휴 시험장` → "예시입니다 — 실제 예약 연계 없음" → 지도 카드 셋 → 시간 칩 트랙(14:00–15:00 · 16:00–17:00 · 18:00–19:00) → 코스 칩 트랙 → `← 돌아가기` · `예약 →`. 시드에 `available=false` 시간대가 있다(상태기계는 예약을 거부) — 지금 화면은 가능/불가 차이가 거의 없다(사용자 지적).
- 장내 코스 지도: 출발 → 경사로 → 좌상단 회전 → 직각 주차 → 신호 교차로 → 우측 가속 → 돌발 → 종료. 가운데가 텅 비어 있다. **실제 운전면허 장내기능시험(2016-12 개정 이후)에는 S자·T자 코스가 없다**(기기 조작 · 차로 준수·돌발 · 경사로 · 좌·우회전 · 직각 주차 · 신호 교차로 · 가속). 이 코스 도면은 "예시" 라고 표시된다.
- 지식 과제: 지금 하나(`비상등·날씨별 행동`), 모드는 `지식 테스트`(QUIZ) 하나 — 정차 중 4지선다 문항 + 이유.

사내 검증 #5 요청(사용자 10/6 결정) — **"말 카드"**: 사내 에뮬은 화면 키보드가 뜨지 않아 한국어 입력이 불가. 코치 시트에 **미리 쓴 한국어 문장 카드**를 두고, 누르면 그 문장이 운전자 말로 보내져 AI 대화로 간다(STT 자리를 대신하는 시뮬레이션이므로 "음성 입력 · 시뮬레이션" 표시 유지). 카드는 의도별로 섞어 여러 갈래로 흐르게(감정 "오랜만이라 무서워요" · 과제 "평행 주차 힌트로 할래요" · 상황 "예약한 시험장 연습할래요" · 되묻기 "뭐부터 하면 좋을까요?" · 프로필 "아이 등하원 때문에 배워요"), 대화 단계에 따라 카드가 바뀐다(첫 화면 = 감정·인사 위주, AI 가 되물으면 과제·상황 카드). 정차 중만, 큰 터치 타깃, 카드 줄은 가로 스크롤 한 줄.
