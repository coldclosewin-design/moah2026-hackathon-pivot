준비실 = C2 점선 작업대 · 띠 = C2 점선 캡슐(라벨 · 순서 그대로). 시간이 남으면 준비실 머리만 C7 처럼 프리셋을 크게

  • 왜: 시연 전용 면은 "운전자 화면처럼 보이지 않는 것" 이 첫째 조건 — 점선 · 고정폭 · 그림자 0 은 운전자 쪽(입체 · 흰 카드 · 큰 문장)과 재료부터 달라 영상에 잠깐 비쳐도 섞이지 않는다.
  • 공수: 작음 — 점선 테두리 하나 + 라디오 행. 띠는 라벨·순서·높이를 지금과 같게 둬 tools/ · 사내 점검 스크립트 수정 0(C3·C7 처럼 접거나 묶는 안은 도구까지 고쳐야 해서 10/9 마감 전엔 보류).
  • 대안: 앱 톤과 더 닮아야 한다면 C1(흰 카드 대시보드 + Graphite 띠, 역시 작음).
