# 제출 PPT 한 장 — 시안 공통 브리프 (2026-10-06 밤)

MOAH 2026(모비스 SW 해커톤) 제출물 **PPT 1장**의 시안. 주최 양식은 **자유**(사용자 확인). 이 한 장이 **앱의 정당성(왜 필요한가)과 기능**을 심사자에게 한눈에 설명해야 한다.
시안은 **16:9 슬라이드 한 장 = 정적 HTML 한 페이지(1920×1080 고정 캔버스)** — 외부 파일·폰트·스크립트 없이 인라인 CSS/SVG, `<script>` 금지. 캡처는 `<img src="../../screenshots/lesson/<파일>.png">` 상대 경로.
각 시안 HTML 아래에 같은 이름 `.png`(headless Edge 로 1920×1080 렌더)를 만든다. 슬라이드 밖 여백·설명은 넣지 않는다(PPT 로 옮길 한 장 그대로).

## 디자인 언어 (앱과 같은 정체성)

- 색 토큰 다섯 + muted: `--ink:#070827` `--paper:#FCFCFA` `--peri:#5B60A1` `--lav:#E5E6F0` `--signal:#F52D48` · `--muted: rgba(7,8,39,.60)`. 투명도 변형 허용, 새 색 금지.
- "기하학 포스터": 큰 면 분할(Ink 면 + Paper 면), 각진 면, 둥근 알약, **Bold 금지**(font-weight 400/500 — 크기 대비로 위계).
- 폰트 `"Noto Sans KR","Malgun Gothic","Apple SD Gothic Neo",system-ui,sans-serif`. 슬라이드에서 본문 최소 20px(1920 캔버스 기준) — 심사자가 화면 공유·인쇄로 본다.
- 캡처는 둥근 모서리 6px + 질감 그림자 `0 4px 10px rgba(7,8,39,.10), 0 1px 2px rgba(7,8,39,.06)`. 캡처 위 글자 덧씌우기 금지(설명은 옆 라벨).

## 꼭 들어갈 내용

**제목**: 드라이브 코치 — 화내지 않는 조수석 · 부제/눈썹: "초보·장롱면허 운전자를 위한 AAOS 운전 연수 어시스턴트" · `[팀명] · [발표자]` 자리(빈칸 표시).

**정당성(왜 필요한가)** — 확인한 공개 통계만, 출처를 슬라이드 아래 작은 글씨로:
1. **자동차보험 차량 물적 사고 10건 중 3건(30.2%)이 주차 중**에 났고, 주차 사고의 **53.8%가 후진** 중이었다 — 보험개발원·현대해상·동부화재·KB손해보험 공동 조사(2012~2014 보험금 지급 분석, 2017년 1월 발표).
2. 초보운전자가 운전 첫해 낸 사고의 **41%가 처음 100일 안에** 몰렸다 — 현대해상 교통기후환경연구소 「초보운전자 사고감소를 위한 정책방안 연구」(2009~2015 사고 317만 건 분석, 2016년 12월).
3. 운전학원 **도로연수 10시간 약 50~60만 원**(2025년 언론 보도 기준) — 혼자 연습할 도구가 부족하다.
4. (서사) 옆자리에서 가르치면 둘 다 힘들다 — 발표자의 실제 계기("장롱면허 10년차인 아내가 아이 때문에 다시 운전을 시작했고, 옆에서 가르치다 둘 다 힘들었다"). 숫자 아님 — 인용 한 줄로.
→ 메시지: **"가장 사고가 많은 순간(주차·첫 100일)을, 화내지 않고 반복해 줄 조수석이 없다."**

**해법 한 줄**: 두려운 상황을 **과제**로 쪼개고, **차량 신호로 과정을 측정**해 **가이드 → 힌트 → 평가** 순으로 도움을 줄여 간다. 정차하면 회차 판정과 리포트.

**기능(지금 앱에 있는 것 — 10/6 태그 `inhouse-20261006-6`)** — 시안마다 3~6개를 골라 강조:
- **과제 18개**: 주차 4(후면·전면 직각·평행·사선) · 도로 주행 6(직선 정지·좌회전·차선 변경·회전교차로·일반 도로·**장내기능 모의시험**) · 점검 2(출발 전 점검·도로 표시 읽기) · 지식 6(비상등·날씨 + 노면 표시·신호와 우회전·교차로 우선·운전 매너·헷갈리는 상식)
- **세 모드**: 가이드(단계마다 말하고 신호로 확인) → 힌트(틀린 순간에만) → 평가(조용히 보고 채점)
- **차량 신호로 과정 측정**: 속도·조향·기어·벨트·시동·도어·지시등·비상등(VSS). 회차가 끝나면 점수 대신 **판정 네 줄**(한 번에·방향·마무리·안전)과 추정 궤적
- **주행 중 화면 잠금**: 5 km/h 넘으면 점수·터치 0(주의 분산 방지) — 말은 음성으로
- **AI 코치**: 회차 멘트·총평·홈 대화는 사내 Copilot(실패하면 규칙 문장), **감점 순간 힌트는 규칙이 지연 0**. 홈에서 **말 카드**로 코치와 대화 → 과제·모드 제안
- **제휴 시험장 예약 → 장내기능 모의시험**(구간 감점·합격선) · **진단서**(공유 범위를 운전자가 고름 — 예시)
- **정직한 출처 표시**: 신호마다 실신호·시뮬레이션·미측정을 세어 배지로

**검증 사실(쓸 수 있는 숫자)**: 사내 차량 환경(Real VSS) **코드 수정 없이** 빌드·실행 — 배지 **실신호 7 · 시뮬레이션 1 · 미측정 0**(후면 주차), 장내 모의시험 실신호 11 · 시뮬레이션 6 · 단위 테스트 350 통과(사외) · 사내 Copilot 응답 1.2~1.5 s(홈 대화 `(ai)` 확인). 테스트·PR 수는 작게.

**정직한 한계(작게 한 줄)**: 카메라가 없어 칸 안 최종 위치는 판정하지 않는다(과정을 본다) · 예약·진단서 공유·시험장 위치 신호는 시뮬레이션/예시 · S자는 연습 구간(실제 시험 항목 아님).

## 시안 넷 (각자 다른 구성)

- **A "문제 → 해법 → 기능" 세 칸**: 왼쪽 Ink 칸 = 정당성(통계 두세 개 큰 숫자 + 계기 한 줄) · 가운데 = 해법(과제 × 모드 사다리 도식) · 오른쪽 = 기능 캡처 두세 장 + 라벨. 아래 띠 = 검증 사실 · 한계 · 출처.
- **B "화면이 주인공"**: 중앙에 큰 캡처 하나(회차 판정 또는 홈 말 카드)와 둘레에 작은 캡처 4~5장을 흐름 순서로(홈 → 주차 중 → 판정 → 리포트 → 모의시험), 각 캡처에 한 줄 라벨. 정당성은 위 띠에 숫자 두 개.
- **C "연습 여정 타임라인"**: 가로 타임라인 `대화로 과제 고르기 → 브리핑 → 연습(가이드/힌트/평가) → 회차 판정 → 리포트·진단서 → 시험장 모의시험`, 단계마다 작은 캡처 + 차량 신호 아이콘. 왼쪽 위에 정당성 숫자.
- **D "숫자로 말하기"**: 큰 숫자 넷(30.2% 주차 사고 · 41% 첫 100일 · 18 과제 · 7 실신호/0 코드 수정)을 그리드로, 각 숫자 아래 한 줄 의미와 작은 캡처. 제목 아래 해법 한 줄.

각 시안: 텍스트는 짧게(한 칸 두 줄 이내), 운전자 문장 규칙과 무관한 발표 자료라 숫자 허용. 출처 줄은 슬라이드 하단 14~16px Muted 로 세 줄 이내.
