요약 — 초보·장롱면허 운전자가 두려운 상황을 과제로 연습하도록, 차량 신호(VSS)로 과정을 측정해 가이드 → 힌트 → 평가 순으로 도움을 줄여 가는 앱을 만들었다. 사내 차량 환경(Real VSS)에서 코드 수정 없이 빌드·실행되었고, 후면 주차 과제 신호는 실신호 7 · 시뮬레이션 1 · 미측정 0이었다.

1.배경

아이 때문에 다시 운전을 시작한 장롱면허 10년차 아내를 위해 시작했다. 옆에서 가르치면 둘 다 힘들다. 가장 사고가 많은 순간(주차·첫 100일)을 화내지 않고 반복해 줄 조수석이 없다는 것이 출발점이다.

3.해결 방안

  • 두려운 상황을 과제로 쪼개고, 차량 신호로 결과가 아닌 과정을 측정한다.
  • 같은 과제를 가이드 → 힌트 → 평가로 반복하며 도움을 줄인다. 정차하면 회차 판정, 쌓이면 리포트·진단서.
  • 틀린 순간 힌트는 규칙이 지연 0으로 말하고, 회차 멘트·총평·홈 대화는 사내 Copilot이 맡는다(실패하면 규칙 문장).

6.한계 · 향후 계획

  • 한계 카메라가 없어 칸 안 최종 위치는 판정하지 않는다(과정을 본다). 예약·진단서 공유·시험장 위치 신호는 시뮬레이션/예시다. 캡처는 외부 에뮬레이터 화면이며, 검증은 사내 차량 환경 기준으로 실제 도로 검증이 아니다.
  • 계획 10/9 제출(PPT · 소스 · APK · 시연 영상). 판정 네 줄이 실차 값으로 맞는지 사내 확인, 시뮬레이션 항목의 실제 연동처 검토.
