## 7. 차량 신호가 UX 규칙의 근거다

- **화면**: 표.

  | 신호 | 앱에서의 의미 |
  |---|---|
  | `Vehicle.Speed` > 5 km/h | 터치 요소가 전부 사라진다(주행 잠금) |
  | `Vehicle.Speed` < 1 km/h **그리고** 운전석 `Door.IsOpen` | 리포트가 열린다(세션 종료) |
  | `Vehicle.Speed` 만으로 | 이동 구간 수·시간·급조작 — **A층, 무조건 성립** |
  | `Chassis.SteeringWheel.Angle` | 핸들 되돌린 횟수, 가이드 "끝까지 돌렸어요" 확인 |
  | `Powertrain.Transmission.SelectedGear` | R↔D 전환 수, 가이드 "기어 R" 확인, P 에서 "다 되셨나요?" |
  | `ADAS.ObstacleDetection.IsWarning` | 근접 경고(안전 축) — 실물에 있는 키. 뒤 **거리 값**(`Rear.Distance`)은 실물에 없어 **Fake 전용**(`vehicle/SimOnlySignals.kt`), 화면의 "뒤 거리" 는 시뮬레이션이다 |
  | `Cabin.Seat.Row1.DriverSide.IsBelted` | 첫 이동 전에 벨트를 맸나 |

- **말**: "버튼이 아니라 차량 신호가 규칙의 근거입니다. 속도가 화면을 잠그고, 정차와 도어가 리포트를 엽니다. 속도 하나만 와도 회차 피드백은 성립하고, 조향각·기어가 오면 그만큼 정밀해집니다. 경로가 실물과 달라 값이 안 오면 그 항목은 미측정으로 빼고 채점하지 않습니다."
