초안(2026-09-26, `main` 4093037 기준). 실제 슬라이드는 사내 양식에 옮긴다 — 이 문서는 **장마다 무엇을 보여 주고 무엇을 말할지**를 정한다. 발표 시간·형식·평가 기준은 주최 공지(최종자료 제출, pageId 1317526558)를 확인한 뒤 "길이 조절"로 맞춘다. 재료의 출처는 `docs/topics/01_driving_coach.md`(제품 정의 v2), `docs/journal/2026-09-25.md`·`26.md`, `docs/05_demo_script.md`.

**한 문장**: 초보·장롱면허 운전자가 두려운 상황을 과제 단위로 연습할 때, 차량 신호로 **과정**을 측정해 주차 중에는 틀린 순간만 말하고, 세우고 내리면 진단 리포트를 펼친다. (시연 본편: 후면 직각 주차, 힌트 모드 두 회차.)

## 7. 차량 신호가 UX 규칙의 근거다

- **화면**: 표.

  | 신호 | 앱에서의 의미 |
  |---|---|
  | `Vehicle.Speed` > 5 km/h | 터치 요소가 전부 사라진다(주행 잠금) |
  | `Vehicle.Speed` < 1 km/h **그리고** 운전석 `Door.IsOpen` | 리포트가 열린다(세션 종료) |
  | `Vehicle.Speed` 만으로 | 이동 구간 수·시간·급조작 — **A층, 무조건 성립** |
  | `Chassis.SteeringWheel.Angle` | 핸들 되돌린 횟수, 가이드 "끝까지 돌렸어요" 확인 |
  | `Powertrain.Transmission.SelectedGear` | R↔D 전환 수, 가이드 "기어 R" 확인, P 에서 "다 되셨나요?" |
  | `ADAS.ObstacleDetection.*` | 뒤 거리 40 cm 근접 경고(안전 축) |
  | `Cabin.Seat.Row1.DriverSide.IsBelted` | 첫 이동 전에 벨트를 맸나 |

- **말**: "버튼이 아니라 차량 신호가 규칙의 근거입니다. 속도가 화면을 잠그고, 정차와 도어가 리포트를 엽니다. 속도 하나만 와도 회차 피드백은 성립하고, 조향각·기어가 오면 그만큼 정밀해집니다. 경로가 실물과 달라 값이 안 오면 그 항목은 미측정으로 빼고 채점하지 않습니다."
- 근거: `feature/lesson/LessonModels.kt`(`LOCK 5`, `STOP 1`), `scoring/`, `docs/02_vss_api_contract.md`
- 40초

## 예상 질문

| 질문 | 답의 뼈대 · 근거 |
|---|---|
| AI 는 어디에 쓰이나? | 정차했을 때만 — 회차 멘트 변주(프로필·이력 기반), 세션 총평, 다음 과제 제안(`CoachPort`). 주행·주차 중 힌트는 규칙(지연 0). 지금은 전송 계층이 없어 시드 풀, 사내 Copilot 인증 뒤 `CoachTransport` 하나만 구현. 실패해도 폴백 |
| 카메라 없이 주차를 어떻게 평가하나? | 평가하지 않는다. **과정**을 잰다 — 이동 구간 수·시간·조향 되돌림·기어 전환·뒤 거리·급조작. 도로주행시험 채점표도 대부분 과정 항목이다. 화면에도 "칸 안 위치는 알 수 없어요"라고 쓴다 |
| 점수 근거는? | 숙련·안전 두 축, 감점표(`ParkingRubric`)는 값으로 노출돼 조정 가능. 시나리오 2벌의 숫자를 단위 테스트가 고정. "지난번보다"가 기본 비교, 남과의 비교는 진단서에만 |
| 실차에서 되나? | `VehiclePort` 실구현은 공개 계약대로, Hybrid 가 안 오는 키만 채운다. 사내 확인 항목은 INTEGRATION B절 |
| 신호가 하나도 안 맞으면? | 속도·도어만으로 이동 구간·시간·급조작 → 회차 피드백 성립(테스트 "A layer alone"). 배지가 "미측정 N"으로 그 사실을 보여준다 |
| 운전자가 화면을 보게 되지 않나? | 5 km/h 초과 시 터치 0개(계측으로 강제), 주차 중 화면에 점수 없음(타입에서 제거), 이전 회차 점수 문장도 자막에서 차단. 음성이 본체 |
| 개인 데이터는? | 진단서는 운전자가 공유 범위(총점만/항목별/원시 신호)를 고르고 철회할 수 있는 구조. 실제 전송은 없다(화면에 명시) |
| 왜 아이템을 바꿨나? | 이전 아이템은 "심사에서 차량 신호 활용은 양념"이라는 미검증 가정에 기댔다. 이 아이템은 신호 없이는 성립하지 않는다. 플랫폼을 포트 뒤에 뒀기 때문에 피벗이 이틀이었다 |
