## 새로 볼 것 (이번 태그)

1. **단위 테스트** — 사내 jar 로 **368 전부 통과**.
2. **`inhouse_check.sh`** — 전과 같은 PASS 목표. 말 카드가 기본 켬이라 준비실 단계 없이도 카드가 보인다(도구는 준비실을 거쳐도 무해). 리포트 배지는 화면이 아니라 로그 `badge=AvailabilityBadge(…)` 로 판정한다.
3. **준비실 들어가기** — 홈 워드마크 `DRIVE COACH` 2초. 그 밖의 화면에서 워드마크 2초 = **시연 탈출**(시나리오 멈춤 · 정차 · 홈). 관리자 띠는 바닥의 얇은 줄 — 손잡이를 누르면 서랍이 올라오고 동작 뒤 자동으로 내려간다. **화면 높이가 띠를 열고 닫아도 같아야 한다.**
4. **홈** — 프리셋 홈: 제목 "후면 직각 주차 ▼ 를 / 힌트 ▶ 모드로 해 볼까요?" — 모드 낱말을 누르면 **가로로 굴러** 가이드 → 힌트 → 평가. 과제 ▼ 는 과제 시트(흰 판, 모드 줄이 버튼 줄). 홈 왼쪽 아래 **초록 원목 차**(프리셋 프로필 = 중형 SUV). `시작` 글자는 ↗ 를 꾹 누를 때만 드러난다(처음엔 ↗ 원만).
5. **코치와 대화** — 오른쪽 위 알약(테두리 없음)을 누르면 알약에서 시트가 피어남. 카드 12장 → 감정 카드("주차장 기둥이 무서워요") → 되물음 → 답 카드("후진이 제일 어려워요") → 홈 제안이 후면 직각 주차로. `(ai)`/`(rule)` 로그와 `response rejected → fallback` 횟수를 적는다(사내 Copilot 이 제목 12자 · 한 마디 24자 규칙을 못 지키면 늘어난다 — 화면은 규칙 문장).
6. **주차 중** — 조향 링이 물방울처럼 따라가는가(540° 에서 끝 점이 `조향 방향 도식` 글자를 덮지 않는가) · 코치 문장 옆 단계 타일 · 검은 원 기어 + 뒤 거리 막대 · **속도 아래 "시뮬레이션 신호" 줄이 없다**(의도).
7. **결과·리포트** — Done 판정 카드 · 리포트 쌍 알약 · `자세히 보기` 에만 "실신호 N · 시뮬레이션 N · 미측정 N"(Hybrid 면 실신호 수가 0 이 아닌가) · **진단서 = 범위 알약 셋(큰 숫자 10 · 8 · 2) → 공유 예시 = 기둥표 + 받는 쪽 폰**(배지 없음, "예시" 표기).
8. **출발 전 점검** — 가이드·힌트 = 흰 차 둘레 카드(차 위에 겹치지 않음, 카드 기호 ◐/● 로 실신호·시뮬레이션 구분) · **평가 = 차만**. 끝 알약 `오늘은 여기까지` 글자 가운데.
9. **주행(코스)** — 지도 왼쪽, 오른쪽 흰 시트(속도 · 모드 · 지금/다음 구간 · 문장). 돌발 = 빨간 시트. 잠금 화면에 "시연 · 막히면 워드마크를 길게" 한 줄.
10. **지식 테스트** — 해설이 두 줄까지 보이는가(최장 "주차 중 전진에서 후진으로…"), 결과 화면에서 맞은 문항도 정답이 보이는가.
11. **첫 실행** — `준비실 → 프로필 초기화` 뒤 홈에서 질문이 **다섯 줄 차례로**(무서운 상황 → 마지막 운전 → 필요한 일 → 면허 → 타는 차), 타는 차를 고르면 프로필 시트에 그 차(왼쪽을 봄)가 보이는가.
12. **런처** — 앱 이름 `Drive Coach` + 아이콘이 흰 원 안 핸들 속 새싹(노란 잎 왼쪽 위)인가. `aapt dump badging` 라벨도 `Drive Coach`.

선택: `copilot_config.json` 에 `"persona": "…한 문장…"` 을 넣어 push → 앱 재시작 → 회차 멘트·대화 말투가 같이 바뀌는가.

- S자 연습이 끝난 뒤 자막 "돌발 상황이에요. 멈추세요." 가 남아 있을 수 있다(무해) — S자 컷은 끝나기 전에 자른다.
