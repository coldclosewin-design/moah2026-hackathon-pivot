## 고칠 것 (`ui/lesson/ProfileScreen.kt`)

| # | 할 것 | 핵심 · 주의 |
|---|---|---|
| ① | **칩을 누른 줄 아래에 정렬** | 다섯 줄 `Row` 의 각 `Column` 위치를 `onGloballyPositioned` 로 받아, 펼친 줄의 **왼쪽 x 에서 질문 한 줄 + 칩(FlowRow)** 이 시작하게. 오른쪽 줄(면허 · 타는 차)은 칩 묶음이 화면 오른쪽 여백(120 dp)을 넘지 않도록 **왼쪽으로만 밀어** 맞춘다(`start = columnStart.coerceAtMost(maxWidth - chipsWidth)`). 칩 묶음 폭은 그 줄 칩들의 측정 폭(최대 4~5개 한 줄) — 넘치면 두 줄로 감싼다. 밑줄(펼친 표시)은 그대로 그 줄 아래 |
| ② | **잘리지 않게** | 줄이 펼쳐진 동안 아래 `앱이 본 것` 줄은 숨기고 `돌아가기` 만 남긴다(또는 칩 영역이 `돌아가기` 줄 위에서 끝나도록 `weight(1f)` 영역 안에 두고 넘치면 스크롤). 제목 두 줄(132 sp)도 펼친 동안 한 단계 줄여(104 sp) 자리를 만든다. 2560×1440 과 본문 1236 dp 에서 다섯 줄 모두 칩 전부 보여야 한다 |
| ③ | **차 미리보기 자리 이동** | 지금 오른쪽 아래(`BottomEnd`, 680×220 dp) → **제목 오른쪽 위**(제목 두 줄과 같은 높이의 `TopEnd`, 폭 520 dp 안팎, 왼쪽을 보게 그대로). 그러면 타는 차 줄 아래가 비어 칩이 들어간다. 차종이 없으면 그리지 않는다 |
| ④ | 첫 실행(온보딩)은 바꾸지 않는다 | 질문이 차례로 펼쳐지는 지금 동작 그대로. 이 변경은 `onboarding == null` 일 때의 배치 |

접근성 이름(`<제목>, <답>, 바꾸기` · `프로필 열기`)과 testTag(`profile-rows` · `profile-<FIELD>` · `profile-vehicle-preview`)는 그대로 — 도구·계측이 쓴다.
