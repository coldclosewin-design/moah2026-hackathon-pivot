## 왜

사용자 피드백: 주차 화면의 위에서 본 차가 "깔끔하지만 장난감 같다", 앞바퀴가 돌아가는 표현이 어색하다, 후진 표시 화살표가 짧고 균형이 안 맞는다. 그리고 회차가 끝났을 때 **내가 어떻게 움직였는지 탑뷰로 보고 싶다**(궤적). 궤적은 Claude 가 속도·기어·조향각으로 **추정** 경로를 계산해 넘긴다 — 시안은 그것을 어떻게 그릴지다.

## 시안 1 — 탑뷰 차 도식 3~4안 (주차 화면 왼쪽 남색 영역)

공통: 기하학 포스터 팔레트 5색(`#070827 #FCFCFA #5B60A1 #E5E6F0 #F52D48`), 평면, 글자 없음. 화면 왼쪽 53 % 남색 색면(1360×1268) 안에 차 하나. **뒤가 위, 앞이 아래.** 실제 앱은 Canvas 로 다시 그리므로 **단순한 도형 몇 개로 재현 가능한 밀도**여야 한다(설정 화면 자동차 일러스트보다 단순, 지금 도식보다 자동차답게).

| 안 | 차체 | 조향 표현 |
|---|---|---|
| A | 지금보다 실루엣 밀도 ↑ — 보닛·트렁크 구분, 창 3분할, 사이드미러 | 앞바퀴 회전 유지, 단 바퀴를 차체 안쪽에 넣고 회전 각을 작게 |
| B | A 와 같은 차체 | **바퀴는 고정**, 차 앞에 **조향 방향 호(arc)** 한 줄 — 각도에 비례해 휘는 보랏빛 곡선 |
| C | 더 단순한 캡슐 실루엣 | 차체 자체를 조향 방향으로 살짝 기울이고(±8°) 바퀴는 없음 |
| D | A 차체 | 바퀴 고정 + 차 좌우에 **짧은 방향 마커**(오른쫏이면 오른쪽 마커가 빨강) |

각 안에 **후진 표시** 도형도 포함해 비교: 텍스트 `차량 뒤쪽` 없이 도형만으로 "뒤로 간다" 가 읽혀야 한다. 후보: 차 뒤쪽 가장자리 빨간 선 / 얇은 셰브론 하나 / 차 뒤 짧은 빨간 점선. 화살표 글리프(↑)는 쓰지 않는다.

## 시안 2 — Done 화면의 궤적 (1장, 2안까지)

Done 화면(흰 바탕, 왼쪽 세로 남색 띠)의 **왼쪽 영역을 넓혀** 회차의 추정 궤적을 그린다.

- 입력(Claude 가 줄 데이터): 0.5 s 간격 점 열 `(x, y, heading)` 미터 단위, 시작이 원점·위쪽이 시작 방향. 후진 구간과 전진 구간이 섞인다(못한 주차는 후진 → 전진 보정 → 후진).
- 표현: 시작 위치 차 실루엣(옅게), 끝 위치 차 실루엣(진하게), 그 사이 궤적 선. 후진 구간 `Periwinkle`, 전진 보정 구간 `Lavender`, 급정지 지점 작은 빨간 점 하나. 주차 칸은 **그리지 않는다**(앱은 칸 위치를 모른다).
- 반드시 들어갈 문구 자리(디자인만, 글자는 앱이 넣음): "신호로 추정한 궤적이에요. 실제 위치와 다를 수 있어요." 32 sp.
- 오른쪽 읽는 영역은 라운드 2 Done 그대로(멘트 2줄 + 한 번 더 / 오늘은 여기까지). 시연 패널은 그리지 않는다(접힘 정책).
