# 녹화 시나리오 — 첫 진입부터 전 기능 한 바퀴 (태그 `inhouse-20261009-3`, 2026-10-09)

사내에서 **이 문서만 보고** 찍는다. 조작은 전부 손으로(스크립트 없음), 관리자 조작은 화면 바닥의 **얇은 줄 손잡이**(눌러서 서랍)로. 원본 약 10분을 찍고 편집에서 긴 구간만 2배속 → **5분 본편**. 길이·형식 요구는 사내 "최종자료 제출"(pageId 1317526558) · "앱 제출 가이드"(pageId 1038298817)를 먼저 본다 — 상한이 3분이면 §6 "3분 축약" 으로.

말할 것(내레이션 또는 자막)은 각 단계의 ▶ 줄. 운전자 화면엔 숫자가 없으니 숫자는 말로만.

## 0. 녹화 전 준비 (영상에 안 들어감)

1. `inhouse-20261009-3` 빌드·설치(`INHOUSE_NOW.md` 1~3), 에뮬 소리 켬, 앱을 **새로 켠다**(느려진 상태에서 2회차가 60 s 를 넘기면 시간 감점 2점 → 98점).
2. 홈 워드마크 `DRIVE COACH` **2초** → 준비실: `AI 연결`(Copilot 로그인 → `연결됨`) → `기록 초기화` → **`프로필 초기화`** → `이 설정으로 홈`. 홈에 **첫 실행 질문**이 뜬 상태에서 녹화를 시작한다.
3. 녹화 중 막히면 어느 화면이든 **워드마크 2초**(시나리오 멈춤 · 정차 · 홈). 리포트 뒤엔 손잡이 → `문 닫기` 한 번.
4. AI 가 답을 거절해 규칙 문장이 나와도(로그 `fallback`) 화면은 정상 — 그대로 간다.

## 6'. 3분 축약 (상한이 3분일 때)

§1 첫 진입(15 s, 질문 둘만 보이고 2배속) → §3 대화(20 s) → §5 본편(1:40 — 1회차 보정 2배속, 2회차 2배속) → §6 리포트·진단서·공유(25 s) → §8 모의시험은 **돌발 20 s 만** → 끝 카드. 빠지는 것: 프로필 시트 · 예약 · 점검 · 지식.

## 7'. 7분 확장
