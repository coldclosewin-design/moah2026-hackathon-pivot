# 라운드 31d · 프로필 편집 칩 정렬과 잘림

#275 머지 후 최신 `origin/main`인 **ad8467d**에서 새 워크트리와 `codex/ui-round31d`를 만들었다. [31d 발주서](../../../handoffs/2026-10-09_codex_ui_round31d.md)에 따라 프로덕션 변경은 `ProfileScreen.kt` 하나다.

선택한 열의 실제 x 좌표와 질문·칩 묶음의 측정 폭으로 편집 영역을 배치한다. 오른쪽 여백이 부족할 때만 왼쪽으로 이동하며, 기존 FlowRow의 줄바꿈과 가용 높이 안의 스크롤을 사용한다. 편집 중에는 제목 두 줄을 104sp로 줄이고 `앱이 본 것`을 숨겨 `돌아가기` 위에 공간을 확보한다. 차 미리보기는 제목 오른쪽 위의 520×220dp 영역으로 옮겼다.

## 실제 배치 확인

디스플레이 2560×1440, 밀도 160 dpi에서 앱 본문은 `[0,76][2560,1312]`로 **1236dp**다. 접근성 트리에서 모든 칩의 테두리를 포함하는 선택 영역과 `돌아가기` 버튼의 경계를 비교했다. 다섯 줄 모두 칩 높이가 **109 → 112dp**, 칩 하단과 돌아가기 버튼 사이 간격이 **0 → 77dp**다. 각 질문은 한 줄이고, 스크롤 없이 칩 전부가 보인다.

| 줄 | 해당 열 x | 질문·칩 시작 x (전 → 후) | 오른쪽 여백 |
|---|---:|---:|---:|
| 무서운 상황 | 84 | 84 → 84 | 1487 |
| 마지막 운전 | 568 | 84 → 568 | 892 |
| 필요한 일 | 1053 | 84 → 1053 | 797 |
| 면허 | 1538 | 84 → 1538 | 276 |
| 타는 차 | 2023 | 84 → 1786 | 120 |

타는 차만 묶음의 폭에 맞춰 왼쪽으로 이동한다. 차 미리보기는 다섯 상태 모두 선택 줄보다 위에 있다. [배치 검사 결과](layout-checks.txt).
