## 결정과 이유

- **결정**: Codex PR 이 main 보다 뒤에 있으면 main 을 병합한 상태로 검증하고, 원인이 Claude 쪽 변경인 계측 깨짐은 리뷰어가 PR 브랜치에서 한 줄로 고친다. **이유**: 원인이 Codex 코드가 아니고, 왕복하면 마감 사흘 전에 반나절이 간다. PR 코멘트에 경위를 남겼다.
- **결정**: 리뷰에서 나온 작은 흠(공유 예시 "1회차–1회차", 예약 선택 뒤 남는 코치 질문 자막)은 머지를 막지 않고 다음 라운드 후보로. **이유**: 시연 본편 흐름에 영향이 없다.
- **결정**: 문서(대본·런북 띠/준비실) → 태그 → "현재 전달 태그" 문서 순서. **이유**: 사내는 태그를 체크아웃해 그 안의 대본을 본다 — 조작 설명은 태그에 들어가야 하고, 태그 이름만 태그 뒤에 적을 수 있다. 태그 뒤 문서(확인 항목·재개 절차)는 `git show origin/main:…` 로 읽게 했다.
- **결정**: 사내 재검증은 영상·덱 작업을 기다리지 않고 바로 재개. **이유**: 코드가 동결됐고 남은 사외 작업은 발표 자료뿐이라 사내 결과에 영향이 없다.
- **결정**: 대본 시각표는 녹화 실측(t+140)으로 바꾸지 않고 머리에 따로 적는다. **이유**: 15 s 차이는 녹화 부하이고 화면 흐름은 같다 — 사람이 누를 때의 시각은 10/4 표가 더 가깝다.

- **결정**: AI 는 **문장과 고정 목록의 의도만** 고르고 화면 이동은 기존 진입점이 한다. 형식·문장·의도 중 하나라도 틀리면 규칙으로. **이유**: AGENTS "AI 경계" — 시연 중 AI 가 없는 과제를 지어내거나 숫자를 말하면 안 되고, 인터넷이 없어도 같은 흐름이 끝나야 한다(`docs/design/12_home_coach_dialog.md`).

- **결정**: 사내 점검의 대화 단계는 **영어** 두 줄. **이유**: 에뮬 기본 키보드에 한국어가 없고 `adb input text` 는 ASCII 만. Copilot 은 영어도 알아들어 `(ai)` 여부를 그대로 잴 수 있고, Fake 규칙(한국어)은 되묻기가 정상.
- **결정**: 디자인 검토에서 F(예약 홈 이유)만 지금, Codex 다듬기 셋(준비실 상태 줄 · 띠 재생 상태 위치 · 대화 위쪽 페이드)은 녹화 뒤. **이유**: F 는 영상 첫 장면 문장이고 모델 문구라 바로 고칠 수 있다. 나머지는 관리자 화면·대화 컷에서만 보이는데 고치면 태그·사내 재검증이 한 번 더 든다(사용자 선택 "1").
