## 결정과 이유

- **결정**: 아이템을 **운전 연수 어시스턴트**로 전면 교체. **대안**: 16번 미채택 후보 03(주차·진입 안내, 30점, 실내경로 코드 이미 존재). **이유**: 16번은 "VSS 활용은 양념 수준이면 충분"이라는 미검증 가정 위에 있었다. 운전 연수는 신호 없이는 성립하지 않아 그 가정에 기대지 않고, 해커톤 요구 "편의/안전 관점의 서비스"에 정면 부합한다. 03은 AI 필요성 2점이 약점. **되돌릴 조건**: 사내에서 속도 신호조차 안 오는 경우 — 그때도 Fake 시나리오로 시연은 되므로 되돌릴 이유는 사실상 없다.
- **결정**: 시연 주인공은 **초보 — 일반 도로 실주행 연수**. **대안**: 휴무일 시험장 모의주행(코스·채점표 명확, Claude 추천). **이유**: 사용자 판단(현실성·공감). 약점(코스가 불명확 → 채점 근거 약함)은 경로를 `Segment` 로 쪼개고 기대 행동을 붙여 해소. 시험장은 2순위 확장 서사로.
- **결정**: 채점은 **A층(속도 파생, 무조건) + B층(시험 채점표, 신호 있을 때)**. **대안**: 채점표 전부 구현 / 자체 지표만. **이유**: 확인된 신호가 속도·도어 2개뿐. A층이 안전판, B층은 `SignalAvailability` 로 `MISSING` 을 견딘다. "무엇이 실신호인지 정직하게 표시"가 가점이 된다는 판단.
- **결정**: **주행 중은 규칙, 정차 시는 AI**. **대안**: 상시 AI 대화, STT. **이유**: 급제동 경고는 지연 0이어야 하고, 사내 네트워크·Copilot 인증·STT 실동작이 전부 미확인. 밤을 새워도 해결되지 않는 종류의 불확실성.
- **결정**: **16번 통째 복사 → 첫 커밋에서 도려내기**, 새 repo. **대안**: 인프라만 추린 클린 스캐폴드 / git clone 으로 히스토리 유지. **이유**: 새 repo 라 히스토리는 어차피 깨끗하고, 16번 폴더가 그대로 남아 되가져오기가 `git show` 한 줄. 실제로는 컴파일 가능한 상태로 만들기 위해 `droad` 렌더링 엔진까지 삭제했다 — `NEXT.md` §5 에 되가져오기 경로를 적어 두었다.
- **결정**: 패키지 `com.moah.hackathon` 유지. **이유**: `tools/*.sh` 의 `run-as`·`am instrument` 문자열 전부를 건드리지 않기 위해.
