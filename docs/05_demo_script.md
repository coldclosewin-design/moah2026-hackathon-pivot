> 시각은 2026-09-26 `tools/emu_flow.sh` 실측(PR #5 리뷰). 구조는 16번 대본을 그대로 따른다: 준비 → 분단위 타임라인(시각/조작/화면·음성/**말할 것**) → 시간 조절 → 사고 대응. 시연 시나리오의 근거는 `topics/01_driving_coach.md` §4.5.

## 준비 (시연 10분 전)

```powershell
.\gradlew.bat assembleDebug            # 기본 -PdemoSpeed=1.0 (실시간). 시간이 모자라면 -PdemoSpeed=1.5
adb install -r automotive\build\outputs\apk\debug\automotive-debug.apk
```
```bash
bash tools/emu_flow.sh /tmp/flow       # 끝에 "result: PASS", "clashes: 0" 이어야 한다
```
- 에뮬 소리 켬(TTS). 시연 패널이 **보이면 Fake** — 사내 Real 포트에서는 패널이 사라지고 Signal Simulator 로 속도·기어·도어를 준다.
- 앱을 끄고 다시 켠다(프로필 관측·ProgressStore 는 인메모리 → 새 세션은 "처음 하는 과제").

## 시간 조절

| 손잡이 | 효과 |
|---|---|
| `-PdemoSpeed=1.5` | 시나리오 44 s → 29 s, 26 s → 17 s. 음성이 밀리면 1.2 로 |
| 패널 **정차** | 시나리오 도중 속도를 0 으로 고정 — 말할 시간을 산다. **출발**로 복귀 |
| 회차 1 만 | 시간이 없으면 "한 번 더"를 건너뛰고 바로 **문 열기** → 리포트(회차 1) |
| 가이드 모드 | 시간이 남으면 회차 3 을 가이드로 — 단계별 확인 음성 6개가 나온다(잘한 주차 시나리오) |

## 사고 대응

| 증상 | 대응 |
|---|---|
| 사내에서 패널은 보이는데 정차·문 열기가 안 먹는다 | 정상 — Hybrid 에서 실물이 주는 키(속도·도어)는 실물이 이긴다. Signal Simulator 로 속도 0·도어 열림을 준다. 조향각·기어가 실물에 없으면 시나리오가 채우고 배지가 "시뮬레이션 N"으로 말한다 |
| 시연 패널이 아예 없다 | `-PfillMissing=false` 순수 Real 빌드다. Signal Simulator 로 `Vehicle.Speed`·`SelectedGear`·`SteeringWheel.Angle`·도어를 준다. 조향각·기어가 없으면 힌트가 A층(급정지)만 나온다 — 그대로 진행하고 배지의 "미측정"을 보여준다 |
| 힌트 음성이 안 나온다 | 자막은 나온다(엔진 없음). 자막을 읽어 준다. logcat `MOAH/AndroidTtsPort` |
| "다 됐어요"가 안 보인다 | 속도가 1 km/h 미만이어야 한다. 패널 **정차** |
| 리포트가 안 열린다 | 정차 + 운전석 도어 열림 둘 다. **정차** → **문 열기**. 또는 `Done` 의 **오늘은 여기까지** |
| 멘트가 반복된다 | 최근 3개 반복 금지이지만 밴드에 4개뿐인 곳이 있다 — 회차 3 이상은 겹칠 수 있다. 회차 2 까지만 |
| 앱이 죽었다 | `adb shell am start -n com.moah.hackathon/.ui.MainActivity`. 세션은 인메모리라 처음부터 |
