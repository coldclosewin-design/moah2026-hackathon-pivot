# 시연 대본 — 후면 직각 주차 세션 (라운드 3 선반영 2026-09-27 · 시각은 재측정 전)

> 시각은 **라운드 3(PR #25) 리뷰 실측**(2026-09-27 `tools/emu_flow.sh`: `시작` 뒤 회차 1 `asked done` t+53 s · Done t+55 s · 회차 2 시작 t+64 s · `asked done` t+97 s · 리포트 t+108 s). 스크립트는 탭마다 덤프에 몇 초씩 쓰므로 사람이 누르면 약 10~15 s 짧다. 구조는 16번 대본을 그대로 따른다: 준비 → 분단위 타임라인(시각/조작/화면·음성/**말할 것**) → 시간 조절 → 사고 대응. 시연 시나리오의 근거는 `topics/01_driving_coach.md` §4.5.
>
> 라운드 3 에서 바뀐 것(`docs/design/03_round2_feedback.md`, `handoffs/2026-09-27_codex_ui_round3.md`): ① 시연 패널은 **기본 접힘** — 우상단 `시연` 을 눌러 시나리오를 고르고, 고르면 다시 접힌다 ② 운전자 문장에 **숫자 없음** — 회차 멘트도 총평도 "서두. 조언." / "흐름. 안전." 두 문장 ③ `Maneuver` 도식은 **탑뷰 B**(고정 바퀴 · 조향 방향 호 · 후진 셰브론) ④ `Done` 왼쪽에 **추정 궤적**(신호로 계산한 경로, "실제 위치와 다를 수 있어요" 캡션) ⑤ `Report` 배지 위 눈썹 `신호 출처`.

## 준비 (시연 10분 전)

```powershell
.\gradlew.bat assembleDebug            # 기본 -PdemoSpeed=1.0 (실시간). 시간이 모자라면 -PdemoSpeed=1.5. 패널을 아예 숨기려면 -PdemoPanel=false (그러면 시나리오를 못 돌린다 — 사내 Signal Simulator 전용)
adb install -r automotive\build\outputs\apk\debug\automotive-debug.apk
```
```bash
bash tools/emu_flow.sh /tmp/flow       # 끝에 "result: PASS", "clashes: 0" 이어야 한다
```
- 에뮬 소리 켬(TTS). 우상단에 `시연` 글자가 **보이면 Fake** — 사내 Real 포트에서는 `시연` 이 사라지고 Signal Simulator 로 속도·기어·도어를 준다.
- 앱을 끄고 다시 켠다(프로필 관측·ProgressStore 는 인메모리 → 새 세션은 "처음 하는 과제").

## 시간 조절

| 손잡이 | 효과 |
|---|---|
| `-PdemoSpeed=1.5` | 시나리오 44 s → 29 s, 26 s → 17 s. 음성이 밀리면 1.2 로 |
| `시연` → **정차** | 시나리오 도중 속도를 0 으로 고정 — 말할 시간을 산다. **출발**로 복귀. 패널은 누를 때마다 접히므로 다시 `시연` |
| 회차 1 만 | 시간이 없으면 "한 번 더"를 건너뛰고 바로 `시연` → **문 열기** → 리포트(회차 1) |
| 가이드 모드 | 시간이 남으면 회차 3 을 가이드로 — 단계별 확인 음성 6개가 나온다(잘한 주차 시나리오) |

## 사고 대응

| 증상 | 대응 |
|---|---|
| 회차 1 이 숙련 58점으로 나온다(60 기대) | 회차 시간이 시간 감점 경계(유예 60 s + 10 s = **70 s**)를 넘었다. 못한 주차 44 s + 도구·망설임 10~13 s 가 보통이라 여유는 15 s 쯤(9/28 에 유예 45 → 60 으로 올린 이유 — 55 s 경계에서 60/58 이 흔들렸다). 시연에는 지장 없다(멘트·조언은 같은 밴드). 녹화라면 다시 찍거나 `-PdemoSpeed=1.2` |
| 시나리오 버튼이 안 보인다 | 패널이 접혀 있다. 우상단 `시연`. 주행 잠금(속도 > 5) 중에는 `시연` 도 사라진다 — 정차를 기다린다 |
| 사내에서 `시연` 은 보이는데 정차·문 열기가 안 먹는다 | 정상 — Hybrid 에서 실물이 주는 키(속도·도어)는 실물이 이긴다. Signal Simulator 로 속도 0·도어 열림을 준다. 조향각·기어가 실물에 없으면 시나리오가 채우고 배지가 "시뮬레이션 N"으로 말한다 |
| `시연` 이 아예 없다 | `-PfillMissing=false` 순수 Real 빌드거나 `-PdemoPanel=false` 빌드다. Signal Simulator 로 `Vehicle.Speed`·`SelectedGear`·`SteeringWheel.Angle`·도어를 준다. 조향각·기어가 없으면 힌트가 A층(급정지)만 나온다 — 그대로 진행하고 배지의 "미측정"을 보여준다 |
| 급정지 힌트("제동이 급했어요")만 안 나오고 리포트 안전이 70 | 급제동 검출은 속도 샘플 시각에 민감하다 — 에뮬 부하(녹화·덤프)로 마지막 정지 샘플이 늦으면 가속도가 임계를 못 넘는다. 9/28 에 여유를 17 → 144 ms 로 벌렸다(임계 -3.0, 시나리오 4.8 km/h). 그래도 빠지면 녹화 중이 아닌지 확인하고 다시. 시연 진행에는 지장 없다(다른 두 힌트·조언은 그대로) |
| 힌트 음성이 안 나온다 | 자막은 나온다(엔진 없음). 자막을 읽어 준다. logcat `MOAH/AndroidTtsPort` |
| "다 됐어요"가 안 보인다 | 속도가 1 km/h 미만이어야 한다. `시연` → **정차** |
| 리포트가 안 열린다 | 정차 + 운전석 도어 열림 둘 다. **정차** → **문 열기**. 또는 `Done` 의 **오늘은 여기까지** |
| `Done` 에 궤적이 없다 | 이동 거리가 0.5 m 미만이거나(출발 전 점검 과제) 경로가 비었다 — 정상. 주차 과제는 시나리오가 돌았으면 나온다. 조향각·기어가 `MISSING` 이면 직선으로 추정된다(A층만) |
| 멘트가 반복된다 | 최근 3개 반복 금지이지만 밴드에 4개뿐인 곳이 있다 — 회차 3 이상은 겹칠 수 있다. 회차 2 까지만 |
| 앱이 죽었다 | `adb shell am start -n com.moah.hackathon/.ui.MainActivity`. 세션은 인메모리라 처음부터 |
