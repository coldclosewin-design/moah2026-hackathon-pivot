- 사내 녹화라면 패널 `AI 연결` 로 Copilot 로그인을 먼저(device code, GitHub 에서 **Authorize 까지**) — `AI 코치 · 연결됨` 이어야 회차 멘트·총평이 Cloud 문장이다. 안 되면 시드 문장으로 폴백하고 시연은 그대로 간다.
