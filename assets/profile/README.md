# 프로필 에셋 라이브러리

사용자 프로필에 맞춰 홈 화면의 시각 요소를 바꾸기 위한 원본 에셋 모음입니다.
현재는 원목 자동차 5종의 **오른쪽 방향 옆모습**이 들어 있습니다.
2026-10-08 사용자 요청으로 폴더를 만들었으며, 현재 단계는 에셋 준비와 인계입니다.

## 폴더 구성

- `manifest.json`: 차종 ID, 프로필 값, 파일 경로, Android 리소스 이름.
- `CLAUDE_HANDOFF.md`: 현재 홈 화면 연결 지점과 적용 시 확인할 사항.
- `vehicles/wooden/v2/`: 1536×1024 RGBA PNG 5개, 오른쪽 방향.
- `vehicles/wooden/v2/prompts.json`: 원래 디자인 프롬프트와 방향 변경 프롬프트.
- `validation.json`: PNG 규격, 파일 해시, 알파 채널 확인 결과.

## 현재 매핑

| 프로필 저장 값 | 칩 ID | 에셋 ID | 특징 |
|---|---|---|---|
| 경차 | compact | vehicle.city | 노랑, 짧고 둥근 차체 |
| 준중형 | small | vehicle.sedan | 빨강, 낮고 긴 세단 |
| 중형 SUV | mid-suv | vehicle.midsize_suv | 초록, 경사진 뒤 지붕 |
| 큰 차 | large | vehicle.large_suv | 네이비, 각진 차체와 루프랙 |
| 아직 선택지 없음 | — | vehicle.minivan | 주황, 높은 지붕과 긴 실내 |

현재 프로필은 네 가지 선택지만 제공하므로 미니밴은 확장용입니다.
미응답·null·알 수 없는 값은 특정 차종으로 추정하지 말고 기존 홈 차량 그림을 기본값으로 사용합니다.

## 에셋 추가 규칙

1. `카테고리/스타일/v버전/`에 추가합니다. 예: `vehicles/wooden/v3/`.
2. 차량은 `profile_vehicle_<차종>_<방향>.png` 형태의 영문 소문자와 밑줄 파일명을 사용합니다.
3. 의미상 같은 차종은 `vehicle.city`처럼 안정적인 ID를 유지하고, 파일·스타일·버전을 구분합니다.
4. 프로필 값과 연결할 에셋만 manifest에 매핑합니다. 새 선택지가 필요하면 프로필 모델·저장·화면 변경을 함께 검토합니다.
5. 다른 프로필 주제는 필요할 때 `avatars/`, `goals/`, `badges/` 등의 카테고리를 추가합니다. 빈 폴더를 미리 만들 필요는 없습니다.
6. PNG의 투명도를 유지하고, 차량은 기본적으로 오른쪽 옆모습으로 맞춥니다. 크기·여백·바퀴 기준선도 실제 홈 화면에서 비교합니다.
7. 검토된 파일을 덮어쓰기보다 새 버전을 추가하고 manifest의 사용 대상을 갱신합니다.
8. 실제 앱에 연결할 리소스만 `drawable-nodpi`에 복사합니다. 이 원본 라이브러리는 앱 빌드에 자동 포함되지 않습니다.

## 제작 기록

내장 이미지 생성기로 원목 자동차를 제작하고, 동일 도구의 편집 기능으로 오른쪽 방향 버전을 만들었습니다.
오른쪽 버전은 이미지 편집 결과이며 원본 PNG의 픽셀 배열을 기계적으로 뒤집은 파일은 아닙니다.
차량 형태·색상·재질을 유지하는 프롬프트와 생성 프롬프트를 함께 보관합니다.
